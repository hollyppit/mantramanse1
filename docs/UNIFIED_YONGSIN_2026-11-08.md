# 통합 용신 판단 엔진 — 전후 비교 (2026-11-08)

기준: `HEAD`의 engine.js·compat-pair.js(옛 방식) ↔ 작업 폴더(새 방식). 같은 무작위 사주 2000개(1935~2014년생, 자동 용신 기준)를 두 엔진에 넣었습니다. 생성: `node tools/unified-yongsin-compare.cjs`.

## 무엇이 바뀌었나

- **옛 방식**: methodAdvice 판정이 조후·병행이면 조후용신, 그 밖에는 억부용신. 격국·통관·병약·종격은 화면에 보여 주기만 했습니다.
- **새 방식**: 억부·조후·격국·통관·제화 각각의 근거와 필요도(해당 없음·참고·필요·급함)를 따로 매기고, 규칙 순서로 주 기준·보조 기준을 정합니다(점수 평균 없음). 종격이 충족되면 세력을 따르는 배치를 씁니다. 주 기준이 아닌 기준이 원하는 오행은 기신·구신이어도 조건부로 세기를 줄이고 이유를 남깁니다.
- 운세 흐름(대운·세운·월운·일진)과 궁합(나와 맞는 오행·일주, 두 사람 궁합)이 같은 통합 판단(역할값)을 씁니다. 월운은 세운을, 일진은 월운을 상위 운으로 이어받고, 상위 운 기둥과 이번 운 기둥의 합·충을 따로 봅니다.
