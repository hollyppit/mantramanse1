# 신년운세 문구 규격 (단계 C) — 모든 문구 작성자가 따르는 기준

AI 실시간 호출 없이, 미리 쓴 문구를 조건으로 골라 조합한다. 이 문서는 그 '미리 쓴 문구'의 형식과 말투 기준이다.

## 1. 말투
- **예외(2026-11-25): 토정비결 원문 해석(월별 gist, 원문 바로 아래 한 줄)은 고전 반말 예언체** — ~리라·~니라·~하라·~마라. 총평·좋은 점·조심할 점·월별 심화 등 상세풀이는 아래 해요체 그대로. 검사 tests/tojeong-classical-sim.cjs.
- **해요체 존댓말.** 독자는 "당신"이라 부르지 않고 주어를 생략하거나 "올해는"으로 시작한다.
- **생활 장면으로.** 보고서체("~할 수 있는 시기입니다"만 반복) 금지. 월급날, 단톡방, 회의, 이사 견적, 병원 예약, 카드값, 연락 끊긴 친구처럼 손에 잡히는 장면을 쓴다.
- **명리 용어는 그대로 쓰지 않는다.** 꼭 필요하면 쉬운 말 뒤 괄호로 한 번만: "나를 다잡는 기운(정관)". 신강·신약·십성·용신·합충 같은 말을 문장 주어로 쓰지 않는다.
- **솔직하게, 결말은 현실적으로.** 좋은 말만 늘어놓지 않는다. 좋은 운과 나쁜 운 모두 쓰고, 각각 대응 방법을 준다.
- **첫 문장은 후킹.** 질문형 또는 단정형 한 문장(화면의 큰 제목이 된다). 예) "올해는 누가 시키지 않아도 책임이 먼저 찾아옵니다."
- 한 블록의 문장 수: hook 1 + situation 1~2 + scene 1~2 + advice 1~2. 한 문장 70자 안팎, 120자 넘기지 않기.

## 2. 금지
- **확정 예언 금지(특히 건강·사고·재물):** "반드시", "틀림없이", "100%", "무조건", "~하게 됩니다(확정)", "병에 걸립니다", "사고가 납니다", "돈을 잃습니다", "죽", "이혼합니다", "망합니다". → "~할 수 있어요", "~쪽으로 기울기 쉬워요", "~를 살펴 두면 좋아요".
- 의료·법률·투자 지시 금지: 특정 약·치료·종목·금액 권유 금지. "검진 일정을 미루지 마세요" 수준까지.
- 출처 없는 전통 해석을 지어내지 않는다. 토정비결 원문 풀이는 **원문에 있는 내용만** 쉬운 말로 옮긴다.
- 범용 문장 금지: 어느 사주에나 붙는 "노력하면 좋은 결과가 있습니다", "건강에 유의하세요", "긍정적인 마음을 가지세요" 같은 문장 금지.
- 같은 묶음 안에서 같은 표현 반복 금지(특히 "~하는 시기입니다", "~할 수 있습니다" 연속).
- 성별·나이·직업 고정관념 금지(누구나 읽을 수 있게).

## 3. 풀이 순서
**근거 → 기질·상황 → 현실 사례 → 실천 조언.** 근거 문장(사주 사실)은 조합기가 데이터로 만든다. 작성자는 `hook`, `situation`(기질·상황), `scene`(현실 사례), `advice`(실천 조언)를 쓴다.

## 4. 사주 조건 블록 형식 (`report/newyear/texts/saju-blocks-*.js`)
```js
/* 섹션 설명 */
(function(root){'use strict';
var BLOCKS=[
  { id:'total.stem.정관.up', section:'total', when:{ stemTG:['정관'], band:['순풍'] },
    hook:'…', situation:'…', scene:'…', advice:'…',
    alt:{ hook:'…', situation:'…', scene:'…', advice:'…' } },   // alt = 같은 조건의 다른 표현(사람마다 해시로 고름)
];
root.NewyearBlocks=(root.NewyearBlocks||[]).concat(BLOCKS);
if(typeof module!=='undefined'&&module.exports)module.exports=BLOCKS;
})(typeof window!=='undefined'?window:globalThis);
```
- `id` 는 파일 안에서 유일. `when` 키(모두 배열, 하나라도 맞으면 그 키 충족, 모든 키 충족 시 블록 선택):
  - `stemTG` / `branchTG`: 올해 세운 천간·지지의 십성(비견 겁재 식신 상관 편재 정재 편관 정관 편인 정인)
  - `tgGroup`: 비겁 식상 재성 관성 인성 (세운 천간 십성의 묶음)
  - `band`: 순풍 보통 주의 부담 (올해 운 등급)
  - `rel`: 천간합 천간충 육합 삼합 반합 방합 충 형 파 해 원진 귀문관 (올해 글자가 원국과 만드는 관계)
  - `change`: up same down (전년 대비) / `daeunChanged`: [true]
  - `samjae`: 날삼재 (2027년은 해묘미띠가 날삼재)
  - `domainBand`: 분야 등급 묶음 high mid low
  - `yongEl` / `giEl`: 목 화 토 금 수 (용신·기신 오행)
  - `monthDir`: good neutral caution burden (그 달 방향)
  - `compare`: same near different (토정·사주 방향 비교)
- 쓸 수 있는 자리표시(조합기가 채움): `{yearGz}`=丁未, `{yearName}`=정미년, `{relWithPlain}`=원국의 어느 기둥(예 "태어난 해의 기운"), `{yongPlain}`/`{giPlain}`=오행 쉬운 말(예 "불(화)"). 자리표시 없이도 읽히게 쓴다.

### 십성 쉬운 말 (작성자가 문장에 녹일 뜻)
| 십성 | 쉬운 말 |
|---|---|
| 비견 | 나와 같은 편·동료·자립심 |
| 겁재 | 경쟁자·나눠 가질 사람·승부욕 |
| 식신 | 꾸준히 만들어 내는 힘·먹고사는 재주·여유 |
| 상관 | 말과 표현·튀는 재능·틀을 깨는 힘 |
| 편재 | 큰돈·움직이는 돈·사업 감각·바깥 활동 |
| 정재 | 월급처럼 꼬박꼬박 들어오는 돈·살림·성실한 결과 |
| 편관 | 압박·갑작스러운 책임·경쟁 속 단련 |
| 정관 | 질서·직함·평가·나를 다잡는 규칙 |
| 편인 | 남다른 공부·직감·혼자 파고드는 힘 |
| 정인 | 도와주는 사람·자격·문서·안정 |

## 5. 토정비결 현대어 풀이 형식 (`report/newyear/texts/tojeong-modern-*.js`)
```js
(function(root){'use strict';
var MODERN={
  111:{ tone:'good', theme:'얼어붙었던 일이 풀리고 마른 나무에 봄이 오는 해',
    overview:['…(괘상·괘사 9구의 뜻을 쉬운 말 2~3문장)'], good:['원문에 있는 좋은 점'], caution:['원문에 있는 조심할 점'],
    months:{1:{tone:'good',gist:'그 달 3구의 뜻 한 문장'}, …, 12:{…}},
    refs:'근거로 쓴 구 예) 卦辭1·3, 正月 위단', status:'draft' },
};
root.TojeongModern=Object.assign(root.TojeongModern||{},MODERN);
if(typeof module!=='undefined'&&module.exports)module.exports=MODERN;
})(typeof window!=='undefined'?window:globalThis);
```
- 원문 파일: `report/newyear/texts/tojeong-kyu1077.js`(guaxiang·zhujie·guaci 9구·months 12×3구). 보충 4괘(663·711·862·863)는 `tojeong-nl-supplement.js`(front·back)에서 — months 는 `null` 로 두고 `monthsNote:'보충본에 월별 구 없음'`.
- tone: good(대체로 길) neutral(길흉 반반·평이) caution(조심이 앞섬) burden(흉이 앞섬). **원문 낱말(吉·凶·財·憂·損·利·喜·厄·訟·病 등)을 근거로** 정하고 애매하면 neutral.
- 원문에 없는 내용(직업 조언, 투자, 건강 처방)을 덧붙이지 않는다. 그건 사주 블록의 몫이다.
- 김혁제 한글 풀이를 보거나 옮기지 않는다(저작권). 판독 불가 □ 가 든 구는 뜻을 짐작하지 말고 그 구를 빼고 쓴다.
- 己가 '이미(已)' 뜻으로 쓰인 자리(예 吉運己回)는 뜻으로 읽는다.
