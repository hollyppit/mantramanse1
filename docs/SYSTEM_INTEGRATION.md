# 관리자·풀이 시스템 연결 점검

## 운영 연결

| 단계 | 관리 화면 | 실제 저장·사용 경로 |
|---|---|---|
| 첫 방문·입력·결과 경로 | 온보딩 | /api/onboarding 초안·공개본 → /api/story 커버 + Hub → 공통 완료 경로 |
| 상품·챕터·기본 문장 | 상품 구성, 챕터·해석 | /api/report-content → Compose.fromSaved → Compose.build |
| 장면 영상·이미지 | 클립 라이브러리, 일간·일주 영상 | /api/media, /api/awakening → 선택 후보 → 뷰어 |
| 원문 자료·검수 | 풀이 자료 | /api/src → 검수 후보 승인 → IK 저장소 |
| 운영 풀이 지식 | 풀이 지식 | 게시 + 검수 완료 + 출처 정책 통과 → /api/ik 심화·본문 대체 |
| 설명 구성·서비스 연결 | 풀이 구성, AI·서비스 연결 | ik:design, ik:rules → 지식 검색·합성 |
| 표현 강도 | 풀이 문체 | style:cfg → IK, AI 편집, 후속 설명의 문체 지시·캐시 서명 |
| 고정 문구·글꼴·배치 | 조합·텍스트 편집 | report-content의 sceneCopy·textStyles → 뷰어 |
| 종합 검사 | 시스템·서비스 점검 | 저장된 상품 검사 + 시스템 연결 진단 + 인생 지도 검사 |

## 제거·수정한 문제

- 설정의 중복 랜딩 관리 진입점을 제거하고 이전 경로도 온보딩으로 통합했다.
- 첫 화면만 즉시 공개되던 저장 방식을 온보딩 초안·게시 방식으로 통일했다.
- 실제 입력 모드를 두 개의 begin 라우트가 덮어쓰던 구조를 한 디스패처로 정리했다.
- 클라이언트 AI 요청의 옛 소설체 지시를 제거했다. 현재 표현 강도는 서버의 문체 설정이 결정한다.
- 문체 변경을 가리던 브라우저 AI 결과 캐시를 제거했다. 현재 문체 서명을 포함하는 서버 캐시를 사용한다.
- 기본 문체만 적용되던 챕터 AI 편집에 챕터 ID, 원본 ID, 분야별 문체 설정을 연결했다.
- AI 사용 중지 챕터는 문장과 미디어 모두 AI 요청·적용 대상에서 제외했다.
- 관리자 저장이 공용 콘텐츠 상태를 갱신하고 열린 미리보기도 갱신하도록 연결했다.
- 미디어 편집 후 조합·미리보기가 이전 라이브러리를 계속 쓰던 문제를 갱신 경로로 해결했다.
- 관리자 로딩 실패를 빈 정상 데이터처럼 취급하던 처리를 제거했다.
- 서비스 점검이 기본 챕터만 검사하던 문제를 저장된 상품 구성·미디어 검사로 수정했다.
- 자료 화면에 검수·승인 수와 서비스 게시 수, 출처 정책 통과 수를 구분해 표시했다.
- 지식 생성기·자료 통계·시스템 진단이 동일한 출처 사용 조건을 공유하도록 했다.

## 유지한 역할 구분

기본 해석 모듈과 자료 기반 풀이 지식은 같은 기능이 아니다. 모듈은 기본 챕터를 만들며, 지식은 검수·게시 후 심화 설명에 추가하거나 충분한 분야의 본문을 대체한다. 사용 여부와 적용 범위를 연결 진단에 표시한다.

표현 강도와 설명 깊이, 화면 글꼴·배치는 서로 다른 설정이다. 각 관리 화면에 적용 범위를 설명하고 다음 작업 화면으로 연결했다.

## 검증 범위

연결 상태·출처 정책·문체 우선순위·저장 상태·로딩 실패를 새 통합 테스트로 검사했다. 기존 자료 학습, IK, AI 편집, 문체, 상품 조립, 인생 지도, 온보딩, 관리자 로그인 회귀 검사를 함께 실행했다. AI 제공자 선택 검사는 네트워크 없는 모의 호출을 사용한다.

운영 사이트에는 아직 배포하지 않았다. 운영 자료의 실제 게시 상태와 제공자 연결은 배포 후 관리자 시스템·서비스 점검에서 확인한다. 실제 유료 AI 호출 및 운영 관리자 화면의 시각 검증은 수행하지 않았다.

## 추가 관리자 편집 점검

- 적용 버튼 전 항목·탭 전환 시 입력값이 유실되던 해석 모듈 편집기를 작업본 자동 수집 방식으로 변경했다. 저장은 별도 버튼으로 유지한다.
- 저장 버튼이 현재 입력을 함께 수집한다. 잘못된 ID나 중복 ID는 입력을 보존한 상태에서 전환·저장을 중단한다.
- 중복 저장을 막고 저장 중 추가 편집을 잠근다. 실패하면 입력과 기존 비활성 상태를 보존하고 재시도할 수 있다.
- 풀이 지식·구성·AI 서비스 설정·문체·온보딩 변경을 공통 미저장 표시와 연결했다. 미저장 문체와 풀이 구성은 탭 복귀 시 다시 로딩하지 않는다.
- 상단의 구형 클립 전용 저장 버튼은 해당 화면에만 표시한다. 공통 미저장 표시에서 수정이 남은 관리 화면으로 이동할 수 있다.
- 마지막 사용자 챕터를 삭제하거나 상품에 챕터가 없어도 오류 대신 빈 상태 안내를 표시한다.
- 비공개 상품도 조합 테스트에서 선택할 수 있도록 했다.
- 편집기 실행 테스트(admin-editing-sim)로 전환·연속 수정·직접 저장·ID 오류·중복 저장·실패 복구를 검증했다.
