# 28수 출전 등록부 (2026-11-21)

28수 천문방위·택일 기능의 근거 문헌 목록이다. 각 문헌을 아래 형식으로 기록했다.

## 검증 단계
| 단계 | 뜻 | 이번 조사에서 붙이는 조건 |
|---|---|---|
| `unverified` | 출처만 발견 | 목록·해제(提要)·도서관 서지만 확인 |
| `text_verified` | 원문 텍스트 확인 | 위키문헌·Kanripo 전산 텍스트 또는 스캔 이미지에서 해당 구절을 직접 읽음 |
| `edition_verified` | 판본·권차 확인 | 간행처·연대·권차·면(葉)을 원본 이미지로 특정함 |
| `cross_checked` | 다른 자료와 교차 확인 | `edition_verified` 자료끼리 대조함 |
| `approved` | 계산 엔진 적용 승인 | 사용자 승인 |

- 전산 텍스트만 본 경우는 `text_verified`가 최대다. 이번 조사에서 `edition_verified` 이상에 이른 자료는 **없다**.
- 전산 텍스트끼리 수치가 일치한 경우는 단계와 별도로 "교차 일치(전산)"로 적었다. `cross_checked`로 올리지 않았다.
- 원문 인용은 조사 때 받은 위키문헌 wikitext·Kanripo 파일·스캔 이미지에서 옮겼다. 위키문헌 고금도서집성 페이지의 구두점은 기계 구두(古詩文斷句)라 원래 것이 아니다.
