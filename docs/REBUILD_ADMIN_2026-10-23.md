# 재작성 문안 로컬 관리자 (2026-10-23)

운영 게시 없음. 로컬 전용 초안 관리 도구입니다. 기존 `report/admin/`, 엔진, 사용자 데이터, DB는 건드리지 않습니다.

## 실행
```bash
node tools/rebuild-admin.cjs --port 4789
```
출력된 `http://127.0.0.1:4789/#token=…` 주소로 접속합니다(토큰은 시작할 때마다 새로 생성, `--token`으로 고정 가능).
상태는 `editorial/rebuild-20261022/admin-data/`(state.json, traces.jsonl), 릴리스 후보는 `output/rebuild-release-candidates/`에 저장됩니다.

## 안전 장치
- 127.0.0.1 바인딩, Host 헤더 검사, `x-admin-token` 필수(타이밍 안전 비교), CSP·nosniff, 화면은 textContent만 사용.
- `POST /api/publish`는 항상 403 `publish-disabled`. 릴리스 후보 파일에는 `localOnly:true, publishedToProduction:false`.
- 시뮬레이션은 로컬 엔진만 사용(AI·네트워크 호출 0). 생년월일시는 기본 저장하지 않고 해시만 기록(`storeBirth` 선택 시에만 로컬 저장).
- 하드 검사 실패 문안은 검수·승인 불가. 승인에는 사유 5자 이상 필요. 시기(대운·세운) 장 문안은 "승인된 시기 판단 확인"을 체크해야 승인됨.
- 승인된 문안을 수정하면 새 버전이 되고 상태는 초안으로 돌아감.

## 기능
| 요구 | 위치 |
|---|---|
| 84개 장 조회 | 대시보드(주제별 장·상태 집계), 문안 탭 |
| 조건 검색 | 문안 탭: 장·상태·문구·조건 필드/값(예: gender=여) |
| 신구 비교 | 문안 상세: 기존 운영 시드 문구(조건 유사도 순)와 단어 단위 diff |
| 품질 검사 | 검사 탭: 하드/소프트 검사, 8개 지표 점수(명리 오류는 문체 점수와 무관하게 불합격) |
| 중복 검사 | 같은 장·다른 장 쌍 유사도(Jaccard) |
| 상충 검사 | 선언 상충의 대칭·존재 검사 + 원국 60개 동시 표시 쌍의 반대 판정 후보 스캔 |
| 시뮬레이션 | 생년월일시·성별·양/음력·기준일·미리보기/승인본 모드, 장별 선택·일치 조건·제외 후보 |
| 사용자별 선택 추적 | 추적 탭: 실행마다 장별 선택 id·버전·상태·제외 사유 기록, 문안별 사용 이력 |
| 버전 관리 | 저장마다 새 버전, 버전 비교, 복원(새 버전으로 기록) |
| 승인·복원 | 상태 전환(초안→검수중→승인→폐기), 릴리스 후보 생성, 릴리스 상태로 복원 |
| 일괄 교체 | 미리보기 후 적용(최대 200건, 전부 새 버전) |
| 감사 로그 | 모든 변경에 작업자·사유 기록 |
