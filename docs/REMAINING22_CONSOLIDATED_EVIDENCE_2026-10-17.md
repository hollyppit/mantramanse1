# 남은 22건 문헌·적용 조건·반례 통합 검수

2026-10-17. 원국 18건·연도 4건 전부 처리. 전체 규칙 확정 0건, 유보 22건. 이번 해결은 적용 조건과 잘못된 일반화의 배제이며 강약·과다·관계 위험의 확정이 아니다. 기존 엔진·모델 결과를 읽거나 정답으로 사용하지 않았다. 게시·배포·운영 변경·외부 AI 호출 없음.

## 조사 범위와 중복 제거

인계문서, cases.json, 22건 원장과 G12/G17/본신 합/32건 기존 기록을 대조했다. 기존 문헌의 평행 전사는 새 근거로 세지 않았다. 새 6개 장은 기존 docs/tools/연구 JSON의 URL·장명·핵심 명조 검색에 없던 구간이다. 6개 완성 비교 명조를 이번 원장에 추가했다. 이들은 하나의 책에 속하며 독립 학파 6개의 합의가 아니다. 새 적용 조건·반례 보강 18건, 새 후보의 격·역할 불일치로 적용을 제외한 3건(G04-N/Y·G14-N), 기존 근거만 동결한 1건(G12)을 구분한다. 후보를 검토한 것만으로 직접 증거 확보라 세지 않았다.

먼저 정한 결론 변경 요건: 상대 세력은 지원자 존재를 넘는 작용 비교, 합충은 성분별 보존/제약 설명, 경합은 격·월령·위치 전제, 판본은 영인 교감, 연도는 원국과 운 시작·기간 근거다. 이 요건을 충족하지 않은 부분은 unknown을 유지했다. 새 조건이 나오지 않는 기존 질문은 종료하며 표현만 바꿔 다시 조사하지 않는다.

## 새 출처 원장

모두 沈氏 본문 디지털 전사다. 현대 東里山人按·교감 校를 저자의 원문과 구분했다. 저자가 붙인 과거 성취·신분·혼인·질병·수명 서술은 예측 정답으로 사용하지 않았다. 아래 내용은 조문을 의역한 것이며 완성 명조와 구별한다.

- **N31** [子平真詮 三十一 論正官](https://www.donglishuzhai.net/chapter/3744.html), L50–57. 재인 병용과 합의 방해를 다룬 조건·완성 명조. 壬戌/丁未/戊申/乙卯는 丁壬 합으로 보조를 잃는 서술. 모든 丁壬 합을 같은 결과로 처리할 수 없다.

- **N35** [子平真詮 三十五 論印](https://www.donglishuzhai.net/chapter/3748.html), L50–64. 인격에서 설기·살·재를 쓰는 서로 다른 전제 및 완성 명조. L57 不要根深/祗要根深 이문, L59 丙/癸 이문은 채택하지 않는다. 校는 편집 교감, 按은 현대 의견이다.

- **N36** [子平真詮 三十六 論印取運](https://www.donglishuzhai.net/chapter/3749.html), L48–64. 인격의 성립 방식에 따라 취운 분기를 달리함. L52–58 일부는 편집자가 中州本으로 보충했다고 표시. 원본 교감 미완료이며 세운 전체 공식이 아니다.

- **N37** [子平真詮 三十七 論食神](https://www.donglishuzhai.net/chapter/3750.html), L48–61. 식신생재의 신강·식왕·재근 조건과 위치 반례. 梁 명조의 癸丑/癸亥 이문은 제외. 식신 성분 존재만으로 식신격을 선언하지 않는다.

- **N41** [子平真詮 四十一 論傷官](https://www.donglishuzhai.net/chapter/3754.html), L48–64. 상관패인의 상관왕·신약·인근 조건 및 겨울 금의 화상위재 사례. 격·기후·강약 전제를 유지. 상관 성분이 있음을 상관격 성립으로 바꾸지 않는다.

- **N42** [子平真詮 四十二 論傷官取運](https://www.donglishuzhai.net/chapter/3755.html), L48–60. 재다/인다 및 신강/신경에 따라 취운 방향이 달라지는 조건. L56·58 교감 글자를 별도 표시. 원국 분기 미확정이면 취운도 확정하지 않는다.

## 완성 비교 명조·반례

### C31 — 壬戌 / 丁未 / 戊申 / 乙卯

근거 N31, L50. 재 壬·인 丁의 합으로 관의 보조를 잃는다는 원문 해설.
대상: G16-N, G16-Y. 일치: 丁壬 재인 조합. 차이: 戊일·未월·인접 합 대 己일·辰월·己를 사이에 둔 격지 합. 목 관의 배치도 다름.
배제하는 일반화: 재인 동시 존재는 항상 병용 성공. 한계: G16에서 합 성립·합거·재인 소실을 확정하지 않는다.

### C35A — 戊戌 / 乙卯 / 丙午 / 乙亥

근거 N35, L52. 신강인왕 때 설기를 취하는 원문 사례.
대상: G23-N, G11-N. 일치: 丙일·卯월; G23은 丙午 일주까지 일치. 차이: G23은 戊戌→癸亥, 乙亥→丙申. G11은 일시도 다르고 금 재가 세 천간에 투출.
배제하는 일반화: 인격의 설기는 항상 해롭다. 한계: 비교 명조의 신강인왕 판단을 두 표본에 복사하지 않는다.

### C35B — 己未 / 甲戌 / 辛未 / 癸巳

근거 N35, L59 후반. 合財存食이라고 명시한 원문 사례. 앞 문장의 丙/癸 이문은 사용하지 않음.
대상: G24-N. 일치: 辛未 일주·甲財·己印의 합 조합. 차이: 비교는 년己–월甲 인접, G24는 년甲–시己 격지; 戌월/未월·癸巳/己亥 차이.
배제하는 일반화: 甲己 합쌍만 있으면 언제나 같은 재 소거 결과. 한계: G24 재·인 잔존이나 인중 여부는 증명하지 않는다.

### C37 — 癸酉 / 辛酉 / 己卯 / 乙亥

근거 N37, L61. 재가 먼저, 살이 뒤이고 식이 사이에 있으면 재당살을 제한한다는 위치 사례.
대상: G02-N, G03-N, G05-N, G20-N. 일치: 식·재·관살 경로를 위치로 검토하는 질문. 차이: 대상들의 일간·월령·투간 순서가 모두 다르며 G05는 식신 비투출.
배제하는 일반화: 식재살 성분 공존이면 반드시 재가 살을 돕는다. 한계: 한 가지 위치 예외만 확인하며 모든 생조·제어량에는 전용하지 않는다.

### C41A — 甲子 / 乙亥 / 辛未 / 戊子

근거 N41, L52. 亥에 근을 둔 甲과 未 회국을 화상위재로 설명한 사례.
대상: G03-N. 일치: 辛일·亥월·辛未 일주·甲 투출. 차이: G03은 癸卯/癸亥/辛未/甲午. 卯가 추가되어 亥卯未 세 지지는 갖추지만 원문의 乙·戊 투출이 없음; 午와 癸 둘도 다름.
배제하는 일반화: 겨울 금의 수는 언제나 목을 생하지 못하므로 재 경로는 전부 무효. 한계: 완성 목국의 화 성립·금의 감당 능력은 세 글자만으로 확정하지 않는다.

### C41B — 壬申 / 丙午 / 甲午 / 壬申

근거 N41, L55. 상관왕·인근심·신약 및 여름 목의 수 조절을 함께 제시한 패인 사례.
대상: G18-N, G21-N, G10-N, G10-Y. 일치: 상관과 인의 제어 경합. 차이: 대상은 丁/庚/己일이며 寅/巳/戌월. 午월 甲일의 기후·근 배치를 갖지 않음.
배제하는 일반화: 상관·인 글자가 하나씩 있으면 패인 성공. 한계: 같은 인 개수·장간 수를 강약으로 환산하지 않는다.
