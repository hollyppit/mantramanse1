## 3. 구조 메모
- **카탈로그 기본값**: `report/v2/reading-catalog.js`의 `SEED`(활성 64장, 전체 107행). 운영은 `ik:editorial:published`가 우선. 보관 장은 `state:'archived'`, 옮긴 legacyIds는 새 장으로 이동. `find()`는 보관 장의 legacyIds도 찾도록 4번째 대체 경로 추가.
- **세계(탭)**: `report/v2/explore.js`. w5·w6·w8은 `enabled:false` + `FOLDED_WORLDS`로 강제 끔, 그쪽으로 가던 옛 챕터는 `worldFor`가 w1로 보냄. 저장본 이름이 '재물운/커리어운/인연운'이면 '○○ 심화'로 덮어씀.
- **새 문안 묶음**(`editorial/rebuild-20261022/index.mjs`의 `bundles.overview`, `bundles.deepplus`):
  - `overview-lib.mjs`(신강·중화·신약 3갈래 틀), `overview-a/b/c.mjs`(self_24~37), `deep-plus.mjs`(심화 13 사람=용신 5갈래, 14 타이밍=현재 대운 천간 십성군 5갈래, 15 개운법=용신 5갈래).
  - `NEG` 상수는 이제 빈 문자열(단서 문장 안 씀). 운영에 이미 올라간 overview 문안에는 그 문장이 들어 있지만 `reading-text.js`의 `MAYBE_NOTE`가 화면에서 거름.
- **읽기 화면** `report/v2/reading-text.js`:
  - 피드백: 문단마다 붙이지 않고 `midFeedback`으로 장 중간 1회(`reading-plus.js`의 `feedback(part,label,force)`는 `force===true`일 때만 출력).
  - 풀이 디테일: `basisGroup`이 `NOTE_SENTENCE`(안내 문구)·`CALC_SENTENCE`(%·적용 조건·id·계산 언급) 문장을 거름. 원국 표·연결된 계산값·참고한 자료 목록은 제거.
  - 타이밍 그래프: `TIMING_TOPIC`(self_20·peak·self_24·wealth_06/10/14·career_08/12/14·love_08/14) → `rankedTiming`(대운 막대 + 상위 3개 시기 점수·이유 + `MONTH_IDS`는 12개월 상위 3개). 점수는 fitScore와 주제 십성으로 만든 읽기용 지표(확률 아님).
  - 심화 13·15장: `elementRoleChart`(오행 비율 + 용신 역할 표시).
  - 후킹: `report/v2/chapter-hooks.js`(`MantraChapterHooks`, `index.html`에서 reading-text 앞에 로드). 표에 있는 장은 본문 첫 문장을 떼지 않고 이 문장을 씀.
- **패널**: `report/v2/reading-media.js` `chapterThemes`에 새 장 번호 테마 추가, `SLOT_TOPIC`으로 요약 장·개운법 장이 해당 주제 장면 슬롯을 씀.
- **운 문맥**: `luck-reading.js` ids에 self_24, wealth/career/love_14 추가.
- **게시 스크립트**: `publish/prepare-overview.mjs`(`--set overview|deep`, 새 라이브러리 행은 `reading_compare_and_swap(key,null,…)`로 생성, 카탈로그는 md5 가드 후 패치 병합, 이력에 `backup-before-<set>` 백업), `publish/apply-overview-runner.mjs`(dry/libraries/catalog/rollback). 기존 `apply-runner.mjs`는 기존 행 갱신 전용이라 새 장에는 못 씀.

## 4. 읽기 전용 확인 SQL
```sql
select value::jsonb->>'version' v, md5(value) h,
 (select md5(value) from public.kv where key='ik:editorial:draft') d,
 (select count(*) from public.kv where key ~ '^ik:blocks:chapter:library\.timeline_(wealth|career|love)_1[345]$') deep_libs,
 (select count(*) from public.kv where key ~ '^ik:blocks:chapter:library\.timeline_self_(2[4-9]|3[0-7])$') ov_libs,
 (select jsonb_agg(t->>'title') from jsonb_array_elements(value::jsonb->'topics') t) titles
from public.kv where key='ik:editorial:published';
```

## 6. 사용자 요구 (지킬 것)
- 해요체, 장 첫 문장은 은유 후킹, 생활 장면 중심, 쉬운 말.
- 화면에서 빼라고 한 것: 문단마다 맞아요/아니에요(중간 1회만), 연결된 계산값·참고한 자료·원국 계산 표, 불필요한 설명·안내 문구, "가능성이지 정해진 일은 아니에요", 끝의 점. 풀이 디테일의 풀이 문장은 남김.
- 타이밍 장은 그래프 → 순위·점수 → 쉬운 이유 순서.
- 패널 이미지는 가로폭에 맞춤(잘려도 됨), 일간·일주 장은 꽉 채워 표시.
- 지킬 선: 사건·수입·합격·결혼·질병을 단정하지 않음, 개운법은 구매 권유·색/물건/방위 단정 금지, 금지어(반드시·무조건·100%·확정).
- 사용자는 기술 설명보다 "무엇을 어떻게 하면 되는지"를 원함. 실행 안내는 PowerShell용, 전체 경로, 한 줄씩.
