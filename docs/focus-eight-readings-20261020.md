# 대표 8개 사전 풀이 고도화 — 2026-10-20

## 범위

- `timeline_self_01`: 본질·기질
- `timeline_self_05`: 겉으로 보이는 모습과 내적 동기
- `timeline_self_12`: 반복하기 쉬운 실수
- `timeline_wealth_02`: 수입 방식
- `timeline_career_01`: 일과 업무 환경
- `timeline_love_06`: 관계에서 반복되는 갈등
- `timeline_self_20`: 대운에서 준비할 일
- `timeline_self_22`: 최종 사용설명서

기존 5개 정밀 유형을 7개 질문에 적용하고, 대운은 현재 흐름 3묶음(6종) × 강약 3종으로 나눈다. 총 44개 문단 묶음, 352개 편집 가능한 문안이다. 각 묶음은 핵심·생활 장면·강점·주의·활용·실천·적용 이유·근거 범위로 구성한다. 유형 밖의 명식은 기존 조건별 본문으로 연결한다.

## 계산과 근거

- 새 계산법이나 명리 규칙을 만들지 않는다. 기존 `deriveFacts`와 `evalConds`를 사용한다.
- 정밀 유형은 일간·강약·개별 십성 2종의 조건이 모두 맞아야 한다. 개별 십성 강함은 기존 기준 14% 이상이다.
- 대운은 `currentDaewoon.season`과 원국의 강약 모델을 함께 대조한다. 현재 대운 값이 없으면 해당 문안을 선택하지 않는다.
- 생활 해설은 `kind: guide`이며 원문 증거로 취급하지 않는다. 개인 풀이의 원문 인용·차단·버전 검증 경로를 유지한다.
- 현재 대운의 기간이나 전환 날짜, 세운의 사건을 이 문안에서 새로 계산하지 않는다.

## 관리자 검수

1. 질문을 고르고 **빠진 조건별 기본 문장 가져오기**를 누른다. 기존 문안의 ID와 수정 내용은 보존한다.
2. **대표 8개 챕터 상세 풀이** 또는 정밀 유형으로 문안을 좁힌다.
3. 가상 생년월일로 **현재 초안 미리보기**를 실행한다.
4. **적용 조건·풀이 근거 검수**에서 요구 값·실제 값·일치 여부, 제외 조건, 미적용 사유를 확인한다.
5. 조건 충족과 실제 본문 선택을 구별한다. 원문 근거가 있는 문안에는 검증된 원리·인용·문서 ID를 표시한다. 참고 해설은 원문 근거가 없다고 표시한다.
6. 적용 사례와 반례 검증 및 기존 게시 절차를 거친다.

대표 챕터에만 최대 320개 문안을 허용해 보존된 이전 문안과 새 문안을 함께 가져올 수 있게 했다. 기본 문안의 새 ID는 공개 조회 때 보충되며, 동일 ID의 기존 게시본은 우선 보존한다. 관리자 검수 진단은 인증된 미리보기 응답에만 추가한다.
