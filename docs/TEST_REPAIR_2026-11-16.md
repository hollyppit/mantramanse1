## 3. 판단 사항 (2건 — 고치지 않음)

1. **health-narrative-flow-sim**: 건강 주제(꺼짐·보관)의 건강 1·6·8장 경로를 전제로 한 검사. 그 내용은 10/26 개편으로 `timeline_self_35`(건강·사고수) 한 장으로 합쳐졌고 운영은 DB 재작성 본문으로 나간다. 고치려면 self_35 기준의 새 테스트를 써야 한다 → 새로 쓸지, 없어진 기능 테스트로 정리할지 결정 필요.
2. **ux-writing-copy-audit-sim**: (1) 문구 목록 도구가 Node 내부 모듈(acorn)을 불러와 Node 24 에서는 `--expose-internals` 없이 실행이 안 된다(`npm i -D acorn` 이면 해결 — 외부 패키지 설치라 승인 필요). (2) 플래그를 주면 "검수 안 된 문구" 685개가 걸린다(대부분 내부 장 작성 지시문 "~를 구분한다"). 승인 목록에 일괄로 넣는 것은 검수를 건너뛰는 것이라 하지 않았다.
