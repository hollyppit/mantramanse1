# '이 사주에서만 읽히는 포인트' 층 (2026-10-27)

유료 풀이에서 사주마다 더 통찰 있는 풀이가 나오도록, 요소 하나씩 말하던 기존 문안 위에 **요소들이 맞물리는 지점**을 읽어 주는 층을 더했어요. 장 화면의 '내 사주로 더 깊게 보면'(depth) 바로 아래에 붙어요. 클라이언트 코드만 바뀌므로 운영 DB 게시는 필요 없어요(푸시하면 배포).

## 무엇을 읽나
| 요소(slot) | 읽는 내용 | 문안 사전 |
|---|---|---|
| pair | 가장 큰 기운 × 가장 작은 기운 (20조합) | `PAIR` |
| bandg | 일간의 힘(신강·중화·신약) × 가장 큰 기운 (15조합) | `BANDG` |
| pat1·pat2 | 구조(재다신약·군겁쟁재·상관견관·살인상생·무재 …16가지) | `PATTERN` |
| lack | 원국에 거의 없는 오행 | `LACK` |
| clim | 사주 전체의 기후(한습·열조 …7가지) | `CLIMATE` |
| st_y·m·d·h | 년·월·일·시주의 12운성 | `STAGE` + `PILLAR` |
| tg_ys…tg_hb | 년·월·일·시의 간·지에 놓인 십성 | `TG` + `PILLAR` |
| rel1~3 | 글자 사이 관계(충·형·파·해·합…)가 어느 두 자리 사이에 걸렸는지 | `RELPAIR` + `RELTYPE` |
| dwg·dwy·dwn·dwr | 지금 대운 십성군×원국, 대운 오행의 역할(용신·희신…), 다음 대운, 대운과 일지·월지 관계 | `DWG` `DWY` `DWN` `DWR` |
| seg·sen·ser | 올해 세운 십성군, 내년 세운, 올해 세운과 일지·월지 관계 | `SEG` `SEN` `SER` |

관점(lens)은 자기(self)·재물(wealth)·일(career)·인연(love) 네 가지이고, 장마다 어느 관점을 쓸지 `reading-insight.js`의 `PLAN`에 적혀 있어요. 건강·전생 장과 PLAN에 없는 장에는 붙지 않아요.

## 배정 규칙
- 사주 하나마다 `assign(sd)`가 장별로 쓸 요소를 미리 나눠요(결정적, WeakMap 보관). 같은 관점 안에서는 **한 요소를 한 장에만** 써서 한 리포트 안에 같은 문단이 되풀이되지 않아요.
- 장마다 선호 요소 순서(`PLAN`)가 있고, 모자라면 `SPARE` 순서로 채워요. 1차로 모든 장에 한 문단, 2차로 남는 요소를 한 문단 더 붙여요(최대 2).
- 자리 설명 문장(예: "월주는 …자리예요.")은 자리마다 3가지 표현을 돌려 쓰고, 한 장 안에서 같은 자리를 다시 말할 때는 생략해요.
- 값이 없으면(출생 시간 미상의 시주, 첫 대운 전 등) 그 요소는 만들지 않아요.
