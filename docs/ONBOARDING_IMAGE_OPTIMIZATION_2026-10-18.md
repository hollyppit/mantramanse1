# 온보딩 편집 메뉴와 이미지 최적화 (2026-10-18)

- 관리자 온보딩 왼쪽에 `홈 온보딩 이미지·문구` 메뉴를 복구했다. 시네마틱의 하위 버튼에 숨겨진 기존 renewal 편집기를 독립 메뉴로 노출하고 장면 순서, 문구, 이미지, 캐릭터 추가·배치·삭제·되돌리기를 연결했다.
- 이 메뉴의 미리보기는 `#/welcome?home=1`로 열린다. 메뉴 전환 시 미리보기 경로도 갱신한다.
- 온보딩 공통 업로드는 PNG/JPEG/정적 WebP를 브라우저에서 긴 변 1920px 이하, WebP 품질 0.84로 처리한 후 업로드한다. 확대하지 않고, 원본보다 작은 결과만 사용하며 투명도와 비율을 유지한다. 영상, GIF/AVIF 및 APNG/animated WebP는 변환하지 않는다.
- `기존 이미지 전체 자동 최적화`: 현재 온보딩 설정에 실제로 지정된 같은 사이트 이미지 주소를 중복 제거하여 순차 처리한다. 새 R2 파일 주소를 초안에 적용하며 기존 원본은 삭제하지 않는다. 이미지별 실패는 원래 주소를 유지하고 표시한다. 이미 최적화한 주소는 브라우저에 기록하여 반복 손실 압축을 피한다.
- 최적화 중 저장·게시를 차단한다. 편집 중인 텍스트를 수집하고 URL 교체를 열린 양식에도 반영하여 이후 collect()가 옛 주소를 복구하지 않게 했다.
- 기존 파일 최적화 결과는 관리자가 초안 저장 후 게시해야 방문자에게 적용된다. 배포 과정에서 운영 중인 공개본이나 저장되지 않은 관리자 내용을 수정하지 않았다.

검증: output/onboarding-image-release/browser-verification.json 및 production-verification.json.
실제 Edge 브라우저에서 3000×2000 투명 PNG 18,810,572바이트 → 1920×1280 WebP 1,412,484바이트(약 92% 절약), alpha=0 유지. 실제 업로드 helper와 기존 이미지 일괄 처리, 중복 제거, 문구 유지, 실패 주소 유지, PC/390px 모바일 메뉴, 캐릭터 추가, 이전 화면 미리보기, JavaScript 오류 없음 확인.
배포는 직전 운영 사이트 전체를 복사하고 이번 관리자 파일 7개만 교체했다. Worker/API와 운영 환경 설정은 유지했다. 배포 ID는 output/onboarding-image-release/deployment.json 참조.
