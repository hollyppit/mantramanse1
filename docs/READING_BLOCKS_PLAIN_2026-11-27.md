## 4. 찾은 문제와 고친 것 (화면 코드만, 고객용)

1. **그래프 범례가 두 번째 장부터 사라짐(버그)** — `reading-feature.js`의 장 사이 반복 제거(FactOnce)가 범례 문단까지 지워,
   주무기 12달 그래프(종합 ‘움직이기 좋은 달’) 등에 “선·띠·점 색이 뭔지” 설명이 없었다.
   → 범례·읽는 법 문단(`dp-key`·`dp-chartnote`·`data-keep`)은 지우지 않게 함. 주무기 범례에 `dp-key`.
2. **시기 순위 이유가 용어로 시작 + 같은 말 되풀이** — “상관 대운이라 … 원래 사주와 흐름이 잘 맞아 순풍을 받아요”가 1·2·3위에 똑같이.
   → `reading-text.js`: “결과물로 인정받는 기운(상관)이 들어오는 10년이고, …”, 해·달은 “경술(금)년은 독립과 경쟁의 기운(비견)이 들어오는 해예요.”
   같은 목록 안 두 번째부터는 “이때도 흐름이 잘 맞아요”처럼 짧게.
3. **내부 이름 노출** — “(엔진 careerProfile)”(적성 장 근거), “(accident-hint.js)”(건강 장 근거), “엔진이 계산한”(말년 블록),
   “표와 역할은 각 기준의 엔진 계산입니다”(개운), “같은 엔진 지수”(주무기 범례), “엔진 구조 판정”(주무기 재물) → 모두 쉬운 말로.
4. **개운 장 ‘개운법의 근거’ 블록** — 억부·조후·한난조습·기신·구신·생극이 설명 없이 습니다체로 나열.
   → `deep-time.js`: “힘의 세기 맞추기(억부)·온도·습도 맞추기(조후)”, “부담이 되는 기운(기신)·부담을 키우는 기운(구신)”,
   ① 내 힘의 세기 ② 사주의 온도·습도 ③ 다섯 기운의 많고 적음, 뿌리 막대 ‘타고난 뿌리(통근)·지금 운이 받쳐 주는 정도·지금 뿌리의 안정감’,
   뿌리 점수 뜻(100점에 가까울수록 단단함), 생활 개운법 문장 해요체. 계산 로그는 접힌 “계산 과정 자세히 보기(명리 용어 그대로)”로.
5. **점수 기준 없음**
   - 순위 블록(`reading-feature.js` rankBlock): “점수는 52점이 기본이고 내 사주의 특징과 맞을수록 올라가요(최고 96점) — 여기서는 「…」이 …점으로 가장 높아요.”
     52점 동점이 여럿이면 그 항목들이 비슷한 무게라고 알려 줌(전엔 52점 네 개가 이유 없이 나열).
   - 직업 후보(`deep-life.js`): 적합도·부담도 뜻. 돈 버는 방식(`deep-wealth.js`): 70점 이상 잘 맞음·50점 아래 힘이 덜 실림.
   - 적성 장 근거: “100점에 가까울수록 잘 맞음”, “마주 보는 두 방식의 합이 100%”.
6. **각주가 닿지 않는 카드 이름표** — 운명 기록 카드(`deep-life.js` dayCard)의 일간·일지·지장간·12운성·신살
   → “나를 뜻하는 글자(일간)·내가 앉은 자리(일지)·그 안에 숨은 기운(지장간)·그 자리의 힘 단계(12운성)·붙은 별(신살)”.
   자동차 비유 카드 ‘강약과 통근’ → ‘힘의 세기와 뿌리’. 주무기 ‘주무기와 직업 십성의 결합’ → ‘주무기와 일에 쓰는 세 가지 힘’.
7. **원국 표(타임라인과 공용 `report/natal-table.js`)** — 십성 이름 열 가지의 뜻을 한 줄 열쇠로 추가.
8. **주무기 블록 공용 문장** — 만세력과 같은 판정 모듈(weapon.js·weapon-data.js, 상담자용 용어 유지)은 그대로 두고,
   유료 블록에서만 `plainWp()`로 “십신의 구조·실제 작용 → 역할(십신)의 짜임과 실제 쓰임”, “午子충 → 午子충(두 글자가 부딪힘)”.
   범례 ‘점 색 = 그 시기 천간의 오행 · 두 값은 합치지 않아요’ → ‘그 시기에 들어오는 기운의 색 · 선과 띠는 따로 매긴 값이라 더하지 않아요’.
9. **DB 문형을 화면에서 풀기** — “억부와 조후 기준이 같은 용신 오행이 수(…)고 / 화예요 / …으로 계산됐어요” 꼴이
   기존 화면 변환 규칙을 빠져나가던 것을 `reading-text.js` 규칙 한 줄로 “내게 가장 필요한 기운(용신)은 물 기운…”으로.

바꾼 파일: `report/natal-table.js`, `report/v2/{reading-text, reading-feature, deep, deep-life, deep-time, deep-wealth, aptitude-chapters, health-chapters, weapon-chapters, weapon-chapters-data}.js`,
`report/v2/index.html`(위 스크립트 `?v=20261127-plain`), 테스트 문구 2줄(`tests/story-content-sim.js`, `tests/metaphor-sim.js` — 해요체로 바뀐 문장).
