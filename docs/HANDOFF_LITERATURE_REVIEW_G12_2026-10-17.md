## 1. 사용자의 현재 의도와 필수 제한

새 대화의 작업 목표는 남은 22건의 근거 보강을 문헌 수집부터 적용 조건·반례 검수까지 묶어서 일괄 완료하는 것이다. G12 한 쟁점을 잘게 나누어 같은 유보 결론을 반복하는 방식은 중단한다. 아래 G12 상세 이력은 기존 근거를 재사용하기 위한 참고이며, 전체 작업보다 우선하는 지시가 아니다.

- 기존 만세력 엔진을 기반으로 유지한다. 엔진 점수·모델 결과를 독립 문헌 검수의 정답으로 삼지 않는다.
- 문헌의 적용 조건과 반례를 실제 표본 배치와 대조한다. 단순 글자 존재·장간 개수로 실효 강도나 상대 우세를 확정하지 않는다.
- 근거가 부족하면 unknown/유보. 유보를 줄이기 위해 결론을 강제하지 않는다.
- **게시·운영 설정 변경·배포·외부 AI 호출 금지.** 웹 문헌 검색/원문 열람은 허용되어 왔다. 외부 AI 생성·후보 추출·유료 API 호출은 하지 않는다.
- 원문·저자 주석·후대 평주·현대 편집자의 해석을 구분한다. 학파가 다른 설명을 합산하여 합의로 표시하지 않는다.
- 완성 문헌 명조와 일부 조건만 제시한 조문을 구분한다. 조문을 조립해 가상의 완성 명조를 원문 사례처럼 만들지 않는다.

## 5. G12 원자료와 현재 결론

G12-N: 남성, 시주 알려짐.
년 壬子 / 월 戊申 / 일 丙戌 / 시 癸巳.

다음 다섯 층을 분리:
1. 子에 癸 장간이 배속되는 사실 — 부분 확인.
2. 년子가 격지 시癸를 실제 지원하는 정도 — 유보.
3. 월戊–일丙–시癸에서 합 성립·합반·합거·합화의 결과 — 유보.
4. 합 뒤 癸의 일부 수 기능이 아니라 **丙에 대한 관 작용**이 남는지 — 유보.
5. 癸 잔존과 별개로 戊가 壬을 충분히 제어하는지 — 유보.

‘合’과 ‘合去’와 ‘化’를 같은 뜻으로 쓰지 않는다. 근 보존·불화는 관 기능 보존의 자동 증거가 아니다. 癸가 남는다고 戊 실패, 癸가 제한된다고 戊 성공으로 판단하지 않는다.

G12에는 辰이 없으므로 申子를 완성 申子辰 수국으로 처리하지 않는다. 午가 없다는 이유만으로 子의 완전 보존을 확정하지 않는다. 巳申은 戌을 사이에 둔다. G12에는 寅이 없어 완전 寅巳申 삼형이 있다고 쓰지 않는다.

## 6. 가장 중요한 비교 명조와 적용 한계

### C7: 壬寅 / 戊申 / 丙寅 / 癸巳

徐樂吾 평주의 합관유살 설명 사례. G12와 네 천간 순서, 월주·시주가 같다. ‘丙이 사이에 있으므로 반드시 戊癸 합거를 막는다’는 일반 명제의 문헌 내 반례다.

G12는 년寅→子, 일寅→戌로 두 지지가 다르므로 결과 전체 전용 금지. 두 寅의 목화 지원·제토와 寅申/寅巳申 관계가 바뀐다. 원문은 그 두 변경 뒤 결과를 해설하지 않는다. 평주가 소개한 三命通會의 去留 명칭 차이는 해당 원전을 직접 확인한 별도 결론으로 세지 않는다.

### C8: 戊子 / 癸亥 / 庚寅 / 戊寅

徐評는 戊癸 합 뒤에도 통근한 癸의 설기를 남긴다. 합이면 항상 癸 기능 0이라는 주장에 대한 반례. 그러나 亥월·庚일간·戊 둘·인접 합이라 子 하나의 독립 효과나 G12의 관 기능을 증명하지 않는다.

### C11: 己酉 / 丙子 / 戊辰 / 癸亥

徐評의 子월·亥 지원 아래 癸의 대상별 작용 제한 사례. 수 지원과 자유로운 극丙 작용이 별개임을 보강. 戊일간 본신 합이므로 G12의 별위 합으로 전용 금지.

### C12: 癸酉 / 癸亥 / 戊子 / 丁巳

徐評의 두 癸와 戊 본신 합 및 재의 향배 사례. 子·亥 존재와 수 기능을 검토할 수 있으나 癸 둘·본신 합이므로 G12의 별위 합거 불가를 증명하지 못한다.

### 그 외 재검수 사례

- 壬子/壬子/丙戌/戊戌: 任氏의 戌 둘 지원·戊 제수. 子월·癸 없음·巳申 없음이라 G12 戌 하나의 충분성 미증명.
- 癸丑/戊午/丙午/壬辰 vs 癸巳/戊午/丙午/壬辰: 任氏가 지지 한 변경으로 합불화/합화를 달리 설명. 근 보존과 원래 관 작용 보존을 구분. 丑을 子로 동일시하지 않는다.
- 癸亥/戊午/壬午/己酉: 任氏가 癸 합으로 戊의 壬 공격이 제한된다고 설명. 합이 戊 제어와 항상 무관하다는 일반론의 반례지만 G12의 소진량 근거 아님.
