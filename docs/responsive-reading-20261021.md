# 작은 화면·큰 화면 풀이 검수

2026-10-21 운영 사용자 화면을 360px, 430px, 1024px iframe 뷰포트에서 확인했다. 실제 휴대전화 하드웨어 검사는 아니다.

## 반영 사항

- 본문·근거 박스에 border-box와 최소 폭 제한 해제를 적용해 좁은 화면에서 패딩이 폭을 늘리지 않도록 했다.
- 근거를 ‘이렇게 풀이한 이유’와 ‘명리 설명과 해석 범위’로 구분했다. 기존 문구와 계산값·출처를 유지했다.
- 근거는 작은 화면 15px, 큰 화면 16px로 표시하고 줄 간격·문단 간격을 정리했다. 긴 출처와 계산값은 줄바꿈한다.
- 펼침 버튼은 최소 48px 높이, 줄바꿈과 키보드 초점 표시를 제공한다. 근거 본문에는 높이 제한을 두지 않는다.
- 챕터 이동 버튼의 말줄임을 제거해 가로 스크롤로 전체 제목을 볼 수 있게 했다. 이전·다음 버튼도 좁은 폭에 맞춰 줄바꿈한다.
- 긴 그래프 라벨의 칸 너비를 유연하게 조정했다. 큰 화면의 읽기 열은 720px를 유지한다.
- 이미지 영역의 화면 높이 점유를 줄이고 챕터 끝 여백을 정리했다.

종합·재물 풀이와 펼친 근거에서 좁은 화면 줄바꿈, 긴 명리 설명, 계산값, 큰 화면 읽기 폭을 확인했다. 운 흐름 챕터의 제목·대운 표시는 430px에서 확인했다.
