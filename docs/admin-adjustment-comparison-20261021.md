- 기준은 두 보정 모두 미적용한 같은 명식입니다. 두 결과의 기준 시점은 동일합니다.
- 기본 비교 대상은 실제 사용자 게시본입니다. 공개 풀이와 같은 게시 카탈로그·문안·기본 문안 보완 경로를 호출합니다. 초안 편집은 이 결과에 섞이지 않습니다.
- '현재 편집 중인 초안'을 고르면 현재 화면에서 수정한 문안으로 두 원국을 비교합니다.
- 오행 비중과 변화량(%p), 강약 분류와 돕는 비중, 용신·희신과 기준을 나란히 보여줍니다.
- 8개 역할의 본문을 나란히 표시하고 동일·변경을 구분합니다. 새로 선택된 문안과 제외된 문안, 양쪽 적용 조건과 명리 근거를 펼쳐볼 수 있습니다.
- 합의 반영·보류 사유, 조후·궁성 계수, 보정 전후 분포를 별도 상세에서 확인합니다.
- 수치 변화가 문안의 선택 조건을 넘지 않으면 본문이 그대로일 수 있음을 안내합니다.
- 비교는 저장·게시·AI 호출 없이 수행합니다. 게시 버전이 달라지면 다시 불러와 검수합니다.
