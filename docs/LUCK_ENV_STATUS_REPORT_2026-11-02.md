## 5. 보안 점검(코드 검토 수준)
- 신규 API 쓰기는 모두 관리자 Bearer 인증(상수 시간 비교), 쿠키 미사용이라 CSRF 해당 없음.
- 입력 검증: 지역·항목 화이트리스트, 출처 https·기준일 필수, 문구 길이·단정·존댓말 검사.
- XSS: 관리자·사용자 화면 모두 값 이스케이프, 출처 링크는 https만 저장·표시, `rel="noopener noreferrer"`.
- 수정함: 잘못된 `x-reviewer` 헤더가 500을 일으키던 문제.
- **남은 위험**: 신규 쓰기 API에 관리자 비밀번호 **대입 시도 횟수 제한이 없음**(기존 `glossary` API와 같은 수준). 기존 관리자 로그인의 잠금 로직과의 통합은 미구현.
