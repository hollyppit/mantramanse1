# 명리 전문가 검수 안내

유료 풀이에 쓰는 사전 문안을 명리 전문가가 검수하기 위한 안내예요. 문안은 모두 AI 없이 미리 써 둔 문장이고, 사주 계산값이 조건에 맞을 때만 골라서 보여 줘요.

## 1. 검수 자료 만들기

```bash
node tools/export-review-packet.mjs
```

`output/review-packet/`에 CSV 5개가 생겨요. 엑셀에서 바로 열 수 있어요(UTF-8).

| 파일 | 내용 | 행 수(2026-10-26 기준) |
|---|---|---|
| `1_chapter_entries.csv` | 84개 장 본문 문안. 조건(when·unless), 핵심, 근거, 사례, 강점, 약점, 실천 | 925 |
| `2_detail_sentences.csv` | 정밀 보정 문장. 일간·월지·용신 × 주제 × 변형 | 680 |
| `3_element_lines.csv` | 사주 요소 풀이. 신살 35종, 12신살, 글자 관계 12종, 십성 10종 × 장 | 410 |
| `4_signature_mapping.csv` | 시그니처 성향군 매핑. 사주 요소가 어느 성향군으로 묶이는지 | 74 |
| `5_signature_text.csv` | 시그니처 문장. 성향군 핵심, 주제별 렌즈, 실천 항목, 66개 조합 | 186 |

## 2. 무엇을 봐 주시면 되나요

1. **명리 근거가 맞는지**: 조건(예: 관성 강함 + 신약, 현침살, 寅巳형)과 문장이 전통 해석에 비춰 무리가 없는지 봐 주세요.
2. **학파에 따라 갈리는 해석**: 갈리는 경우 "학파 차이"라고 적어 주시면 표현을 완화하거나 근거 문단에 설명을 더해요.
3. **성향군 매핑**(4번 파일): 예를 들어 낙정관살을 "책임감" 성향군으로 묶은 것이 적절한지 봐 주세요. 시그니처 카드의 근거가 돼요.
4. **단정 표현**: 사건·결과(사고, 질병, 이혼, 합격, 수익 등)를 단정하는 문장이 없어야 해요. 남아 있으면 "삭제"로 표시해 주세요.
5. **건강 문장**: 진단이나 예측처럼 읽히는 문장이 있으면 표시해 주세요.

## 3. 돌려주는 방법

각 행의 마지막 두 열만 채우면 돼요.

- `판정(적합/수정/삭제)`: 셋 중 하나
- `검수 의견`: 수정이면 고칠 방향이나 대안 문장

판정이 "수정"·"삭제"인 행은 id(또는 축·값·주제·변형, 요소·장)로 원문 위치를 찾아 고친 뒤, 해당 장만 다시 게시해요.

## 4. 함께 쓰는 자동 점검

```bash
node tools/audit-reading-consistency.mjs 30
```

가상 명식으로 실제 리포트를 만들어, 한 리포트 안에서 반복되는 문장과 서로 반대되는 경향 문장(예: "결정이 빠르다"와 "결정이 늦다")을 찾아 `docs/READING_CONSISTENCY_AUDIT.md`로 정리해요. 반대 경향이 함께 나온다고 틀린 풀이는 아니에요. 장마다 상황(일·관계·돈)이 다른지, 같은 상황에서 정반대로 말하는지를 검수 때 함께 봐 주세요.
