# 기본 84개 문안 완성·검수 기록

## 작성·게시

기본 84문항에 704개 문단을 미리 작성해 관리자 DB에 게시했습니다. 질문별 참고 해설 76편과 연속 창작 8편이며, 각 항목에 핵심·생활 사례·강점으로 쓸 조건·부담이 되는 조건·활용·실천·적용 이유·근거 설명을 제공합니다. 창작 본문에는 계산된 일간의 오행에 따라 선택하는 다섯 가지 문학적 표현이 있습니다.

- 문안 버전: `complete-84-20261020-1`
- 소스: `functions/_reading-guide-copy.js`, `functions/_reading-fiction-copy.js`, `functions/_reading-library-seed.js`
- 저장: `ik:blocks:chapter:library.timeline_*` 84개 레코드
- 적용·제외 검증 사례: 240개. 관리자 화면에서 문안과 사례를 다시 편집·검증·게시할 수 있습니다.
- 검수 주체: Codex 편집 검토 및 자동 조건·출력 검사입니다. 외부 전문가 승인이나 전통 해석의 예측 정확성을 주장하지 않습니다.

## 개인 풀이와 참고 해설 구분

기존 명리 엔진이 해당 사주에서 검증한 게시 근거가 있으면 그 판단을 우선 사용합니다. 근거가 없거나 장점·위험·사례 문장이 비어 있어도 해당 질문의 참고 설명을 보여줍니다. 참고 문안은 `kind: guide`, 개인 풀이와 참고 설명을 함께 보여주는 문단은 `contentKind: mixed`로 구분합니다. 참고 설명과 창작에는 개인 판단의 근거 ID를 붙이지 않습니다.

참고 설명이 개인 성향·과거·미래를 증명한 결과처럼 보이지 않도록 범위를 표시합니다. 기존 조건·제외 조건·자료 비활성화 검증은 유지하며, 새로운 명리 규칙을 만들어 빈칸을 채우지 않습니다. 전문적인 설명은 접힌 근거 영역에 남깁니다. 본문·창작에는 영상과 이미지를 추가하지 않았습니다.

## 창작의 연속성

기록관 서윤과 목수 하람이 항구의 빠진 기록을 찾는 이야기로 8편을 연결했습니다. 기록실 개방 → 항구와 역할 소개 → 동료와의 약속 → 물이 차오르는 밤의 협업 → 과거의 확인 누락 인정 → 공개된 기록 체계 정비 → 다음 담당자에게 인계하는 흐름입니다. 인물·나무 열쇠·빈 장부의 설정을 유지하고 독자의 실제 전생이나 현실의 인과로 연결하지 않습니다.

별도 웹소설 감상 버튼도 같은 게시 문안을 사용합니다. 아직 조회하지 않은 편은 기존 단일 요청 흐름에서 순서대로 불러오고, 이미 조회한 편은 다시 요청하지 않습니다. 예전의 빈 8장면 모델과 별도 전생 AI 생성 경로를 사용하지 않습니다.
