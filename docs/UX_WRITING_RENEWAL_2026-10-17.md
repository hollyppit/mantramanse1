# 풀이 문체 개편 — 구현 및 검증 기록

## 원인

- `functions/api/movingtoon-reading.js`가 남성 안내자 선택 시 반말을 최우선으로 지시했습니다.
- `_style.js`의 직설형은 전문 근거를 먼저 제시하도록 했고, 기존 문체는 가능성 표현을 줄이도록 지시했습니다.
- 생활 사례와 전생은 서술체를 유지하도록 별도 지시했습니다.
- `reading-flow.js`의 계산·전문 근거 문단은 일반 본문처럼 펼쳐져 있었습니다.

## 구현

- `_ux-writing.js`: 지식·계산과 분리된 표현 정책. 존댓말, 결론 우선, 성향→행동→손해→핵심→실천, 같은 기질의 조건부 최선·최악, 챕터 책임 범위를 지시합니다.
- 직설성 기본 3, 전체 및 챕터/분야별 1~5 설정. 5는 해당 생성 요청의 독자 체크박스 선택이 있어야 적용됩니다. 미선택은 최대 4입니다. 설정·정책이 캐시 서명에 포함됩니다.
- 관리자에서 전문 용어 수준, 문장 권장 길이, 문단 최대 길이, 사례 밀도를 저장합니다. 강조는 최소화 정책으로 고정했습니다.
- 본문 생성과 후킹은 안내자와 관계없이 존댓말을 사용합니다. 전문적인 관리자 검토 자료와 원본 RAG는 수정하지 않습니다.
- 반말, 전문 용어, 본문 백분율, 과도한 강조, 문단 길이, 동일 문단 반복을 검사합니다. 긴 문장·동일 어미 반복은 경고입니다.
- 실패 문단만 한 차례 재작성합니다. 정상 문단을 보존하고 refs/claim_ids 변경을 거부합니다. 재작성 뒤 일반 검증·grounded 근거 검증·기존 독립 검수를 다시 적용합니다. 실패는 통과시키지 않습니다. 검수의 의미 판단은 AI 검수 품질의 한계를 갖습니다.
- 원국·규칙·출처·예외·불확실성을 `왜 이런 풀이가 나왔나요?`에서 확인합니다. 기존 계산 데이터는 보존했습니다.
- 본문 글자 크기·행간 개선, 전문 근거 접기. PDF는 같은 생성 문장을 사용하고 전문 근거를 뒤에 배치합니다. 에셋·재생·스크롤 코드는 변경하지 않았습니다.
- 관리자 비교는 동일한 계산·검색 패키지를 재사용해 A 원문 / B 일반 2 / C 팩폭 3 / D 팩폭 4를 표시합니다. 문장 진단, 실제 근거 ID 연결 수, 동일 문단 반복 수, 항목별 수정 전후를 제공합니다. 근거 ID 연결은 의미적 일치를 보장하는 지표가 아닙니다.

## 후속 완료 — 실제 생성 비교와 고정 문구 검토

- 우선 5개 챕터 × 가상 원국3개에 실제 이전 AI15건 / 개선 AI30건(직설성3·4)을 생성해 비교했습니다. 상세: [실제 생성 비교 기록](UX_WRITING_ACTUAL_COMPARISON_2026-10-17.md), [전체 문장 비교 HTML](ux-writing-review/actual-comparison.html).
- 초기 자동 검수 통과 후보에도 의미 확장·추상성이 발견됐습니다. 최종 비교는 승인 지식의 뜻을 사람이 검토한 요지를 실제 AI가 문장화한 결과이며, 운영 API 전체 자동 흐름의 무인 품질 합격과 구분합니다. 최종30건은 실패 문단1개 재생성 후 자동 검사 통과, 이후 사람의 전체 문단 편집5건을 별도로 표시했습니다.
- 재물 챕터는120개 합성 명식 검색에서 출처 검증을 통과한 MONEY 판단이 없어 개인 해석을 보류했습니다. 해석 자료 부족을 계산표 부재나 재성이 없는 원국으로 바꾸지 않았습니다.
- 사용자 화면94파일에서13,023문자열·텍스트를 전수 추출하고 문체 후보를 검토했습니다. 1차887위치/29파일 편집 뒤 로컬 서사186문단 등을 재편집했습니다. 남성 안내자 반말 자동 변환을 제거했고, 운영 온보딩의 옛3문구는 읽기 시 정확한 문장 매핑으로 정리했습니다. [범위·유지 사유·검증](UX_WRITING_FIXED_COPY_AUDIT_2026-10-17.md).
- 최종 회귀20종과 신규 고정 문구 검사1종 통과. 엔진120개 기준선, 인트로126조합, 원본 지식·출처22키 및 온보딩2키 MD5 일치를 확인했습니다. API 키는 출력·수정하지 않았습니다. 응답 사용량으로 확인한 보수 추정 비용은 약0.931달러이고, 중단되어 사용량을 확인하지 못한4개 요청의 예약액까지 포함하면 약1.014달러입니다. 청구서 확정액은 아니며2달러 제한을 유지했습니다.

## 해석상 한계와 배포 상태
- 자연스러움·추상성·행동/손해/해결책의 충분함·의미적 중복은 정규식만으로 보장하지 않습니다. 이번 실제 산출물은 별도 편집 검토했으며, 이후 새 출력도 grounded 모드의 독립 검수를 유지합니다.
- 관리자 비교의 근거 서명은 입력 계산·검색 패키지의 동일성을 증명하며, 서로 다른 출력의 의미적 결론 일치까지 증명하지 않습니다.
- PDF 생성 로직·계산표 회귀 테스트는 통과했으나, 새 실제 풀이로 PDF 다운로드·최종 페이지 렌더링까지 확인하지 않았습니다.
- 실제 배포와 파괴적 운영 DB 변경은 수행하지 않았습니다. 실제 배포는 사용자 별도 승인 대상입니다.
