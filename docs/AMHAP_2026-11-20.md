# 지장간 암합 계산·해석 기능 — 보고 (2026-11-20)

## 1. 전제: 지장간 기준은 그대로

- 사용자 결정에 따라 지장간 데이터는 바꾸지 않았다. 午 = 己·丁, 亥 = 甲·壬은 프로젝트 채택 기준(사용자 설정값)이다. 통상 체계(午 丙·己·丁, 亥 戊·甲·壬)와의 차이는 `docs/JIJANGGAN_FIX_2026-11-20.md` 1-1절에 기록했다.
- 암합은 엔진의 일반 지장간(`JIJANGGAN`)만 쓴다. 월률분야(`WOLRYUL`)의 사령 천간을 지장간에 더하지 않는다.
- 월률분야는 선택 설정(`wolryulAssist`)으로 '태어난 때 월지에서 그 지장간이 사령 중이었음'을 표시하는 데만 쓴다. 성립 여부는 바꾸지 않는다.

## 2. 새 모듈 `amhap.js` (`MantraAmhap`)

| 함수 | 영역 | source |
|---|---|---|
| `natal(M, ch)` | 원국 네 지지의 여섯 쌍 + 같은 기둥 간지 암합 | `natal` |
| `luck(M, ch, layers)` | 운 지지 ↔ 원국 지지, 운끼리 | `daeun`·`seun`·`wolun`·`ilun`·`luck-luck` |
| `compat(M, chA, chB, {nameA, nameB})` | A 지지 ↔ B 지지, A 천간 ↔ B 지장간, B 천간 ↔ A 지장간 | `compatibility` |
| `interpret(M, rec, ctx)` | 일반·연애(love)·직업(career)·주의(caution) 문장 | — |

### 기록 구조 (지시문 10항 형식)

```js
{ type: 'branch-hidden-stem' | 'stem-hidden-stem' | 'self-hidden-stem',
  source, branchA, branchB, hiddenStemA, hiddenStemB, depthA, depthB,
  combination: '戊癸合', element: '火', relation: '暗合' | '干支暗合' | '明暗合' | '自合',
  school: 'default' | 'extended' | 'myeongam' | 'self' | (추가 학파),
  isValid, isTransformation: false, positions: [['month','day'], …],
  relatedTenGods: [{ stem, owner:'A'|'B', tenGod }], loveLink, careerLink, overlap: ['육합', …],
  saryeong?, period?, levels?(운끼리), activation, text: { general, love?, career?, caution } }
```

- **중복 방지**: 같은 지지 쌍·같은 합은 한 기록으로 묶고, 위치는 `positions`에 모두 남긴다(예: 午가 둘이고 亥가 하나면 기록 1개, 위치 2개).
- **다른 관계와의 관계**: 합충형파해는 `overlap`에 따로 적을 뿐 서로 지우지 않는다.
- **부작용 없음**: 오행 세력에 더하지 않고, 원본 지장간 데이터를 고치지 않는다.
- **운 암합**: 그 시점에만 계산하고 원국 결과에 더하지 않는다(`activation` = 운 단계, `period` = 그 운).

### 판정 기준과 학파 설정(`CFG`)

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `basic` / `useBasic` | 子戌(戊癸)·丑寅(戊癸)·寅未(甲己)·卯申(乙庚)·午亥(丁壬), 켬 | 대표 지지 암합 조합 |
| `extended` | 끔 | 일반 지장간에서 그 밖의 지지 조합도 찾음(예: 巳酉 丙辛, 子巳 癸戊) |
| `myeongam.samePillar` | 켬 | 같은 기둥 간지 암합(丁亥·戊子·辛巳·壬午 등) |
| `myeongam.otherPillar` | 끔 | 같은 사람의 다른 기둥 명암합 |
| `myeongam.cross` | 켬 | 궁합에서 A 천간 ↔ B 지장간 |
| `selfHap` | 끔 | 같은 지지 안 자합(辰 속 戊癸 등) |
| `extraCombos` | 없음 | 추가 학파 조합(기본 조합을 덮지 않고 더함) |
| `wolryulAssist` | 켬 | 사령 중 표시만 |

- 대표 5조합은 모두 지금 지장간 기준에서 성립한다. 丑寅의 戊癸는 丑 여기 癸와 寅 여기 戊의 합이다.
- 조합의 천간이 그 지지의 지장간에 없으면 `isValid:false`로 두고 화면에 보이지 않는다.

## 3. 해석 원칙

- 일반 문장은 '드러나지 않는 결합·내면의 끈'이라는 보조 해석으로 쓴다. 세운 문구는 지시문 예시 그대로다.
- **연애(love)** 문장은 다음 경우에만 붙는다.
  - 일지(배우자궁)가 끼었을 때
  - 배우자 자리 십성과 이어질 때(남자는 재성, 여자는 관성)
  - 내용은 표현되지 않은 호감·사적인 교감까지만 말하고, 다른 요소와 실제 상황을 함께 보라고 덧붙인다.
- **직업(career)** 문장은 다음 경우에만 붙는다.
  - 월지나 관성과 이어질 때
  - 내용은 조직 안의 드러나지 않는 역할·외부 협업·별도 프로젝트·겸업까지만 말하고, 직업 변동은 판단하지 않는다고 명시한다.
  - 운 단계에서 월지에 충·형이 함께 걸리면 '변화 신호가 겹침'을 덧붙인다.
- 모든 기록에 '길흉 판정이 아닌 보조 해석, 합화 아님' 주의 문장을 붙인다.
- 금지 표현(불륜·외도·유부·바람·반드시·무조건·이직/퇴사/해고 단정)은 테스트로 막는다.

## 4. 화면

- **원국 탭**: '천간 관계·지지 관계' 아래에 '암합 분석' 카드.
  - 지지 암합: 조합·합·오행·위치·참여 지장간(깊이)·십성·해석
  - 간지 암합: 접어서 표시
  - 없으면 "원국에서 확인되는 기본 암합이 없습니다."
- **운세 흐름 상세**:
  - 대운·세운·월운·일진 상세에 '○○ 암합' 상자를 둔다. 운 공통 분석 층이 켜져 있으면 ② 칸 안, 꺼져 있으면 기본 상세 안이다.
  - 그 운이 원국이나 다른 운과 실제로 암합을 이룰 때만 나온다.
  - 그 시점의 대운~일진 기둥은 기존 `olLayers`로 얻는다.
- **궁합 화면**: '두 사람의 간지 관계' 아래에 '숨은 인연 — 암합 분석' 카드.
  - 지지 암합 개수, 명암합 개수, 일지·배우자 자리와 이어진 개수, 각 항목
  - 명암합은 접어서 표시
  - 점수에는 넣지 않는다.
  - "암합이 많다고 좋은 궁합, 없다고 나쁜 궁합이 아님"을 명시한다.
- 로컬 브라우저에서 세 화면을 모두 확인했다. 예시 명식(庚午 己卯 己卯 辛未)의 결과는 다음과 같다.
  - 원국: 기본 암합 없음
  - 대운 寅 ↔ 시지 未: 寅未 甲己
  - 상대 1983-11-20 생과의 궁합: 午亥 丁壬

## 5. 테스트 (`tests/amhap-sim.cjs`, 지시문 12항 10가지)

1. 대표 5조합 판정(순서 무관). 기본값에서는 그 밖의 조합을 잡지 않고, `extended`에서 잡는다.
2. 참여 지장간이 일반 지장간에 있다.
3. 월률분야에만 있는 천간(子 壬·卯 甲·酉 庚·午 丙·亥 戊)으로 암합을 만들지 않는다.
4. 원국 결과와 운 결과가 섞이지 않는다. 운 분석 뒤에도 원국 결과가 그대로다.
5. 대운·세운·월운·일진·운끼리를 각각 맞게 표시한다.
6. 궁합은 늘 A↔B 교차이고, 양방향 명암합이며, 이름을 표시한다.
7. 명암합과 지지 암합을 구분한다. 같은 쌍은 기록 하나에 위치를 모두 보존한다.
8. `isTransformation`은 늘 false다.
9. 암합이 없을 때 지지 암합을 출력하지 않는다.
10. 모듈을 불러오고 분석을 돌린 전후로 다음이 같다. 원국·지장간 표·합충형파해·오행 세력(전 모델)·강약·용신·대운 점수·**궁합 점수**·지장간·월률분야 데이터. 사주 300명 + 상대 300명으로 확인했고, 문장의 금지 표현도 검사했다.

결과: 300명 중 원국에 기본 지지 암합이 있는 사람은 100명이다. 기록 수는 원국 388, 운 152, 궁합 2,495다(궁합은 명암합이 대부분이라 접어서 보여 줌).

## 7. 더 검토할 명리학 쟁점

- 대표 5조합 밖의 조합을 기본으로 넣을지(학파마다 다름). 예: 巳酉 丙辛은 반합과 겹치고, 子巳 癸戊는 巳의 여기 戊다. 지금은 `extended` 설정으로만 켤 수 있다.
- 午·亥의 여기를 넣는 체계라면 午 속 丙, 亥 속 戊로 생기는 암합(예: 辛午, 癸亥)이 추가된다. 지장간 기준을 바꿀 때 함께 검토해야 한다.
- 운 단계 암합에서 월운·일진의 월률분야 사령을 활성도로 쓸지(지금은 원국 사령 표시만 함).
- 무빙툰(`report/`) 화면에는 아직 연결하지 않았다(만세력 화면만).
