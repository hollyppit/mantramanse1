# 카카오 알림톡 템플릿 (2026-11-27)

솔라피 콘솔 → 알림톡 템플릿 등록에서 아래 내용 그대로 등록한다.

- **템플릿 유형:** 모두 '기본형'(강조 없음)
- **변수 이름:** `#{…}` 안의 글자를 한 글자도 바꾸지 않는다. 코드가 이 이름으로 값을 넣는다.
- **버튼:** 모두 '웹사이트 열기', '외부 브라우저로 열기'는 체크하지 않는다.

검수를 통과하면 템플릿 ID를 Cloudflare Pages Secret에 넣는다. 넣은 종류만 발송된다.

| 템플릿 | Secret | 보내는 때 |
|---|---|---|
| ① 구매 완료 | `SOLAPI_TPL_PAID` | 결제가 완료된 직후(구매 확인 메일과 같은 때) |
| ② 문의 답변 | `SOLAPI_TPL_ANSWER` | 관리자가 1:1 문의 답변을 저장할 때 |
| ③ 만료 예고 | `SOLAPI_TPL_EXPIRE` | 이용 기간(결제일 + 12개월)이 끝나기 30일 전, 매일 10시 |
| (기존) 만세력 PDF | `SOLAPI_TEMPLATE_ID` | 만세력 PDF 고르기 창 → 알림톡 보내기 |

**받는 사람:** 마이페이지 '카카오톡 알림 받기'에 번호를 등록한 회원에게만 보낸다. 번호가 없으면 지금처럼 메일만 간다.

---

## ① 구매 완료 — 템플릿 이름 `구매 완료 안내`

```
[만트라 포춘] 구매 완료 안내

구매가 완료되었습니다.

· 상품: #{상품}
· 결제 금액: #{금액}
· 이용 기간: #{기한}까지

아래 버튼을 눌러 바로 풀이를 보실 수 있습니다.
구매 후 7일 이내이고 유료 장을 열지 않았다면, 내 구매 내역에서 바로 환불할 수 있습니다.
```

**버튼**

| 버튼 이름 | 링크(모바일·PC 같게) |
|---|---|
| 풀이 보러 가기 | `https://mantrafortune.com/report/` |
| 내 구매 내역 | `https://mantrafortune.com/report/my/` |

**검수 메모**
> 회원이 사주 풀이 상품을 결제하면, 결제 완료 직후 1회 발송하는 구매 확인 안내입니다. 마이페이지에서 알림 수신 번호를 직접 등록한 회원에게만 보냅니다. 광고 내용은 없습니다.

---

## ② 문의 답변 — 템플릿 이름 `1:1 문의 답변 안내`

```
[만트라 포춘] 1:1 문의 답변 안내

남겨 주신 1:1 문의에 답변이 등록되었습니다.

· 문의 제목: #{제목}
· 답변 일시: #{일시}

아래 버튼을 눌러 마이페이지에서 답변을 확인해 주세요.
```

**버튼**

| 버튼 이름 | 링크(모바일·PC 같게) |
|---|---|
| 답변 확인하기 | `https://mantrafortune.com/report/my/` |

> 마이페이지 문의 목록 주소(`/report/#/me?inq=list`)는 `#`이 들어가 카카오 링크 검수에서 문제 될 수 있어 '내 구매 내역' 주소로 둔다. 그 화면 위 메뉴에서 마이페이지로 이동할 수 있다. 검수에서 `#` 주소가 허용되면 바꿔도 된다.

**검수 메모**
> 회원이 직접 남긴 1:1 문의에 운영자가 답변을 등록하면 1회 발송합니다. 답변 내용은 마이페이지에서 확인합니다. 광고 내용은 없습니다.

---

## ③ 만료 예고 — 템플릿 이름 `이용 기간 만료 예정 안내`

```
[만트라 포춘] 이용 기간 만료 예정 안내

구매하신 상품의 이용 기간이 곧 끝납니다.

· 상품: #{상품}
· 이용 기간: #{기한}까지

기간이 지나면 해당 풀이를 다시 볼 수 없습니다.
기간 안에 필요한 내용을 확인해 주세요.
```

**버튼**

| 버튼 이름 | 링크(모바일·PC 같게) |
|---|---|
| 내 구매 내역 | `https://mantrafortune.com/report/my/` |

**검수 메모**
> 구매한 디지털 콘텐츠의 이용 기간(결제일로부터 12개월)이 끝나기 30일 전에 1회 발송하는 계약 이행 안내입니다. 재구매 권유나 할인 등 광고 내용은 넣지 않습니다.

> 재구매 권유("다시 구매하세요", 할인 안내)를 넣으면 광고로 반려된다. 넣지 말 것.

---

## 켜는 순서

1. 위 세 템플릿을 등록하고 검수를 받는다.
2. Supabase에 마이그레이션 `supabase/migrations/20261127_kakao_notice.sql`을 적용한다(운영 DB 변경 — 승인 필요). 먼저 Vault에 `cron_secret`을 만든다.
3. Cloudflare Pages Secret을 넣는다.
   - 공통: `SOLAPI_API_KEY`·`SOLAPI_API_SECRET`·`SOLAPI_PFID`·`SOLAPI_SENDER`
   - 템플릿 ID: `SOLAPI_TPL_PAID`·`SOLAPI_TPL_ANSWER`·`SOLAPI_TPL_EXPIRE`
   - `CRON_SECRET`: Vault `cron_secret`과 같은 값
   - `KAKAO_CHANNEL_URL=https://pf.kakao.com/_QxhxgvX`(마이페이지 '채널 추가하기' 버튼)
4. 개인정보처리방침에 '알림 수신 번호(선택)' 항목을 추가한다. 항목·목적·보유 기간 문안은 아래 내용으로 한다.
   - 항목: 휴대폰 번호(선택)
   - 목적: 구매·문의 답변·이용 기간 안내 알림톡 발송
   - 보유 기간: 알림 해제 또는 탈퇴 시 즉시 삭제
   - 위탁: 메시지 발송 — (주)솔라피, 카카오
5. 위 Secret 중 템플릿 ID가 하나라도 들어가면 마이페이지에 '카카오톡 알림 받기' 카드가 나타난다.
