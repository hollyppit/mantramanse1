2026-11-19: 정기결제는 결혼중개업 등록 뒤에 신청하기로 해서 공개 약관에서 뺐다. 등록 후 정기결제를 열 때 아래 문구를 되돌려 넣는다.

## terms.html 제6조의2 끝에 추가
```html
      <li><b>자동 충전(정기결제)</b>: 회원은 충전 화면에서 카드를 등록하고 충전할 묶음, 기준 잔액, 한 달 최대 결제 횟수를 정해 자동 충전을 신청할 수 있습니다. 신청하면 크레딧 잔액이 기준 개수 미만이 될 때마다 별도 확인 없이 등록한 카드로 그 묶음을 1회 결제하며, 한 달(한국 시각 기준 매월 1일~말일) 결제 횟수는 회원이 정한 최대 횟수를 넘지 않습니다. 회사는 신청·변경·결제·해지 때마다 회원의 이메일로 내용을 알립니다.</li>
      <li>회원은 언제든 충전 화면에서 자동 충전을 잠시 끄거나 해지할 수 있으며, 해지하면 등록한 카드 정보(결제 대행사가 발급한 빌링키)를 즉시 삭제하고 더 이상 결제하지 않습니다. 결제가 연속 3회 실패하면 회사는 자동 충전을 멈추고 회원에게 알립니다. 회원 탈퇴 시 자동 충전은 자동으로 해지됩니다.</li>
      <li>자동 충전으로 결제한 크레딧의 청약 철회·환불은 일반 구매와 같습니다(제7조, 환불정책).</li>
```

## refund.html 1-2 끝에 추가
```html
      <li><b>자동 충전</b>으로 결제된 크레딧도 결제 건마다 위와 같은 기준(7일 이내·미사용이면 전액)으로 환불합니다. 자동 충전은 충전 화면에서 언제든 해지할 수 있고, 해지한 뒤에는 결제되지 않습니다.</li>
```

## products.html 인연의 광장 크레딧 문단 뒤
```html
    <p><b>자동 충전(정기결제, 선택)</b>: 카드를 등록해 두면 크레딧 잔액이 정한 개수 미만이 될 때마다 고른 묶음을 자동 결제합니다. 한 달 최대 결제 횟수(1~5회)를 회원이 정하며, 결제할 때마다 메일로 알리고, 충전 화면에서 언제든 끄거나 해지할 수 있습니다. 해지하면 등록한 카드 정보(빌링키)를 바로 지웁니다.</p>
```
