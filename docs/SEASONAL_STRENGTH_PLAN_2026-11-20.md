# 계절·월령 중심 오행 세력 엔진 + 운 중첩 그래프 — 구현 보고 (2026-11-20)

요구서 두 건(① 오행 강약 엔진 고도화, ② 계절 가중 오행 비율·대운~일진 중첩 그래프)을 구현했다.

**사용자 결정**
- 새 세력을 강약·용신 판정에 바로 반영한다.
- 왕상휴수사 계수는 설정값으로 두고 '앱 참고 모델'로 표시한다.

## 1. 바꾼 구조

### 1-1. 엔진(`engine.js`)

| 항목 | 내용 |
|---|---|
| `SEASONAL_CFG` | 학파·모델마다 다른 값을 모두 모은 설정. `seasonMode`(사계월 처리), `ws`(왕상휴수사 계수), `rootless`(뿌리 없는 천간), `rel`(충형파해), `johuInWeights`(조후를 세력에 섞을지) |
| `monthCommand(ch)` | 월령 오행을 정한다. 寅卯·巳午·申酉·亥子는 계절 오행이다. 辰未戌丑은 기본 `tuwang18`: 월률분야 표에서 여기·중기 12일이 지난 정기 18일은 토왕용사(土), 그 전은 계절 오행. 절입 시각 기준 경과 일수를 쓴다 |
| `wangsangOf(오행, 월령)` | 요구서 표 그대로: 같음 왕 · 월령이 생함 상 · 내가 월령을 생함 휴 · 내가 월령을 극함 수 · 월령이 나를 극함 사 |
| `MODELS.season` | 새 기본 모델 '월령·왕상휴수사'. 화면 여러 곳이 `model:'season'`을 넘기므로 이름은 그대로 두고 계산만 바꿨다 |
| `MODELS.season1` | **이전 기본 계산을 그대로 보존**('월령 가중(이전 방식)'). f69cd50 엔진의 `season`과 같은 값임을 테스트로 확인한다 |
| `elementWeights` | `season` 모델이면 아래 1-2의 계산식을 쓰고, 결과에 `seasonal`(세 지표·근거 로그)을 붙인다 |

### 1-2. 계산식 (`season` 모델)

글자마다 다음 값을 곱한다.

- 천간: `궁성 계수 × 왕상휴수사 계수(그 천간 오행) × (지장간에 같은 오행이 없으면 0.8)`
- 지지: `궁성 계수 × (월지면 2) × 충형파해 계수 × Σ(지장간 비율 × 왕상휴수사 계수(그 지장간 오행))`
- 합화: 기존 규칙 그대로(조건 6가지, 25%/50% 이동). 옮겨 간 몫은 옮겨 간 오행의 왕상휴수사를 따른다.
- 조후 계수: 새 모델에서는 끈다(`johuInWeights:false`). 조후는 기존 `climate()`·조후 용신 판정에서 따로 본다(요구서 4항 A/B 분리).
- 강약(돕는 힘 = 비겁+인성 비율)·득령·득지·득세·통근 분석·통합 용신 판정 함수는 바꾸지 않았다. 입력 비율만 새 세력으로 바뀐다(요구서 5항: 세력 계산 → 희기 판정 순서).

| 설정값(기본) | 근거 |
|---|---|
| 왕 1.2 · 상 1.1 · 휴 1.0 · 수 0.9 · 사 0.8 | 왕>상>휴>수>사 순서는 고전 기준. 0.1 간격과 '휴 = 1.0'은 앱 참고 모델이다. 크기 범위는 이전 조후 계수(0.85~1.15)와 맞춤 |
| 뿌리 없는 천간 ×0.8 | 앱 참고 모델(허부·무근 천간을 약하게) |
| 충 ×0.85 · 형·파·해 ×0.95 | 앱 참고 모델. 한 지지가 여러 관계에 걸리면 곱한다 |
| 사계월 `tuwang18` | 월률분야 일수(여기·중기 12일 + 정기 18일)와 같은 경계 |

### 1-3. 세 지표 (`ch.weights.seasonal`)

- `appearance` ① 출현량: 여덟 글자와 지장간 비율만 센 값(계수 없음)
- `seasonalPct` ② 계절 세력: 월지 2배와 왕상휴수사만 반영
- `finalPct` ③ 최종 세력: ②에 뿌리·충형파해·합화·궁성까지 반영한 값. `ch.weights.pct`와 같고, 판정에 쓴다
- `command`(월령과 그 근거), `states`(오행별 등급·계수), `rootless`, `relations`, `cfg`
- `trace`: 글자마다 근거 한 줄(예: `월지 卯 월령 ×2 — 乙 100% 왕 · 午卯파 ×0.95`)

### 1-4. 운 중첩(`luck-overlay.js`, 기본 방식 = 계절 재분석)

이전 셈법(더해 쌓기)은 `compute(..., {mode:'additive'})`로 남겼다.

새 방식은 단계(대운 → 세운 → 월운 → 일진)마다 원국과 그때까지의 운 기둥 전체를 놓고 다음을 다시 계산한다.
- 관계: `relationsAmong`으로 다시 찾는다.
- 뿌리: 운 지지가 원국 천간의 뿌리가 되는지 다시 본다.
- 충형파해: 운이 끼면 그 운의 층 무게만큼만 반영한다.
- 월령 왕상휴수사:
  - 대운·세운: 원국 월령 그대로(요구서 6항)
  - 월운·일진: 그달(그날) 절입 기준 월령. 태어난 계절을 통째로 바꾸지 않도록 월운 층 무게(0.4)만큼 반영한다.

층 데이터 구조(층마다):

| 필드 | 뜻 |
|---|---|
| `pct` | 그 단계 최종 오행 비율 |
| `delta` | 바로 아래 단계 대비 증감 |
| `vsNatal` | 원국 대비 증감 |
| `add` | 이 층에서 늘어난 운 몫(층별 증가분) |
| `parts.luck` | 누적 운 몫 |
| `parts.natalShift` | 운 때문에 원국 글자의 뿌리·충형이 바뀐 몫 |
| `parts.seasonShift` | 월령이 바뀐 몫 |
| `parts.hwa` | 합화 이동 |
| `season` | 그 단계 월령·근거·오행별 등급 |
| `rootGain` | 운으로 새로 뿌리가 생긴 원국 천간 |
| `relHits` | 충형파해에 걸린 자리와 계수 |

출현 개수(`vec`: 운 기둥 천간 1 + 지지 1)와 세력 변화(`parts`)는 따로 둔다.

`ten-god-roles.js`(십성 작용 판정)는 겹쳐 보기의 최종 비율을 그대로 쓴다. 오행 안 두 십성은 원래 몫 비율대로 나눈다.

### 1-5. 화면

- 만세력 **오행·강약** 탭에 '계절·월령으로 본 오행 세력' 카드를 추가했다.
  - 월령과 근거, 득령/실령, 강약
  - 오행별 표: 왕상휴수사(계수)·①·②·③·③−①·통근·투간·희기 역할
  - 뿌리 없는 천간과 충형파해 목록
  - 접은 '계산 근거 보기'(글자별 로그와 설정값)
  - 모델 고르기에 '월령 가중(이전 방식)'도 남겼다.
- **운세 흐름** 겹쳐 보기(만세력 `olBox`, 공용 `luck-layers-view.js`):
  - 층마다 '월령 ○ 기준 왕상휴수사 · 원국 ○에 뿌리 생김 · 원국 대비 ○±' 한 줄을 붙였다.
  - 막대의 원국 몫에 운 때문에 바뀐 몫을 반영했다.
  - 셈법 설명을 새 방식으로 고쳤다.
  - 월운·일진 층에는 고른 날짜를 넘겨, 사계월 토왕용사까지 맞게 계산한다.
- 기존 화면 구성·스위치(겹쳐 보기 `luckOverlay` 등)는 그대로다.

## 5. 남은 것 / 하지 않은 것

- 계수 조정 화면이 없다. 설정은 `engine.js`의 `SEASONAL_CFG` 상수다. 관리자 화면에서 바꾸려면 별도 작업이 필요하다.
- 암합(지장간끼리의 합)은 여전히 계산하지 않는다.
- 투간은 표시와 '뿌리 없는 천간' 판정에만 쓰고, 따로 가산하지 않는다(이중 가중 방지).
- 대운의 '천간 앞 5년 · 지지 뒤 5년' 나누기는 하지 않았다(이전과 같음).
- 경계선 실패로 남은 것: `signal-sim`(직업 지표 '무난' 비율 28%, 목표 29~51%). 지장간 정정 때부터 경계에 걸려 있던 분포 검사다.
