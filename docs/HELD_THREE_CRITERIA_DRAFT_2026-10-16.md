# 보류 3개 판정 명세 초안 v0.1

상태: 연구용 초안 / 운영 미연결 / 게시 불가. 작성일 2026-10-16.

대상: D27-20261016-L-male-over, D27-20261016-L-female-over, D27-20261016-M-risk.

이 문서는 원문의 상대적 세력 개념을 기존 엔진의 비중 수치와 동일하다고 가정하지 않는다. 실행 가능한 부분은 기존 모델 후보를 분류하는 오프라인 연구용 선별기다. 모든 반환값은 publishable=false, traditionalVerdict=unvalidated다. candidate도 게시·전통 판정 통과를 뜻하지 않는다. 운영의 기존 3개 review 규칙과 계산 엔진은 변경하지 않았다.

## 2. 입력 계약

필수 입력은 ruleId, 명시적 gender(M/F), hourKnown, groupPct, helpPct, context, alternatives다. 입력값의 출처는 원국 계산 옵션과 함께 기록해야 한다. 성별 누락을 남성으로 기본 처리하지 않는다. 성별이 원문 배속 범위 밖이면 not-candidate로 반환한다. 시주 미상은 unknown이다.

groupPct는 재성/관성 해당 군, helpPct는 비겁군+인성군이다. 둘은 같은 모델·같은 원국의 원시 ch.weights.groups에서 가져온다. 개별 tenGods의 다른 분모와 혼합하지 않는다. 유한한 0~100 숫자여야 하고 두 비중의 합은 100을 넘을 수 없다(부동소수점 오차 1e-8만 허용). 이 오차 허용은 명리 임계값이 아니다.

sd.groups는 소수점 한 자리로 반올림되므로 판정 입력에 쓰지 않는다. 기본 모델은 season이며 alternatives에는 hidden, simple8을 각각 한 번씩 요구한다. 다른 모델의 도움도 해당 모델의 비겁+인성으로 다시 합산한다.

context에는 deukryeong, deukji, deukse, hasRoot, methodConflict, specialStructure의 boolean이 필요하다. 누락은 false로 추정하지 않고 unknown이다. 기존 strength.deukji는 일지 본기 생조 여부이며 정밀 통근 점수와 다르다. 엔진은 득령·득지·득세를 반환하지만 도움 비중 zone 계산에 이 세 값을 별도 가산하지 않는다. 이 기록들을 임의 점수로 합산하지 않는다.

methodConflict 또는 specialStructure가 true이면 전문 검토 대상으로 유보한다. 두 값은 이번 명세가 자동 판정하지 않는다. 실험자가 근거를 남겨 입력해야 하며, false를 기본값으로 운영에 사용해서는 안 된다.

## 3. 규칙별 절차

### L-male-over / L-female-over

1. 입력 계약과 원문 성별 범위를 확인한다.
2. 각 모델에서 해당 군 >=30 AND 도움 <42를 계산한다. strong >=28은 별도 관측값일 뿐 후보 선별을 대체하지 않는다.
3. 모델 간 결과가 다르면 unknown(model-sensitive).
4. 모두 참이면 candidate(existing-engine-screen-only), 모두 거짓이면 not-candidate(outside-existing-engine-screen).
5. 어느 경우에도 원문의 상대적 과다를 확정하지 않는다. 잘못된 성별, 시주 누락, 구조 정보 누락, 경계 수치, 모델 변동을 구별해 사유를 남긴다.

후보는 검증 표본을 수집하기 위한 분류다. 감정적 압박, 상대 행동, 관계 사건을 예측하거나 출력하는 기능은 없다. not-candidate 역시 실제 관계 문제가 없다는 판단이 아니다.

### M-risk

공통 계약에 더해 targetYear 정수, 동일 연도의 annual.year, 그 연도를 포함하는 대운 startYear/endYear, 세운·대운 각각의 천간/지지 십성이 필요하다. 정보 누락·다른 연도·대운 기간 불일치는 unknown이다.

기간이 맞더라도 annual-composition-unspecified로 unknown을 반환한다. 원국 재성 비중에 세운 천간을 더하거나 연간 가중치를 임의 설정하지 않는다. 대운+세운의 합충형·통근·조후와 실제 일간 지원 변화를 합성하는 규격이 없으므로 연도 과다와 회복을 계산하지 않는다. 시간 정보를 갖췄다는 사실만으로 게시 가능하게 바뀌지 않는다.

## 4. 게시 전 필요한 후속 검증

| 단계 | 이번 결과 | 통과 조건 |
|---|---|---|
| 소프트웨어 계약 | 통과 | 누락·성별·경계·모델 충돌·기간 불일치·게시 차단 동작 |
| 기존 엔진 재현 | 통과 | 합성 표본에서 원시 값 선별과 실제 패턴 존재 일치 |
| 원문↔수치 동등성 | 미검증 | 상대 세력을 판단하는 독립 명세와 근거를 정하고, 엔진 수치로부터 독립적으로 판정한 대조 명조 확보 |
| 조후·통근·특수구조 예외 | 미검증 | 예외 처리의 필요·충분조건과 충돌 우선순위 명시 |
| 시운 합성 | 미정 | 대상 연도 전체 작용과 일간 감당 능력의 입력·계산·회복 조건 정의 |
| 독립 표본 평가 | 미수행 | 기준 확정 후 학습/조정용과 평가용 명조를 분리하고, 판정 불일치·위양성·유보율·경계 민감도 보고 |
| 게시 결정 | 보류 | 위 미검증 항목 해결 및 별도의 검수. 이번 테스트 성공만으로 게시 금지 |

표본 정답을 현재 엔진의 동일 임계값이나 동일 패턴에서 가져오면 순환 검증이다. 독립 검토자는 상대 세력 판단 근거와 불확실성을 기록해야 한다. 최소 표본 수·허용 오차·평가 기준도 검토 전에 정해야 하며, 이번 문서는 근거 없는 숫자로 합격선을 만들지 않는다. 전통적 구조 판정 일치와 실제 관계·손익 예측 정확도는 서로 다른 검증이다.
