# 운세 환경 해석·나의 운명 지도 — 배포 전 점검 및 롤백 절차 (2026-11-02)

이 문서는 로컬 구현 기준입니다. **운영 배포·DB 변경은 아직 하지 않았고, 사용자 승인 전에는 하지 않습니다.**
아래 "실행 전 기록" 항목은 배포 직전에 운영자가 채워야 하며, 이 저장소에서는 확인할 수 없습니다.

## 2. 실행 전 기록 (배포 직전에 채우기)

- 비밀 값(ADMIN_PASSWORD 등)은 이 문서·저장소에 기록하지 않습니다.

## 3. 기능 끄기 (가장 빠른 대응, DB 변경 없음)
`feature-flags.js`의 값을 `false`로 바꿔 배포하면 해당 기능만 화면에서 사라집니다. 기존 만세력·결제·무빙툰에는 영향이 없습니다.
- `interpret` — 환경 해석 카드, `timeline` — 환경 변화 타임라인, `region` — 나의 운명 지도 카드.
- 관리자 탭 2개는 사용자에게 보이지 않으므로 끌 필요가 없습니다(관리자만 접근).

## 4. 프런트엔드 롤백 (Cloudflare Pages)
1. 신규 기능 추가 변경을 중지합니다.
2. Cloudflare Pages → 해당 프로젝트 → Deployments에서 **2번에서 기록한 이전 정상 배포**를 "Rollback to this deployment"로 되돌립니다(또는 이전 커밋으로 `git revert` 후 `main` 푸시).
3. 운영 사이트에서 확인: 만세력 입력→원국 표시, 운세 흐름 탭, 무빙툰(`/report/`), 관리자(`/report/admin/`) 로그인.
4. 원인과 복구 결과를 기록합니다.
- 프런트 롤백은 KV 값을 지우지 않습니다. 이전 코드는 새 KV 키를 읽지 않으므로 남아 있어도 무해합니다.

## 5. 데이터 롤백 (KV, Supabase 아님)
- **지역 자료:** 관리자 "지역 데이터" 탭의 변경 이력에서 항목별로 "이 변경 되돌리기". 전체 삭제는 KV 키 `region:facts` 삭제(이 키만 영향, 화면은 "자료 부족"으로 돌아감).
- **문구:** 관리자 "운세 환경 문구" 탭에서 "게시 취소" 또는 이력 복원. 전체 삭제는 KV 키 `luckenv:phrases` 삭제(화면은 코드의 기본 문구로 돌아감).
- 두 키는 새로 만들어지는 값이라 백업 이후 사용자 데이터와 섞이지 않으므로, 삭제해도 회원·결제·리포트 데이터에는 영향이 없습니다.
- **Supabase 전체 복원은 필요하지 않고 권장하지 않습니다**(이번 작업은 Supabase를 바꾸지 않음).
