# 사주 격국 분석 카드 설계 (2026-11-15)

오행·강약 탭의 '십성 분포·신강신약' 카드 바로 아래에 **사주 격국 분석** 카드를 추가한다.
판정 엔진은 독립 모듈 `gyeok-structure.js`(`MantraGyeokStructure.analyze(Manse, chart)`)이며 **표시 전용**이다.
신강신약·용신(통합 판단 포함)·오행 비율·운세 점수 산식은 바꾸지 않는다(엔진 기준선 `tests/engine-baseline-sim.js` 불변).

## 0. 기존 코드와의 관계

| 기존 | 하는 일 | 이번 작업에서 |
|---|---|---|
| `engine.js gyeokCore` | 자평진전식 취격(투출 정기→중기→여기, 없으면 정기)·상신/파격/구응 → **통합 용신 점수에 쓰임** | 읽지도 바꾸지도 않음. 취격 순서만 **같은 규칙**으로 맞춰 용신 탭과 이름이 어긋나지 않게 함 |
| `gyeokguk.js` | gyeokCore 의 화면 설명판(용신 탭 '학파별 표·격국 판단' 카드) | 그대로 둠. 관리자 화면에서 새 판정과 나란히 비교 |
| `engine.js jongCore` / `jonggyeok.js` | 종격·전왕(종왕·종강) 판정(충족·가능성·보류) | 종격 판정은 `M.jongCore` 결과를 **그대로 읽어** 재사용(기준값 이중 관리 방지) |
| `byeongyak.js` | 병약 용신 | 관계 없음(용신 탭) |
| `engine.js patterns` | 관살혼잡·상관견관 등 '있음' 수준 태그 | 재사용하지 않음. 새 모듈은 성립·불성립·예외를 따로 판정 |
| `ch.saryeong` | 절입 후 일수로 본 사령 지장간 | 복수 투출의 동점 해소·근거 표시에만 사용 |

새 모듈이 따로 있는 이유: 기존 격국 판정은 용신 계산의 입력이라 규칙을 바꾸면 운세 점수가 바뀐다. 이번 카드는 합거·월령 충·복수 후보·판정 유보·특수격·오행 구조·십성 작용을 분리해 보여 주는 **해석 층**이므로 계산 층과 분리한다.

## 1. 네 가지 분류 체계(서로 섞지 않음)

| 체계 | 무엇을 보나 | 출력 개수 |
|---|---|---|
| A. 기본 격국(정격) | 월령 지장간의 투출로 정한 격 1개 + 격의 안정성 | 대표 1개(충돌 시 '복수 후보', 근거 부족 시 '판정 유보') |
| B. 특수격(외격) | 화격(化氣格)·전왕 1행격(곡직·염상·가색·종혁·윤하)·종격(종아·종재·종살·종왕·종강) | 성립하면 대표로 올림, 가능성만 있으면 유보 안내 |
| C. 특수 오행 구조 | 금수쌍청·목화통명·수화기제·수화상전·화염토조·금한수냉·모왕자쇠(토다금매 등) | B·D 와 합쳐 주요 항목 1~3개 |
| D. 십성 작용 | 관인상생·살인상생·식신제살·식상생재(식신/상관생재)·상관패인·재생관 / 상관견관·관살혼잡·군겁쟁재·효신탈식·재다신약·관살태과 | C 와 합쳐 주요 항목 1~3개 |

C·D 는 '흐름(도움이 되는 연결)'과 '부담(조심할 연결)' 두 성격으로 나누되, 길흉으로 단정하지 않는다.

## 2. 공통 측정값

- **십성 힘 단계(0~3)**: 기존 gyeokguk.js 와 같은 식. 천간 투출(년 0.8·월 1·시 0.8) + 지장간(자리 년 0.6·월 1·일 0.9·시 0.7 × 정기 1·중기 0.55·여기 0.35).
  투출+통근(지장간 합 ≥0.5)=3, 투출 없이 월령 정기=3, 투출만 또는 지장간 ≥0.9=2, 조금이라도 있음=1, 없음=0. 십성 비율 3% 미만이면 최대 1.
- **묶음 단계 gl(g)**: 같은 묶음 두 십성 중 큰 값(비겁·식상·재성·관성·인성).
- **오행 비율**: `ch.weights.pct`(현재 선택 모델), 묶음 비율 `ch.weights.groups`, 돕는 힘 `ch.strength.help`.
- **통근**: `M.analyzeNatalRoot(ch).natalRootScore`.
- 판정 기준이 학파마다 갈리는 곳은 아래 **[기준]** 으로 하나를 정하고 모든 사주에 똑같이 쓴다.

## 3. A. 기본 격국(정격)

### 3-1. 취격(격 정하기)
1. 월지 지장간을 정기 → 중기 → 여기 순으로 본다.
2. 년간·월간·시간에 **같은 글자**로 드러난 것(투출)을 그 순서로 먼저 취한다. **[기준]** 자평진전식 '투출 우선', 엔진 gyeokCore 와 동일.
3. 투출이 없으면 정기를 취한다(‘월령 본기 취격’).
4. 정기가 비견이면 **건록격**, 겁재면 양간 **양인격**·음간 **월겁격**. 이때 격의 쓰임(격용)은 천간에 드러난 재·관·식상 중 힘이 큰 것.
5. 일간 자신의 글자는 투출로 세지 않는다(일간은 격의 주인).

### 3-2. 성립 판정(establish) — 격이 '서는가'
| 결과 | 조건 |
|---|---|
| 성립 `firm` | 취한 글자가 **월간**에 투출했거나, 년·시간 투출 + 지지 통근(그 십성 힘 3) |
| 약하게 성립 `weak` | 투출 없이 정기로 취격(월령 본기), 또는 년·시간 투출이지만 통근이 약함 |
| 복수 후보 `multi` | 아래 '기준 충돌' 중 하나 |
| 판정 유보 `hold` | 아래 '근거 부족' 중 하나 |

**기준 충돌 → 복수 후보**
- 子午卯酉(왕지) 월인데 정기가 아닌 글자만 투출(예: 午월 己 투출, 丁 미투출). 투출 우선 기준으로는 중기·여기 격, 왕지 정기 기준으로는 정기 격.
- 정기가 투출하지 않았고 중기·여기가 **둘 다** 투출(사령 글자가 그중 하나면 사령 글자를 대표, 아니면 중기 대표).
- 월지가 삼합·방합으로 다른 오행 국(局)을 이루고, 그 국 오행의 십성이 천간에 투출(국의 기운이 월령을 바꿀 수 있음).

**근거 부족 → 판정 유보**
- 취한 투출 글자가 일간이 아닌 다른 천간과 **천간합(합거)** 되고 다른 투출 후보가 없음 → 격신이 묶여 격을 세우기 어렵다.
  **[기준]** 합거는 붙어 있는 자리(년-월·월-일·일-시)의 천간합만 본다. 년간-시간처럼 떨어진 합(요합)은 힘이 약해 합거로 보지 않는다.
  같은 글자가 여러 자리에 투출했으면 모든 자리가 합거될 때만 합거로 본다.
  다른 후보가 있으면 다음 후보로 넘기고 '합거로 다음 후보 취격'을 근거에 남긴다.
- 월지가 **충**을 받고 투출이 없음(월령 본기마저 흔들림).
- 건록·양인·월겁격인데 격용(재·관·식상)이 천간에 없음.
- 시주를 모르고, 투출이 없거나 투출 위치가 시간뿐(시간 글자가 격을 바꿀 수 있음).

**예외**
- 일간과의 천간합(합아, 예: 甲일간 + 己 정재 투출)은 합거로 보지 않는다. 격은 유지하고 근거에 '일간과 합'을 적는다.
- 월지 육합은 격을 바꾸지 않는다(참고 근거만). 충은 안정성(3-3)의 파격 요인으로 반영.

### 3-3. 안정성 판정(stability) — 선 격이 '잘 짜였는가'
성립과 별개로 본다. 성립이 `hold` 면 안정성도 `hold`.
격마다 **상신(돕는 것)·파격 요인(깨는 것)·구응(깨는 것을 막는 것)** 규칙표(gyeokCore 와 같은 표)에 아래 합충 요인을 더한다.

| 격 | 상신 | 파격 요인 → 구응 |
|---|---|---|
| 정관 | 재생관(재), 관인상생(인) | 상관견관 → 상관패인(인) / 관살혼잡 → 식신제살 / 월지 충·형 |
| 편관 | 식신제살, 살인상생 | 재자약살(재 강·식신 없음) → 인성 / 관살혼잡 → 식신제살 / 효신탈식 → 재제효 |
| 정재·편재 | 재생관, 식상생재 | 비겁탈재 → 관성 / 월지 충·형 |
| 식신 | 식신생재, 식신제살 | 효신탈식 → 재제효 |
| 상관 | 상관생재, 상관패인 | 상관견관 → 상관패인 |
| 정인 | 관인상생 | 재파인 → 비겁 / 인다 → 재성 |
| 편인 | 살인상생, 재제효 | 도식 → 재제효 |
| 건록·양인·월겁 | 관성 제어, 재성 활용, 식상 설기 | 격용 없음 / (양인) 관살 없음 |
| 공통 추가 | — | 월지 충 → 월지가 다른 지지와 육합·삼합·방합을 함께 이루면 구응(탐합망충) |

- **[기준]** 월령을 깨는 요인은 **충만** 센다. 두 글자 형(丑戌·寅巳 등)은 삼형이 다 갖춰지지 않은 경우가 많아 근거 칸에 참고로만 적는다.
- 격신 합거는 성립 단계(3-2)에서 이미 다음 후보로 넘기거나 유보하므로 안정성에서 다시 세지 않는다.

| 결과 | 조건 |
|---|---|
| 안정(성격) `seong` | 상신 1개 이상, 남은 파격 요인 없음 |
| 구응으로 유지 `rescued` | 파격 요인이 있으나 모두 구응됨 |
| 보통 `plain` | 상신도 파격 요인도 뚜렷하지 않음 |
| 불안정(패격) `pa` | 구응 없는 파격 요인이 남음 |
| 유보 `hold` | 성립 유보, 또는 시주를 몰라 시간 글자가 성패를 좌우할 수 있음 |

## 4. B. 특수격(외격)

### 4-1. 화격(化氣格) — 일간이 합으로 다른 오행이 됨
일간 합 짝: 甲己→토, 乙庚→금, 丙辛→수, 丁壬→목, 戊癸→화.
| 조건 | 기준 |
|---|---|
| ① 일간이 **월간 또는 시간**(붙어 있는 자리)과 합 | 필수 |
| ② 월령이 화신(化神) 오행 | 월지 정기 오행 = 화신, 또는 월지가 화신 오행의 삼합·방합에 참여 |
| ③ 화신 오행 비율 ≥ 35% | |
| ④ 일간 원래 오행의 뿌리가 약함 | 통근 점수 ≤ 15 |
| ⑤ 화신을 극하는 오행이 천간에 없음 | |
| ⑥ 쟁합·투합 없음 | 같은 짝 글자가 둘 이상이면 불성립 |
- 성립: 전부 충족. 가능성(유보): ①·② 충족 + 나머지 중 3개 이상. 그 외 불성립.
- 시주를 모르면 성립·가능성을 유보로 낮춤(시간이 합 짝이거나 극하는 글자일 수 있음).

### 4-2. 전왕 1행격 — 한 오행이 사주를 채움
일간 오행별 이름: 목 곡직격, 화 염상격, 토 가색격, 금 종혁격, 수 윤하격.
| 조건 | 기준 |
|---|---|
| ① 월령이 일간 오행 | 월지 오행 = 일간 오행(토는 辰戌丑未) |
| ② 지지가 일간 오행으로 모임 | 일간 오행의 방합·삼합(반합 제외)이 있거나, 지지 정기가 일간 오행인 곳 ≥ 3 |
| ③ 일간 오행 비율 ≥ 50% | |
| ④ 관성(일간을 극하는 오행)이 천간에 없고 비율 < 8% | |
| ⑤ 돕는 힘 ≥ 65% | |
- 성립: 전부. 가능성: ①·③·④ + 나머지 1개 이상. 시주 모르면 유보.

### 4-3. 종격 — `M.jongCore` 결과를 그대로 사용
- jin → 성립, ga → 가능성(가종, 유보로 표시), hold → 유보, none → 불성립.
- 이름: 종아·종재·종살(일간 극약), 종왕·종강(일간 극왕, 전왕 계열).

### 4-4. 특수격 우선순위와 정격과의 관계
1. **화격 > 전왕 1행격 > 종격** 순으로 성립한 것을 대표 특수격으로 둔다. 1행격과 종왕격이 함께 성립하면 1행격 이름을 쓰고 '종왕 계열'이라 적는다.
2. 대표 특수격이 **성립**하면 카드의 대표를 특수격으로 바꾸고, 정격은 '월령 기준 참고 격'으로 내린다.
   설명: "기운이 한쪽으로 쏠려 보통의 균형 잡기(정격·억부)보다 그 흐름을 따르는 해석을 앞세웁니다."
3. **가능성·유보**만 있으면 정격을 대표로 유지하고 '특수격 가능성 — 판정 유보'를 덧붙인다. 특수격을 억지로 붙이지 않는다.
4. 양신성상격·잡기격·일행득기 세부 변형 등 나머지 외격은 이번 범위에서 **판정하지 않는다**(문서·화면에 명시).
5. **예외**: 특수격이 성립하면 일간 강약 균형(억부)을 전제로 한 부담 항목(재다신약·관살태과·군겁쟁재·모왕자쇠)은 특수격 흐름과 모순되므로 주요 구조에서 뺀다. 상세 근거에는 '제외'와 이유를 남긴다.
6. 전왕 1행격은 돕는 힘 58% 이상(중화 상단 이상)일 때만 검토한다.

## 5. C. 특수 오행 구조
| 구조 | 성립 | 불성립·예외 | 성격 |
|---|---|---|---|
| 금수쌍청 | 일간 금·수, 금+수 ≥ 55%, 금·수 각 ≥ 15%, 금·수 모두 천간에 있음 | 화 ≥ 12% 또는 토 ≥ 15%(탁함) / **예외**: 금한수냉 조건(겨울·한난 ≤ −0.6·화 < 8%·천간 화 없음)을 갖추면 금한수냉으로 넘김(둘이 동시에 서지 않음) | 흐름 |
| 금한수냉 | 금+수 ≥ 55%, 亥子丑월, 화 < 8%, 한난 ≤ −0.6 | 화가 천간에 있으면 불성립(데워 줌) | 부담 |
| 목화통명 | 일간 목, 목 ≥ 20%, 화 ≥ 18% + 화가 천간에 투출 | 수 ≥ 15%(불을 끔) 또는 금 ≥ 15%(나무를 상함) | 흐름 |
| 수화기제 | 수·화 각 ≥ 18%, 차이 ≤ 12%p | 子午·巳亥 충이 있으면 수화상전으로 넘김 | 흐름 |
| 수화상전 | 수·화 각 ≥ 20%, 子午 또는 巳亥 충 | 목 ≥ 10%면 통관되어 불성립 | 부담 |
| 화염토조 | 화+토 ≥ 60%, 수 < 8%, 巳午未월 또는 한난 ≥ 0.6·조습 ≤ −0.6 | 수가 천간에 있으면 불성립 | 부담 |
| 모왕자쇠(토다금매·수다목표·목다화식·화다토초·금다수탁) | 일간을 생하는 오행 ≥ 40%, 일간 오행 ≤ 15% | 화다토초는 화염토조와 겹치면 화염토조만 표시 | 부담 |

## 6. D. 십성 작용
L(t) = 십성 힘 단계, gl(g) = 묶음 단계, G = 묶음 비율, help = 돕는 힘.
| 작용 | 성립 | 불성립·예외 | 성격 |
|---|---|---|---|
| 관인상생 | gl(관) ≥ 2, gl(인) ≥ 2, 정관 ≥ 편관, help < 70 | 재파인(gl(재)=3, G재 ≥ G인+15, 비겁 < 2) | 흐름 |
| 살인상생 | L(편관) ≥ 2, gl(인) ≥ 2, 편관 > 정관, help < 60 | 재성이 살을 키우며 인을 깸(gl(재)=3 & gl(인) < 3) | 흐름 |
| 식신제살 | L(식신) ≥ 2, L(편관) ≥ 2, L(식신) ≥ L(편관)−1 | 천간 편인이 식신을 막고(L(편인) ≥ 2) 재성 구응 없음 | 흐름 |
| 식상생재(식신생재·상관생재) | gl(식상) ≥ 2, gl(재) ≥ 2, help ≥ 30 | 효신탈식(천간 편인 ≥ 2, 재 < 3) | 흐름 |
| 상관패인 | L(상관) ≥ 2, gl(인) ≥ 2, G식상 ≥ 15, help ≤ 65 | 재파인 | 흐름 |
| 재생관 | gl(재) ≥ 2, gl(관) ≥ 2, help ≥ 35 | 상관견관이 풀리지 않음 | 흐름 |
| 상관견관 | L(상관) ≥ 2, L(정관) ≥ 2 | 인성 ≥ 2(패인) 또는 재성 ≥ 2(생재로 전환)이면 해소 | 부담 |
| 관살혼잡 | 정관·편관 모두 천간에 드러나고 L ≥ 2 | 식신제살 또는 편관 합거(합살)면 해소 | 부담 |
| 군겁쟁재 | G비겁 ≥ 35, gl(재) ≥ 1, G재 ≤ 25 | 관성 ≥ 2(비겁 제어) 또는 식상 ≥ 2(통관) | 부담 |
| 효신탈식 | 천간 편인 L ≥ 2, L(식신) ≥ 2 | 재성 ≥ 2(재제효) | 부담 |
| 재다신약 | G재 ≥ 35, help < 35 | 비겁 ≥ 2 | 부담 |
| 관살태과 | G관 ≥ 35, help < 35 | 인성 ≥ 2(받아 줌) | 부담 |

**상호 배타**: 관인상생/살인상생 중 하나, 상관패인이 서면 상관견관 해소, 식신제살이 서면 관살혼잡 해소.

**[기준] 흐름 작용 공통 조건**: 관인상생·살인상생·식신제살·식상생재·상관패인·재생관은 관여하는 두 십성 묶음 중 **하나 이상이 천간에 드러나야** 성립한다. 둘 다 지장간에만 있으면 작용이 흐릿해 세우지 않는다.

## 7. 주요 항목 고르기(C+D 합쳐 최대 3개)
점수 = 0.4×명확성 + 0.35×중요도 + 0.25×영향.
- 명확성: 십성 작용은 (두 십성 단계 합)/6 + 둘 다 천간이면 0.2. 오행 구조는 기준선 대비 여유(0~1).
- 중요도: 격신 묶음이 관여하면 +0.5, 월령(월간·월지)이 관여하면 +0.3, 일간 옆(월간·시간)이 관여하면 +0.2.
- 영향: 관여 묶음(오행) 비율 합 / 50(최대 1).
성립한 항목이 없으면 '주요 구조' 칸 자체를 출력하지 않는다.

## 8. 화면(오행·강약 탭)
순서: **대표 격국(가장 크게) → 주요 구조 → 종합 해석 → 상세 판정 근거**.
- 대표 격국: 이름·성립 칩·안정성 칩·한 줄 쉬운 설명. 특수격 성립 시 특수격이 대표, 정격은 '참고'.
- 각 항목(대표 격국·주요 구조)을 누르면 **성립 근거 / 원국에서의 작용 / 유리한 조건 / 불리한 조건** 네 칸을 생활밀착형 존댓말로 펼친다.
- 종합 해석: 격국과 주요 구조가 서로 어떻게 작용하는지 + '유리한 조건' / '주의할 조건' 두 칸.
- 상세 판정 근거(접힘): 취격 과정, 후보, 성립·안정성 판정 근거, 특수격 점검표, 오행 구조·십성 작용 점검표(성립·불성립 이유).
- 고지: 격국만으로 직업·재물·성격·길흉을 단정하지 않는다는 문장.
- PC는 2열 카드 그리드, 560px 이하에서 1열.

## 9. 표현 규칙
