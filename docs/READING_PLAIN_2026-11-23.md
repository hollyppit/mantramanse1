# 상세풀이 쉬운 말 · 용어 각주 · 시기표 (2026-11-23)

화면 코드만 바뀌어요. DB 게시본은 그대로라서 재게시가 필요 없고, 배포(main 푸시)는 승인 뒤에 해요.

## 1. 용어 각주
- 새 파일 `report/v2/term-notes.js`(표시), `report/v2/term-notes-data.js`(용어 240개, 생성기 `tools/build-term-notes.cjs`)
  - 뜻 출처: 만세력 용어 사전(index.html GLOSSARY의 명리 분야), "쉽게 읽기" 한 줄, 그리고 `terms.js`의 쉬운 뜻·"내 사주에서는" 한 줄
- `reading-text.js`가 장 HTML을 다 만든 뒤 `TermNotes.mark`를 부르면 이렇게 처리해요.
  - 장마다 같은 용어는 처음 한 번만 점선 단추로 만들어요.
  - 용어 뒤 괄호 뜻은 걷어요. 예: "대운(10년 단위의 흐름)" → "대운"(누르면 뜻이 떠요)
  - 이 사주의 값이 든 괄호(%·연도·~)는 남겨요.
  - 제목·단추·펼침 제목·그림 안은 건드리지 않아요.
  - 접힌 근거 안에서는 괄호를 걷은 자리만 단추로 만들어요.
  - 낱말 속이나 동사로 쓰인 경우(상관없이·무관해요·관대한·지지해)는 용어로 보지 않아요.
- 말풍선은 탭·클릭으로 열고, 다시 탭·바깥 탭·닫기·Esc·스크롤로 닫혀요. 모바일 375px에서 확인했어요.

전후 예시(DB 근거 문장, 화면에서):
- 전: 현재 대운(10년 단위의 흐름) 천간의 십성(나와 다른 글자의 관계)이 재성(편재·정재) 쪽이고, 원국(타고난 사주 여덟 글자)에서 재성의 세력이 중간이라…
- 후: 현재 [대운] [천간]의 [십성]이 [재성] 쪽이고, [원국]에서 재성의 세력이 중간이라… ([ ] = 누르면 뜻)

## 2. 시기표 카드 "시기별로 보면"
- `life-narrative.js`의 `periodCard`가 서사 장마다 카드를 만들어요(`res.card`).
  - 칸: 지나온 10년 · 지금(곧 끝나요) · 다음 10년(곧 들어와요) · 그다음 10년
  - 나이·연도·흐름은 `periods()`의 엔진 값만 써요.
  - 문장은 장 고유 `CH_LUCK`에서 가져오고, 없으면 주제별 대운 문장 앞 두 문장을 써요.
  - "전체 인생 흐름" 장은 모든 대운 칸을 보여 줘요.
- `reading-text.js`가 카드를 운 단계 자리에 그려요.
  - 카드가 다룬 대운 문단(지금 지나는…/곧 들어올…/YYYY년 무렵…)은 본문에서 빼요.
  - 해마다 짚는 문장, 오행 전략, 암합 문장은 남겨요.

전후 예시(1985-11-02 14시 여, 커리어 · 일하는 방식):
- 전(한 문단): 지금은 경인 대운이 저물고 신묘 대운으로 넘어가는 교운기예요(2027년 무렵 바뀌어요). … 곧 들어올 만 42~52세 신묘 대운을 일하는 방식의 흐름으로 보면, … 2037년 무렵(만 52~62세)부터는 …
- 후(카드):
  - 지나온 10년 · 만 22~32세 · 2007~2017년 · 무게 실림 — 숫자로 평가받는 일이 늘어나는 시기였어요.
  - 지금 · 곧 끝나요 · 만 32~42세 · 2017~2027년 · 좋고 나쁨 섞임 — 기준과 절차를 지켜야 하는 일이 늘어나는 시기예요. 모호한 지시는 한 줄로 정리해 확인받으세요.
  - 곧 들어와요 · 만 42~52세 · 2027~2037년 — 혼자 판단하고 직접 움직일 일이 늘어나는 시기예요. 결과 기준을 먼저 합의해 두세요.
  - 그다음 10년 · 만 52~62세 · 2037~2047년 — 새로 배워야 할 일이 늘어나는 시기예요. 공부할 범위를 먼저 정하세요.

## 3. 쉬운 말
- 포인트 블록(`reading-insight.js lifeFirst`): 12운성·십성 문단에서 생활 모습을 먼저 쓰고, 근거를 뒤에 붙여요.
  - 전: 년주의 12운성은 '건록'이에요. 년주는 어린 시절과 바깥에서 받는 첫인상을 비추는 자리예요. 건록은 스스로 서는 단단한 기운이라, 자립심이 강하고 내 힘으로 기반을 만들어 가요.
  - 후: 자립심이 강하고 내 힘으로 기반을 만들어 가요. 어린 시절·첫인상 자리(년주)에 스스로 서는 단단한 기운(건록)이 있어서예요.
- 재물 그릇 안내(`deep-wealth.js`)
  - "전통 규칙을 시각화한 서비스 내부 지표이며…" → "내 사주 안에서 견줘 본 값이라 실제 재산이나 수입 액수를 뜻하지는 않아요."
- `deep.js`: "서비스 내부 지표" → "참고 점수"
- DB 시기 문단(timing)의 "엔진이 계산… 말하지 않아요"는 게시 변환(`convert.mjs`)에서 빠져 화면에 나오지 않아요. 그래서 고칠 필요가 없었어요.
