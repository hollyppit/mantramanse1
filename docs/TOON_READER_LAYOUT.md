# 주제별 무빙툰 감상 창 개선

2026-10-18 운영 배포: `fb1aaacd`.

`report/v2/samsara.js`의 공통 감상 창에 `toon-reader.css`를 연결했다. 주제별 단편과 전생 무빙툰이 같은 개선을 사용한다. 풀이 본문·서사 생성·계산·미디어 설정은 변경하지 않는다.

- 영상/이미지: 상단 화면 높이의 25% (낮은 가로 화면은 22%).
- 본문: 어두운 단색 배경, 19~24px 글자, 위에서부터 표시, 독립 스크롤.
- 하단: 이전/다음 버튼, 현재 컷 번호, 자동 넘김 제어, 클릭 가능한 전체 컷 진행 바.
- 방향키·Home/End·좌우 스와이프를 지원한다. 수동 탐색 또는 본문 스크롤은 자동 넘김을 정지한다. 재생 토글은 읽던 스크롤 위치를 유지한다.
- 첫 컷의 이전 버튼은 비활성화, 마지막 컷은 감상 마치기. 종료 시 원래 포커스와 배경 스크롤 상태를 복원한다.

검증: `node tests/samsara-sim.js`, `node tests/toon-reader-browser.cjs`, `node tests/toon-reader-browser.cjs --deployed` (`TASK_PLAYWRIGHT` 필요).

실제 배포된 보고서 페이지의 공통 플레이어를 검증용 이야기로 열어 1440×1000, 390×844, 320×568, 844×390에서 비율·겹침·가로 잘림·버튼·방향키·컷 직접 이동·재생 토글의 스크롤 보존·닫기를 확인했다. 실제 사용자 풀이 생성은 실행하지 않았다. 증빙: `output/toon-reader/`.
