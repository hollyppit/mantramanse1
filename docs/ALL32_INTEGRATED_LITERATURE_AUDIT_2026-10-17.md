# 32개 표본 전체 — 기존 문헌 통합 검수 완료표

2026-10-17. 남은 검수 범위를 G17 한 경로에 한정하지 않고 원국 24건·연도 관찰 8건 전체로 넓혀 검토했다. 문헌 대조 범위 검수는 32건 완료했다. 전체 규칙 확정은 0건, 최종 유보는 32건이다. 검수 완료와 판정 확정은 다르다. 게시·운영 변경·외부 AI 호출 없음.

## 방법과 적용 범위

원자료와 문헌 지장간표, 출처 원장만 사용했다. 기존 엔진·모델 점수·비교 결과를 정답으로 읽지 않았다. 상대 세력·충합·조후/특수구조·운의 개별 메모는 이번 통합 수작업 검수이며, 스크립트가 자동으로 명리 결론을 도출한 것이 아니다. 장간의 십성군 목록은 독립적인 오행 배속 목록이며 점수·강도·실효 계산이 아니다.

각 기록에 입력/근/상대 작용/충합/조후·특수구조/운/원문-수치 동등성의 7개 축을 확인했다. 근이나 관재 성분의 존재가 확인돼도 실제 과다·감당 가능을 확정하지 않았다. 부분적 반례로 특정 단순화를 배제하는 것과 전체 규칙의 정상 음성은 다르다. 시주 미상은 6개 관찰이며 임의로 보충하지 않았다.
