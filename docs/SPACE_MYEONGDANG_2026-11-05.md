## 2. 원칙

- 세 이론(현공비성·팔택·형세)은 독립 계산하며 **점수를 합산하지 않는다**. 사주(억부·조후)는 방위 오행의 역할만 읽어 나란히 표시한다.
- 특정 건물의 길흉을 사주만으로 확정하지 않는다. 입력이 없으면 추정하지 않고 '판단 보류'.
- 유파 기준: 원반 정향, 입춘 기준 삼원구운, 건물 운반은 준공(개축 시 개축) 연도 기준, 별의 상태는 평가 시점 운 기준, 5 입중 시 좌·향산 음양. **미지원:** 체괘·반음·성문결 등(경고로 표시).
- AI 호출 없음. 모든 문장은 사전 문구 조합.

## 3. 검증 결과

- 9운×24좌향 전 판이 1~9를 한 번씩 포함, 격국은 4종으로만 분류(상산하수 48·왕산왕향 48·쌍성회좌 60·쌍성회향 60).
- 삼원구운 경계, 운반(8·9운), 연비성(2024=3 중궁·오황 서쪽), 월비성, 본명괘(1984·1990·2000 등), 팔유성(감·진·태·이·곤괘) 기대값 일치.
- 무작위 사주 400건 × 좌향·연도: 예외 0. 사주 연결 판정 적합/무난/주의 약 34/31/35%.
- **외부 전문가 사례 대조는 하지 않음**(요청에 따라 생략). 공개 전 감정 사례로 교차 확인을 권장.

## 4. 운영 순서

1. 관리자 → '공간·명당 풍수' → **문구 검수**에서 118개 읽고 일괄 검수 완료. 수정한 문구는 '해석 문구'에서 게시.
2. 관리자 → '소원 성취 명당' → 기본 목록 불러오기(82곳) → 분야 태그 검수 → 게시. (82→92곳. 좌표를 끝내 못 찾은 화진포 1곳만 제외)
3. '공간·명당 풍수' → **공개 스위치 켜기** (약 1분 내 반영).
4. 로컬 미리보기: 주소 뒤 `?mantraFlags=space` (운영 도메인에서는 무시).

## 5. 롤백

- **즉시:** 관리자 '공개 스위치 끄기' → 기존 '풍수' 탭으로 복귀(기존 55개 항목 풍수는 코드 변경 없음, 새 탭 안 ④로도 이동만 함).
- **코드:** 작업 전 지점 태그 `backup-before-space-myeongdang-20261105`. 해당 기능 커밋을 `git revert` 하면 된다. 기존 원국·사주풀이·택일 계산 로직은 수정하지 않았고, 택일·운세 흐름·용신 탭은 카드만 덧붙였다.
- **데이터:** KV 키 `fengshui:doc` 하나만 사용 → 키 삭제로 게시본 전체 초기화. 다른 키 불간섭을 테스트로 확인.
