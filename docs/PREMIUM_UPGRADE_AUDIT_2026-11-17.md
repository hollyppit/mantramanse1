## 4. 개선 설계 (2단계 — 공통 개인화 프로필)

### 4-1. 공통 분석 프로필 `report/v2/profile.js` (신규, 계산식 변경 없음)
기존 계산값만 모아 한 객체로 정리합니다. **새 점수 공식은 만들지 않습니다**(바꿀 일이 생기면 기존 결과와 비교표를 만든 뒤 따로 승인).
```
profile = {
  v: 'profile-1',
  day: { stem, element, yinyang },                     // 일간
  season: { monthBranch, johu: 'cold|hot|dry|wet|mild' },
  strength: { level, basis[] },                         // 신강·신약 + 근거
  yong: { yong, hee, gi, method, needBoth: 억부+조후 병행 여부 },   // ch.unified 그대로
  gyeok: { name, state: '성격|파격|미정', why },         // gyeok-structure
  tenGods: { dominant[], missing[], pairs[] },          // 식상생재·관인상생·상관견관 등 상호작용
  relations: { 합[], 충[], 형[], 해[], 파[] },            // 원국
  luck: { daewoonNow, seun2027, turningYears[] },
  tension: [ ... ]                                      // 상충 조건 목록(예: 신약인데 재성 과다 → 재다신약)
}
```
타임라인 69장·신년운세 사주 블록이 모두 이 프로필을 읽게 하면 장 사이 모순이 구조적으로 줄어듭니다.

### 4-2. 서사 조립을 "규칙 1개" → "층 3개"로
| 층 | 역할 | 고르는 방법 |
|---|---|---|
| 주 규칙(지금 것 유지) | 핵심 진단·후킹 | 지금처럼 우선순위 1등 |
| **수식 문단(신규)** | 복합 조건·양면성·반전 — "다만 ○○가 함께 있으면…" | `profile.tension`·십성 쌍마다 1문단, 장당 최대 2개 |
| **근거 줄(확장)** | 내면의 구조 — 실제 값 슬롯 | `{재성:월지 午火}`, `{대운:2031~ 壬子}` 같은 슬롯 |
| 결론(개인화) | 현실 전략 | 용신·나이대·주 규칙 조합 |

예상 효과: 장당 변형 6~9가지 → 수식 문단 조합으로 수십 가지, 본문 ~530자 → 900~1,300자(장 중요도별로 다르게), 근거 문장 10%대 → 40% 이상.
각 결과에 `trace: { rules:[id@ver], profile:'profile-1', exceptions:[] }` 를 남겨 관리자에서 "왜 이 문장이 나왔나"를 봅니다.

### 4-3. 토정비결 월별을 원문 중심으로
월 카드 순서(사주 블록은 맨 아래 별도 상자로 분리):
1. 이달의 주제(원문 구절에서 뽑음 — 후킹도 원문에서)
2. 원문 3구 + **구절별 해설**(상징 → 뜻 → 생활에서 보이는 장면)
3. 재물·일·관계 중 원문이 실제로 말하는 것만(원문이 언급 안 한 분야는 지어내지 않음)
4. 할 일 / 조심할 판단
5. **다음 달로 넘어가는 한 줄**(이번 달 톤 → 다음 달 톤 변화로 자동 선택)
6. [별도 상자] 사주 월운으로 본 이달 — 같은 방향 / 다른 방향 / 근거 범위 차이 설명 (일치를 "적중률 상승"처럼 쓰지 않음)

총운: 괘 이름·상(象) 풀이 → 한 해 관통 주제 → 상반기(1~6월 구절 톤)·하반기(7~12월) → 분야 → 주의·준비 → 요약 카드.
필요 문안량: 120괘 × 12개월 = **1,440 월 구절 해설**(원문 판독본에서 초안 → 사람 검수). 이것이 신년운세 작업의 대부분입니다.
