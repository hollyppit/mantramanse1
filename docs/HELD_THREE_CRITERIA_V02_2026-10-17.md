# 보류 3개 판정 명세 v0.2 — 충돌·수치 경계 분석

2026-10-17. 연구용 초안이며 운영 미연결·게시 불가다. 원문 의미와 엔진 수치의 동등성은 아직 검증되지 않았다. v0.1의 원문 근거 표 및 후속 독립 검증 요건은 유지하고, 실행 계약은 이 문서로 보강한다. 외부 AI 호출 및 운영 DB 변경은 없다.

## 1. 이전 결과의 정확한 범위

기존 480개 합성 원국을 동일하게 재생해 모델 충돌 27건과 반올림 차이 1건을 재현했다. 충돌은 성별 배속이 맞고 시주가 알려진 규칙 평가에서 센다. 반올림 진단은 성별 배속 밖의 평가도 포함했던 별도 계수이므로 두 수치를 같은 모집단의 오류율처럼 비교하면 안 된다.

| 충돌 축 | 건수 | 의미 |
|---|---:|---|
| 해당 군 30% 경계만 다름 | 12 | 도움 <42% 판단은 같지만 재성/관성 >=30% 판단이 모델별로 다름 |
| 도움 42% 경계만 다름 | 7 | 해당 군 >=30% 판단은 같지만 도움 <42% 판단이 다름 |
| 두 경계 모두 다름 | 8 | 해당 군과 도움의 두 boolean 모두 모델별로 다름 |

이 분류는 predicate 차이의 분류이며 인과 효과 크기나 전통적 정답의 판정은 아니다. 표본은 임의 추출한 대표 모집단이 아닌 결정론적 합성 표본이다.

## 2. 모델 차이의 구현상 이유

기존 engine.js에서 season은 천간 각 1점, 지지는 지장간 일수 비율, 월지 2배 가중이다. hidden은 같은 지장간 비율을 쓰되 월지 가중이 없다. simple8은 월지 가중 없이 지지를 본래 오행으로만 집계한다. 따라서 season↔hidden은 월지 가중 차이를, hidden↔simple8은 지지 분배 방식 차이를 비교한다. 정재/편재의 개별 비중 분모와 십성군 분모도 다르므로 혼합하지 않는다.

| 표본 ID / 규칙 | season 군% / 도움% | hidden 군% / 도움% | simple8 군% / 도움% | 경계 차이 |
|---|---|---|---|---|
| 13 / 남성 | 24.8148 / 27.4074 | 25 / 30.8333 | 37.5 / 25 | 군 비중만 |
| 26 / 여성 | 44.4444 / 40 | 37.5 / 45 | 37.5 / 50 | 도움 비중만 |
| 27 / 남성 | 20 / 50 | 22.5 / 43.75 | 37.5 / 37.5 | 두 조건 |

표 안 숫자는 설명용 반올림이며 실제 비교는 원시 double 값으로 수행했다. 어느 한 모델을 우선하거나 다수결로 통과시키지 않는다. 원문은 해당 가중치와 투표 규칙을 제시하지 않는다. 27건 모두 unknown(model-sensitive)을 유지한다.

## 3. 반올림 1건

표본 ID 469는 1984-02-17 13:00 남성 합성 입력이다. 이 원국에 여성 관성 규칙을 진단용으로 비교할 때 season 관성 비중이 29.999999999999993%, 도움은 24.81481481481481%였다. 표시용 소수점 한 자리 값은 30.0%여서 >=30 비교가 뒤집혔다. 원시 값의 30과의 차이는 약 -7.1e-15이다.

이 사례는 성별 배속 밖이므로 실제 여성 규칙 후보로 채택되는 사례가 아니다. 이전 보고의 ‘반올림 차이 1건’을 실제 대상 원국의 오판정 1건으로 해석해서는 안 된다. 실제 적용 범위 안의 해당 반올림 사례는 0건이었다.

원시 엔진 비교는 기존대로 엄격한 >=30 및 <42를 유지한다. double의 경계 근접을 전통적 세력 차이로 해석하지 않기 위해 연구 선별기에만 별도 유보 처리를 넣었다. 엔진에서 30으로 올림 보정하거나 원문 임계값을 새로 만들지 않았다.

## 4. 보강한 실행 계약

- precision='raw-engine'을 필수로 요구한다. 표시용 반올림 데이터 또는 출처 표식 누락은 unknown이다. 이 표식은 입력자의 선언이며 실제 원시 엔진 경로를 기술적으로 인증하지는 않는다. 운영 연결 시 원시값 어댑터를 별도 검증해야 한다.
- 각 모델별 원시 비중, 도움, 두 조건의 boolean, 임계값까지의 signed margin을 반환한다.
- 충돌 축(groupPass/helpPass)과 수치 경계 모델 목록을 함께 보존한다. 배열 순서를 바꿔도 최종 결과는 같아야 한다.
- 모델 충돌이면 unknown(model-sensitive). 합의하더라도 어느 모델이든 abs(군%-30)<=1e-10 또는 abs(도움%-42)<=1e-10이면 unknown(numeric-boundary-review).
- 1e-10 percentage point는 이 가중 합산 구현의 부동소수점 경계 진단을 위한 보수적 연구 허용폭이다. 명리적 임계값·예측 허용 오차·30%를 만족시키는 보정량이 아니다. 모든 계산 환경의 오차 상한을 증명한 값도 아니다.
- 성별 범위 밖이면 먼저 not-candidate, 시주·구조 정보 누락이면 unknown이다. 나머지 진단 원인을 최종 사유와 혼동하지 않는다.
- 연도 규칙은 연도 종합 재성 작용과 일간 감당 능력을 합성하는 규격이 없으므로 계속 unknown이다.
- 모든 결과 publishable=false / traditionalVerdict=unvalidated. candidate는 연구 표본 선별일 뿐 게시 허가가 아니다.

## 5. 재검증

실행:

```text
node tests/held-three-criteria-sim.cjs --report
node tests/held-three-disagreement-sim.cjs --report
node tests/engine-baseline-sim.js
```

기본 계약 검증 2,483개와 충돌·경계 회귀 검증 1,958개가 통과했다. 원래 27건을 모두 재현·유보했고, 반올림 1건의 적용 범위 밖 여부를 확인했다. 모델 목록 역순에서도 결과가 유지되며, 경계 양쪽의 ±1e-14 흔들림과 정확히 30/42인 사례는 유보된다. 기존 엔진 120개 차트 기준선도 일치한다.

v0.2의 합성 표본 집계:

| 규칙 | candidate | not-candidate | unknown |
|---|---:|---:|---:|
| 남성 | 17 | 446 | 17 |
| 여성 | 10 | 397 | 73 |
