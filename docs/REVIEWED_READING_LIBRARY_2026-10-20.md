# AI 없는 기본 풀이와 검수 라이브러리

## 서비스 동작

- `/api/movingtoon-reading`의 일반 요청은 `reviewed-only` 경로로만 처리합니다. API 키, `force`, 개인 상황, 이전 조언, 캐시 실패로 유료 생성에 진입할 수 없습니다.
- 계산된 사주를 기존 조건·제외 조건·원문 검증 엔진에 적용하고, 해당 질문에 연결된 게시·검수 완료 지식만 사용합니다.
- 관리자가 게시한 문장을 우선 선택하고 부족한 부분은 적용된 DB 지식의 설명·장점·위험·행동으로 구성합니다. 일반 실천 점검은 개인별 명리 결론과 구분합니다.
- 기본 84개 문항의 문안 704개를 작성·게시했습니다. 개인 판단의 근거가 없는 경우에는 질문별 참고 해설을 제공하며, 새로운 개인 판단으로 빈칸을 채우지 않습니다. 창작 8편은 다섯 가지 상징 표현을 가진 연속 이야기로 제공합니다. 자세한 검수 기록은 COMPLETE84_COPY_REVIEW_2026-10-20.md에 있습니다.
- 결과 진입 시 AI 문장 합성, 관계 AI 추정, 전생 단편 자동 생성을 제거했습니다. 해당 공개 생성 API도 기본 경로에서 유료 호출을 차단합니다.
- 기존의 관리자 사전 생성은 서버 내부의 명시적 opt-in으로만 실행할 수 있습니다. 운영 DB의 자동 사전 생성·자동 연구와 자동 게시는 껐습니다. 별도의 선택형 AI 기능까지 모두 폐지한 것은 아닙니다.

## 관리 방법

관리자 → **검수 풀이 라이브러리**에서 질문을 선택합니다.

1. 기존 DB 문장 제안을 확인하거나 새 문장을 작성합니다. 화면에서 본문·위치·필요 근거·추가 적용 조건·제외 조건을 편집합니다.
2. **존댓말 정리·초안 저장**으로 저장합니다. 게시본은 유지됩니다.
3. 가상 생년월일·성별·시간 미상을 지정해 **현재 초안 미리보기**를 실행합니다. AI 비용은 없습니다.
4. 적용되어야 하는 문장 ID와 적용되면 안 되는 문장 ID를 지정해 사례를 추가합니다. 개인 풀이마다 적용 사례와 반례가 필요합니다.
5. **적용·반례 검증**을 통과하고 검수 확인 후 **검증 후 게시**합니다.

검증 사례는 초안과 함께 저장합니다. 이전 버전은 초안으로 복원한 뒤 다시 검증·게시할 수 있습니다. 동시 수정은 CAS로 차단하며 게시 문장에 연결된 근거 버전이 바뀌거나 자료가 비활성화되면 그 문장은 사용하지 않습니다.

저장 키는 기존 service-role 전용 CAS가 허용하는 `ik:blocks:chapter:library.<chapterId>`입니다. 기존 블록 편집 API는 이 예약 접두어를 편집하지 못합니다. 공개 API는 관리 내용을 편집하거나 초안을 읽을 수 없습니다.
