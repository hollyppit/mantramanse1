# 토정비결 원문 판독 지침 (규장각 奎古 1077)

목표: 지정된 면(side)들의 **인쇄된 한문 글자만** 정확히 옮겨 JSON 파일로 저장한다.

## 절대 규칙
- 화면에 인쇄된 글자만 쓴다. 토정비결을 기억으로 채우거나, 다른 사이트를 찾아보거나, 문맥으로 추측해 고치지 않는다.
- 읽기 어려운 글자는 `□` 로 두고 `uncertain` 에 후보를 적는다. 확실하지 않으면 반드시 uncertain 에 남긴다.
- 이체자·약자는 인쇄된 모양대로(예: 甁·瓶 구분). 간체자로 바꾸지 않는다.
- 각 구 아래의 **한글 풀이와 【해왈】 한글은 옮기지 않는다.**
- 단, 【註解】 줄에 섞인 한글 토(하니·이라 등)는 인쇄된 그대로 zhujie 에 함께 적는다.
- 괘 그림 옆 주역 괘 이름은 가로로 **오른쪽→왼쪽**으로 읽는다(예: 008a = 姤之乾).
- 다른 판독 결과 파일(passA·passB의 남의 파일)을 열어 보지 않는다.

## 화면 보는 법 (내장 브라우저, 자기 탭만 사용)
1. `tabs_create` 로 자기 탭을 하나 만들고, 이후 모든 호출에 그 `tabId` 를 넣는다. 다른 탭은 건드리지 않는다. 끝나면 `tabs_close`.
2. 면 주소: `https://kyudb.snu.ac.kr/ImageServlet.do?imgFileNm=GA01077_00_IL_0001_{SIDE}.jpg&path=/data01/stream/OCT/IMG/GA01077_00/GA01077_00_0001/GA01077_00_IL_0001_{SIDE}.jpg` ({SIDE} 예: 002a)
3. 이동 뒤 javascript_tool 로 원본 크기로 펼친다:
   `const im=document.querySelector('img'); if(!im.complete) await new Promise(r=>im.onload=r); document.body.style.margin='0'; im.style.cssText='width:1384px;max-width:none;max-height:none;height:auto;display:block;margin:0;position:static'; await new Promise(r=>setTimeout(r,200)); window.scrollTo(X,Y); [scrollX,scrollY]`
   - 페이지 기본 화면이 크기를 되돌리면, 같은 이미지 주소로 새 img 요소를 만들어 body 를 그것만으로 바꾼 뒤 1384px 로 본다(시범 판독에서 효과 확인). 애매한 글자는 2768px 로 키워 그 부분만 다시 본다.
4. 여섯 곳을 스크린샷한다: X ∈ {360(오른쪽 절반), 0(왼쪽 절반)} × Y ∈ {0, 620, 1240}. browser_batch 로 javascript(scrollTo) → screenshot 을 이어 붙이면 빠르다. 글자가 애매하면 그 부분만 다시 스크롤해 본다.

## 면 구조
- 오른쪽 위: 괘 번호(한자 숫자, 예: 一一一), 괘 그림 옆 작은 글씨 주역 괘 이름(예: 乾之姤), 【註解】 한문 한 줄, 【卦象】 4자 2구.
- 본문은 위·가운데·아래 **3단**. 각 단은 오른쪽부터 **15칸(쌍)**: 「卦辭」 3쌍 → 正月 1쌍 → 二月 … 十二月 각 1쌍. 머리글(卦辭·正月…)은 위 단에만 있고, 가운데·아래 단도 같은 칸 위치를 따른다.
- **한 쌍 = 세로줄 두 개(각 4자).** 오른쪽 줄이 앞 구, 왼쪽 줄이 뒤 구. 예) 111괘 위 단 첫 쌍: 오른쪽 줄 「東風解凍」, 왼쪽 줄 「枯木逢春」 → `["東風解凍","枯木逢春"]`.
- 111괘 위 단 참고(검증된 예): 卦辭 `[東風解凍,枯木逢春]` `[月明中天,天地明朗]` `[君謀大事,何必疑慮]`, 正月 `[春化日暖,鳳雛麟閣]`, 二月 `[東園桃李,逢時滿發]`.
- 한 면에 괘가 하나가 아니거나(빈 면·표·설명 면 등) 구조가 다르면 그대로 notes 에 적고, 읽을 수 있는 것만 옮긴다.

## 저장 형식
파일: `{OUTDIR}/{SIDE}.json` (Write 도구, UTF-8)
```json
{
  "side": "002a",
  "kind": "gua",                  // gua | other(표·빈 면·설명)
  "gua": 111,                     // 인쇄된 번호를 아라비아 숫자로
  "printed_number": "一一一",
  "zhouyi": "乾之姤",
  "zhujie": "有變化之意",
  "guaxiang": ["東風解凍","枯木逢春"],
  "bands": [
    { "guaci": [["",""],["",""],["",""]], "months": [["",""],["",""],["",""],["",""],["",""],["",""],["",""],["",""],["",""],["",""],["",""],["",""]] },
    { "guaci": [...3쌍], "months": [...12쌍] },
    { "guaci": [...3쌍], "months": [...12쌍] }
  ],
  "uncertain": [ { "where": "bands[1].months[4][0]", "pos": 2, "read": "□", "candidates": ["是","事"] } ],
  "notes": ""
}
```
- bands[0]=위 단, [1]=가운데, [2]=아래. months[0]=正月 … months[11]=十二月.
- 모든 구는 4자. 4자가 아니면 그대로 쓰고 notes 에 적는다.

## 끝나면
마지막 답변에 처리한 면 목록, 각 면의 괘 번호, uncertain 개수, 이상한 점(번호가 예상과 다름, 빈 면 등)만 짧게 보고한다.
