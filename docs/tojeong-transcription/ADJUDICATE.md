# 불일치 칸 판정 지침

두 판독자(A·B)가 같은 칸을 다르게 읽은 곳만 원본 이미지에서 다시 보고 판정한다.
목록: `adjudicate.json` (각 항목: side, key, where(칸 위치 설명), A, B). 화면 보는 법·면 구조는 `INSTRUCTIONS.md` 와 같다(내장 브라우저, 자기 탭 하나, 탭 한도 ~9개라 실패하면 1분 간격 재시도, 다운로드 금지, 하위 에이전트 금지, 끝나면 탭 닫기).

## 판정 원칙
- 인쇄된 글자 모양이 기준이다. 문맥·한글 풀이·기억으로 고르지 않는다(한글 풀이와 다르면 note 에만 적는다).
- 해당 칸을 2배 이상 키워 본다. 칸 위치는 where 를 따른다: 위·가운데·아래 단, 오른쪽부터 卦辭 3쌍 → 正月 … 十二月, 한 쌍의 오른쪽 줄이 앞 구.
- A·B 중 맞는 쪽이 있으면 그것을, 둘 다 틀리면 직접 읽은 값을 쓴다. 가려지거나 찢겨 정말 안 보이는 글자만 □.
- 이체자는 인쇄 모양대로 고른다.

## 저장
`{OUTDIR}/adj-{묶음번호}.json` 에 배열로:
```json
[{ "side":"002b", "key":"b1.m3.0", "value":"山生水踈", "pick":"A|B|other", "confidence":"high|medium|low", "note":"" }]
```
목록의 모든 항목에 하나씩 답한다. 끝나면 처리 수, low 판정 목록만 한국어로 짧게 보고.
