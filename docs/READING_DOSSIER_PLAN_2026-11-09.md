# 풀이 장 구성 다양화 계획 (2026-11-09)

참고: 사용자가 보내 준 '운명의 거울 · 전생과 미래의 인연' 화면 구성
(일주 카드 → 서사 한 단락 → 운명의 말 → 초상 → 첫 장면 한 줄 → ✦ 항목 목록 → 점수 막대 → 태그).

## 원칙

- 계산은 바꾸지 않는다. 사주 값(일간·일지·십성 비중·12운성·신살·대운·세운)에서 규칙으로 고른 상징 해석만 더한다.
- 명리 근거는 남기되 생활 말로 풀고, 용어는 괄호에 둔다.
- 장마다 같은 틀을 되풀이하지 않는다. 아래 블록 중 그 장의 질문에 맞는 2~3개를 고른다.
- 실존 인물(연예인 닮은꼴 등)·실제 전생·사건 단정은 쓰지 않는다.
- 운영 DB 문안(rebuild 게시본)은 그대로 두고, 화면 블록(reading-feature SPEC)만 더한다. DB 재게시가 필요 없다.

## 검사

- 노드 시뮬레이션: 여러 사주에서 undefined·NaN·조사 오류가 없는지, 장 사이 같은 문장이 반복되지 않는지.
