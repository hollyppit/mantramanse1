```bash
node tools/timeline-contra.cjs
```


## 수정 결과 (같은 날, 위 표는 수정 전 값)

깊이 풀이(`reading-depth-data-2·3·4.js`)와 포인트(`reading-insight-data-1.js`)의 문장 14개에서 성향 단정을 빼고 처방은 남겼다. 같은 240명으로 다시 재니 11개 조합이 2개로 줄었다.

- self_37 3명: 깊이 `g[4]` "작은 실행 하나" ↔ 서사 "속도를 늦추고 열을 내리는 생활". 이어서 `g[4]`를 "서두를 필요는 없고, 한 번에 하나씩"으로 고쳐 없앴다.
- self_03 1명: 포인트 "계산과 실행이 늦어져" ↔ 서사 "그만큼 성급해요". 서로 다른 성향 설명이라 남겼다.

규칙이 낱말 기반이라 "0건"은 문장 표현이 규칙에 더 안 걸린다는 뜻이기도 하다. `report/v2/index.html`의 해당 파일 `?v=` 값은 올렸다.

## 원인

깊이 풀이는 일간의 힘·가장 센 기운·용신 같은 값 하나로 문장을 고른다. 서사와 저울은 여러 조건을 함께 본다. 그래서 깊이 풀이가 성향(빠르다·균형형·활발한 곳)을 단정하면 어긋난다. 서사는 두고 깊이 풀이 쪽을 "처방"만 말하게 바꾸는 것이 가장 적게 손대는 방법이다. 위 표의 원인 키 약 8개 문장이 대상이다.

## 오탐으로 거른 것

- "생활 리듬을 챙기는 힘이 약한 편" ↔ "(신강)": 다른 종류의 힘이다.
- "준비를 끝내 두세요" ↔ "추진력이 커요": 조언이지 성향 진단이 아니다.
- 점검표 2순위 이하 "준비만 하다 때를 놓치는 곳": 참고 목록이다(처음 66건 → 1순위만 8건).

## 한계

- 낱말 규칙이라 규칙에 없는 표현의 모순은 못 잡는다. 0건인 축(준비 정도·틀·혼자와 함께·리더와 전문가·내 힘)이 모순이 없다는 뜻은 아니다.
- 시기표(periods)·그래프·표·근거 상자는 비교에서 뺐다.
- 운영 DB의 관리자 게시 문안은 보지 않았다(감사 도구의 한계와 같다).
