## 확인 범위

운영 사용자 화면 /report/v2/에서 양력 입력부터 직접 진행했다. 가상 명식 두 개의 85개 장(기본 84개 + 전성기 보충 1개)을 순서대로 이동하고 본문·생활 예시·풀이 근거를 펼쳐 확인했다. 별도로 출생시각 미상 명식의 기본·운 흐름·관계 8개 장을 확인했다. 최종 중복 방문을 제외한 화면 기록은 178개다.

- 꾸준형: 1963-05-05 16:20 여성, 서울, 자동 보정. 중화·식신·정재 상세 문안이 선택되는 사례.
- 탐구형: 1987-11-20 18:00 여성, 서울, 자동 보정. 인성 비중이 높고 확인·검토 조건을 비교할 수 있는 사례.
- 시간 미상: 1992-06-23 남성, 서울, 자동 보정. 시주를 추가하지 않는지 확인하는 사례.

실제 개인 기록이 아닌 검수용 가상 입력만 사용했다. 사용자 화면에서 보이는 DOM 문장과 펼친 근거를 기록했으며, 관리자 미리보기나 로컬 모의 화면으로 대신하지 않았다.

## 발견하고 수정한 점

1. 원문 판단·적용 이유·근거에서 문장을 다시 추출해 '사주에서 드러나는 내 모습'으로 여러 장에 반복하던 표시를 제거했다. 근거와 원문 판단 자체는 펼쳐 보는 근거란에 보존한다. 내부 fitScore나 '조건을 모두 충족해 선택' 같은 설명이 본문으로 승격되지 않는다.
2. 이해하기 쉬운 명리 단서가 생활 예시 앞에서 사라지지 않게 했다. '식신의 반복해서 만드는 성향과 정재의 실무 감각 → 같은 작업을 꾸준히 하되 익숙한 순서를 지키려는 장면'처럼 본문의 맥락이 이어진다.
3. 추가 예시는 전체 명식에서 가장 큰 십성군 대신 실제 선택된 본문의 조건을 따라 고른다. 7개 대표 상세 장에서는 일간·강약·두 개별 십성의 조합을 맞추고, 조건이 충분하지 않으면 해당 챕터의 일반 예시를 사용한다. 시기 장에 축적 설명과 확장 예시가 섞이던 문제도 이 경로에서 제거했다.
4. 자동차·일간 설명에서 실제 게시 제목을 별도의 최상위 십성군 설명으로 덮어쓰지 않는다. 기존 본문의 조건과 제목을 함께 유지한다.
5. 충분한 실천 문장이 있으면 고정된 추가 조언을 붙이지 않는다. 꾸준히 반복하는 작업의 개선을 권한 뒤 갑자기 모임 날짜와 역할을 나누라는 조언이 붙던 문제를 제거했다.
6. 창작 본문에 이미 들어간 생활 비유와 화면의 성찰 문단이 겹치던 현상을 고쳤다. 창작 8개 장 × 2개 명식에서 비유가 한 번씩 나타남을 확인했다.
7. 이미 '예를 들어', '예를 들면', 구체적인 상황을 떠올리는 문장이 있는 본문에는 다른 예시를 덧붙이지 않는다. 현침살 설명이 붙는 장에서도 조합 예시가 추가로 반복되지 않게 했다.
8. 사용자 화면의 계산 자료에 개별 십성 비중을 전달해, 기존 저장된 풀이를 표시할 때에도 상세 조합을 대조할 수 있게 했다.
