# 추가 문헌 21구간·명조 5건 — 32개 사례 실제 재검수

2026-10-17. 원국 24건·연도 관찰 8건을 모두 재검수했다. 부분 사실 확인 32건, 규칙 전체 확정 0건, 최종 유보 32건이다. 모든 사례를 다섯 비교 명조와 일간·월지·기둥 차이로 대조했다. 이는 새 문헌을 연결만 한 이전 수집 원장과 달리 조문 적용 범위와 관련 글자의 藏/透 및 개별 미해결 판단을 기록한 결과다. 게시·운영 변경·외부 AI 호출 없음.

## 판정의 구분

관찰 상태 present/absent는 일간 외 천간에서 해당 글자가 보이는지의 뜻이다. absent가 조문의 불충족 전체나 정상 음성을 의미하지 않는다. hiddenPositions는 장간 소속만 나타낸다. 未知 시주에 해당 글자가 나타날 수 있으면 unknown-incomplete-hour로 남긴다. 기능 효력은 별도로 모두 unknown이며 점수로 환산하지 않았다.

궁통보감의 월별 조건과 신봉통고의 상대/동정/병약 관점을 각각 검토했다. 신봉통고의 개고·동정 제한을 자평진전·임씨 관법과 하나로 합치지 않았다. 달별 조문의 실제 격·과다·생조 판단을 선행 확정하지 않고 글자 충족만으로 결과를 올리지 않았다.
