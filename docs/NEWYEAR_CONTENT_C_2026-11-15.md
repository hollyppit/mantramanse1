## 조합 방식
- 장 순서: 여는 장(괘 번호·첫 글귀·정미년 상징) → 총운(핵심 흐름 / 토정비결이 말하는 올해 / 두 풀이가 만나는 지점 / 기회와 위기 / 작년과 달라지는 점) → 재물 → 직업·사업 → 연애·인연 → 건강·안전 → 12개월 → 결정적 시기 → 행동 지침.
- 문단 순서: 후킹 → **근거(데이터로 만든 사실 문장)** → 상황 → 현실 장면 → 실천 조언.
- 블록 고르기: 조건 키(세운 십성·등급·관계·변화·삼재·분야 등급·월 방향·용신/기신 오행)가 가장 많이 맞는 블록, 같은 조건이면 사주 해시로 본판/다른 판. 한 풀이 안에서 같은 블록을 두 번 쓰지 않음.
- 토정·사주 비교: 괘 방향(tone)과 세운·월운 방향이 같으면 같은 방향, 한 단계 차이면 '결이 다름', 반대면 "두 풀이가 다르게 봐요"로 **나눠서** 보여 줌.
- 12개월: 음력 달(토정) 이름 + 양력 기간, 같은 무렵의 절기 월운(사주)을 함께. 기준을 장 머리에 명시.
- 공개 모드(`mode:'public'`): 검수 전(draft) 토정 현대어는 숨기고 원문만. 미리보기(`preview`)는 모두.
