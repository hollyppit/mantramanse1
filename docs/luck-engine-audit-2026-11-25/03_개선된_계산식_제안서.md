## A안. 관계 점수 정밀화 (`relationParts`)

### A-1. 지장간 가중 역할
```
roleHid(지지) = Σ 지장간 (역할값(지장간 오행) × 일수/30)      역할값: 용 +2 · 희 +1 · 한 0 · 구 −1 · 기 −2
```
지금은 지지 본기 오행 하나의 역할만 본다.

### A-2. 충
```
충 = (−roleHid(충 받는 원국 지지) × 5 − 2) × 충 종류 배율 × 자리 무게
충 종류 배율: 子午卯酉(왕지) 1.0 · 寅申巳亥(생지) 0.9 · 辰戌丑未(고지) 0.6
자리 무게: 일 1 · 월 0.8 · 년 0.5 · 시 0.5
```
- 기본 감점은 −5 → −2로 줄인다. 충 자체는 변동성에서 따로 다룬다.
- 고지충은 붕충·개고(창고가 열림)라 깨짐보다 '드러남'의 성격이 강하므로 0.6배로 둔다.

### A-3. 합(육합·삼합·반합·방합)과 합화 성립도
```
성립도 h = 0.4
         + 0.3  (월지 오행 = 합화 오행, 또는 월지 오행이 합화 오행을 생함)   ← 월령 지원
         + 0.3  (합화 오행이 원국·운 천간에 투출)                        ← 투간
         − 0.2  (합에 참여한 원국 글자가 같은 운에서 충도 받음)            ← 합충 혼재
         범위 0.2 ~ 1.0
합 = 합화 작용 + 묶임 작용
   = 역할(합화 오행) × 5 × 자리 무게 × h
   + (1 − h) × (−roleHid(묶인 원국 지지) × 1.5 × 자리 무게)
```
- 합화가 잘 성립하면(h=1) 합화 오행의 역할만 본다.
- 성립이 약하면 합화보다 '원국 글자가 묶여 제 역할을 못함'(합거·합반)의 의미가 커진다. 용신 글자가 묶이면 −, 기신 글자가 묶이면 +이다.

### A-4. 천간합·천간충
```
일간 합   = 역할(합화 오행) × 3 × h × 0.6       (일간 합화는 드물어 0.6)
일간 충   = −4                                  (기존 −5)
다른 천간 합(합거) = −역할(묶인 글자) × 1.5 × 자리 무게   (기존과 같음)
```

### A-5. 형·파·해 (새로 흐름에 반영, 작게)
```
형(자형 제외) = (−roleHid(대상) × 2 − 1.5) × 자리 무게 × 0.6
파·해        = (−roleHid(대상) − 0.5) × 자리 무게 × 0.3
자형·원진·귀문관 = 흐름 점수 0 (변동성에서만)
```

### A의 효과(04 비교표 요약)
- 관계 기여 중앙값이 2.7 → 1.9로 줄었다. 관계 점수를 키우지 않는다는 원칙에 맞다.
- 대운 등급 변화는 약 4%이다. 상위 변경 사례는 대부분 '고지충 과대 감점'과 '조건 없는 합화 감점'이 줄어든 경우이다.

## B안. 원국 구조 감점은 성립할 때만 (`evaluateLuck` 구조 성분) — 2026-11-25 적용(`LUCK_CFG.structure.establish`)

운에서 같은 기운이 올 때 감점(관살혼잡 −12 · 상관견관 −10 · 군겁쟁재 −12 · 도식 −8)을 적용하기 전에 아래 조건을 확인한다.

| 구조 | 성립 조건(모두 만족할 때만 감점) |
|---|---|
| 관살혼잡 | 정관 ≥5% 그리고 편관 ≥5% · 식신 <8%(제살 없음) · 신약이면서 인성 ≥15%가 아님(화살 없음) |
| 상관견관 | 정관이 쓸모 있음(용·희) · 정인 <8%(패인 없음) · 상관 ≥5% 그리고 정관 ≥5% |
| 효신탈식(도식) | 식신이 쓸모 있음 · 재성 <10%(재제효 없음) · 편인 ≥8% |
| 군겁쟁재 | 관성 <10% 그리고 식상 <10%(관제비겁·통관 없음) |

효과: 대운 등급 변화 약 1%, 최대 점수 변화 8~9점.

## E. 분야 지표 등급 (`luck-grade.js`)

**E-1. 경계값 판정 정정(오류 수정)**
```
좋음 : 점수 > 상위30% 기준값      (지금은 ≥)
조심 : 점수 < 하위30% 기준값      (지금은 ≤)      사고수는 방향 반대
```
독립 표본 결과는 다음과 같다(좋음/무난/조심).

| 지표 | 지금 | 초과·미만 |
|---|---|---|
| 연애 | 32/35/33 | 29/43/28 |
| 재물 | 33/31/36 | 29/40/31 |
| 건강 | 36/34/31 | 32/40/27 |
| 사고수 | 30/42/28 | 27/47/26 |
| 결혼 | 33/32/34 | 31/37/32 |

**E-2. 기준값 재산출**: 개발 표본으로 다시 뽑은 기준값이 기존 값과 ±2 이내라, 재산출보다 E-1이 핵심이다.

**E-3. 전체 기준과 개인 기준**
- 지금은 전체 명식 기준(같은 점수면 누구나 같은 등급)이다.
- 한 사람의 평생 세운에서 지표 점수 폭은 중앙값 23~39점이다. 개인 기준(그 사람의 평생 분포 안 상·하위 30%)을 쓰면 '평생 재물 점수가 낮은 사람'도 좋은 시기가 표시된다.
- 제안: 기본은 전체 기준을 유지하고, 상세 화면에 '내 평소 대비' 표시를 보조로 둔다. 안내 문구에 기준을 적는다.
  - 예: "같은 점수면 누구에게나 같은 등급이에요" / "내 평생 흐름 안에서 높은 편이에요"
