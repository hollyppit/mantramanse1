## 핵심 결론
1. **분야 지표 등급에 실제 오류가 있다.**
   - 경계값을 '이상/이하'로 판정해서 경계에 걸린 5~9%가 양쪽 등급으로 들어간다. 그래서 설계(30/40/30)가 33/33/33으로 나온다.
   - '초과/미만'으로 바꾸면 독립 표본에서 설계에 가깝게 맞는다.
2. **합화 조건 없이 모든 합을 합화로 보고, 고지충을 왕지충과 같은 세기로 감점한다.**
   - 개선안 A로 대운 등급 약 4%가 바뀐다.
   - 크게 바뀐 8건은 대부분 辰戌·丑未 충 감점 완화라서, 전문가 대조가 먼저 필요하다.
3. **원국 구조(관살혼잡·상관견관·도식·군겁쟁재)를 이름만으로 판정한다.**
   - 개선안 B·C는 영향이 작고(등급 0.3~1%) 방향 오류만 막는다. 먼저 넣어도 되는 쪽이다.
4. **변동성 지표는 이미 흐름 점수와 독립이다(상관 −0.04).**
   - 다만 상하위 운 충돌, 대운·세운 중첩, 복음·반음, 구조 변화가 빠져 있어 2판을 설계했다.
5. **학파 선택에 따라 대운 등급 11~15%가 바뀐다.**
   - 화면에 '해석법에 따라 달라짐' 표시가 필요하다.

1. 분야 지표 경계값 정정 · `luck-grade.js` 주석 정정 · 대운 그래프 잘림 표시

3. 1차 전문가 대조(06) → A안
