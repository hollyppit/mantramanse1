# 월운·일진 캘린더 수정 (2026-10-18)

## 수정
- 캘린더 도구 `.mc-controls`를 `.fc-controls`로 분리했다. 시네마틱의 absolute 위치·bottom·left·right 선언이 도구를 하단 CTA 위에 띄우던 원인을 제거했다.
- 공통 interaction.css의 버튼 배경이 데이터 색상을 덮어쓰지 않도록 캘린더의 날짜·월 막대·목록 선택자 범위를 명시했다.
- 월 막대 높이는 엔진 적합도 `(fitScore + 100) / 2` 반올림(0~100)을 사용한다. 색 분류는 엔진 fitScore <= -12 또는 defense score >= 40인 경우 방어운을 우선하고, 그 외 기존 네 활성도 중 최고 흐름이다. 문턱값은 엔진 LUCK_CFG.condition 및 FLOW_CONFIG.overlay에서 읽는다. 명리 기초 산식이나 다른 화면의 엔진 결과를 변경하지 않는다.
- 화면의 펼침 설명에 개인별 동적 가중치, 월운 해당 절기 60% + 대운 40%, 일진 해당 날짜 작용, 방어 부담도, 분류 문턱을 명시했다.
- 기존 상위 3개 risk 목록을 색 판정에 사용하지 않고 기준에 해당하는 모든 날짜를 붉게 표시한다. 택일은 별도의 목적 점수 48 미만도 주의 표시한다. 주의 표시는 추천보다 우선하며 선택된 주의 날짜도 붉은 배경과 선택 테두리를 함께 유지한다.
- 월운 설명과 선택 날짜 상단 운세명에도 방어운을 표시한다.

## 검증
- 실제 Edge에서 서로 다른 4개 생년월일로 각 12개월, 각 365일(총 1,460일)의 날짜 색상과 월운 점수·방어운 막대를 엔진과 대조했다.
- 단독 허브와 홈 내 허브 통합 화면 모두 실행했다. 320/390/1280px, 연도 변경, 목적별 택일, 선택된 주의 날짜의 붉은 배경, 날짜 안내·하단 CTA 겹침 없음, JavaScript 오류 없음 확인.
- artifacts: output/calendar-release/browser-verification.json, embedded-browser-verification.json, screenshots.
- 운영 사이트 직전 배포를 보존한 패키지에 hub-saju.js와 hub.css 2개만 교체했다. Worker 및 서버 환경은 유지한다.
