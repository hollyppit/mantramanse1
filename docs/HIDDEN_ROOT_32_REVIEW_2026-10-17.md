## 보강한 적용 기준

1. **원표 먼저**: 지지별 지장간 목록·순서·여기/중기/본기와 관법을 출처 문장·표에 연결한다. 실제 원표를 확보하지 못하면 null/unknown으로 남긴다. 기억이나 엔진 표를 독립 원문으로 재포장하지 않는다. 원표가 다른 경우 학파별 버전을 분리한다.
2. **배속과 투출 분리**: 원표 검증 후 각 지지의 숨은 천간을 기록하고, 어느 천간 위치에 같은 글자가 나타나는지 대응시킨다. 투출 위치의 일치는 사실 항목이며 격국 성립·세력 우세를 자동 뜻하지 않는다. 시주 미상은 시지 장간과 시간 투출을 모두 유보한다.
3. **통근 정의 고정**: 동일 천간·동일 오행을 근으로 보는 범위, 인성 생조를 근에 포함하는지, 월지·일지·다른 지지의 취급, 장간 깊이와 합충에 따른 유지/손상 조건을 먼저 명시한다. 이번 원문은 이 모두의 필요충분조건을 제공하지 않는다. 인성의 생조와 일간 자체의 근을 혼합하지 않는다.
4. **십이운성은 별도 축**: 원문은 4왕·4중·4쇠와 통근 설명을 제공하지만, 이를 장간의 유무·뿌리 점수와 자동 동치로 삼지 않는다. 봉법/거법/좌법 중 어떤 기준인지 정하고 천간별 시작점 원표를 검증한 뒤 적용한다. 4쇠의 ‘무근에 가까움’을 무근 확정으로 바꾸지 않는다.
5. **상대 작용 장부**: 각 위치마다 생조/비조·설기·극제의 방향, 장간 검증 여부, 투출, 계절, 근거 문장, 합충·조후·특수구조 불확실성을 각각 기록한다. 글자 존재·실효 작용·전체 우세는 서로 다른 필드다. 독립 기준이 없으면 수치 합산·다수결·글자 개수로 결론을 채우지 않는다.
6. **시운 지원 변화**: 원국 통근과 대운/세운 지원을 분리한다. 지원 오행이 들어옴→실효 지원 증가→일간 감당 능력 변화의 각 연결을 입증해야 하며 한 단계라도 부족하면 연도 재성 과도 판단을 유보한다.

위 1~6은 검수 데이터 계약·추가 근거 요구사항이다. 새 전통 관법이 입증됐다는 뜻은 아니다. 기존 원문으로는 검토 순서와 혼동 방지를 보강할 수 있지만 장간 배속표와 상대 작용의 실효 판정까지 완성할 수 없다.
