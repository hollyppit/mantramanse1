# 거시 시대 흐름 — 이론 조사 보고 (2026-11-18)

목적: 개인 원국·운과 별개로 모든 사람에게 공통인 '시대 기운'을 만세력에 넣기 전에, 쓸 수 있는 이론과 근거를 확인한다.
원칙: 근거가 확인된 규칙만 계산에 쓰고, 확인되지 않은 이론은 '연구 대기'로 두어 화면에 확정 결과로 내보내지 않는다.

## 2. 삼원구운

### 2-1. 계산 기준(기존 `fengshui-engine.js` 와 같음)
- 기준 연도 1864년(甲子年) = 상원 1운 시작. 180년(정원) = 상원·중원·하원 각 60년, 원마다 3운, 운마다 20년.
- 운 = `floor(((연도 − 1864) mod 180) / 20) + 1`. 원 = 60년 단위.
- 교체 시점: **입춘**(양력 2월 4일 무렵)을 경계로 본다. 입춘 전날은 이전 운이다. 기존 공간·명당 엔진과 같은 기준(`SCHOOL.periodBoundary`).
- 지원 범위: 기존 엔진이 1864~2103년을 지원한다(`xuankong` 의 연도 검사). 시대 흐름은 180년 주기로 앞뒤 계산이 가능하지만, 화면은 1864~2103년만 보여 준다.

### 2-3. 출처 간 차이와 미확인 사항
- 9운 = 2024년 입춘~2043년: 여러 대중 출처가 일치([Epoch Times](https://www.epochtimes.com/b5/24/1/7/n14153269.htm), [cnyes](https://hao.cnyes.com/post/273386), [Master Sean Chan](https://www.masterseanchan.com/fengshui-2024-flying-star-chart/), [HKIE 자료](https://hkie.org.hk/wp-content/uploads/hkie/file1/316a816/風水閒談-家居風水與人的關係Feb2021.pdf)).
- **이견 1**: 일부 작가는 "2024년은 역법상의 시작이고 기운에는 완충기가 있어 2026년(丙午)부터 화 기운이 뚜렷하다"고 본다([uptogo](https://uptogo.com.tw/?p=556046)). 통설이 아니므로 계산에는 쓰지 않고, 화면 설명에 "교체 직후 몇 해는 이전 운의 기운이 남는다고 보는 견해도 있다" 정도로만 밝힌다.
- **이견 2**: 5운(오황) 20년은 중궁이라 괘가 없어, 앞 10년은 坤(2), 뒤 10년은 艮(8)에 붙여 보는 유파가 있다. 오행은 어느 쪽이든 토(土)라 시대 오행 결과는 같다. 괘 표시만 '중궁'으로 둔다.
- 교체 시각: 입춘 '날짜' 기준으로 계산한다. 입춘 '시각' 직전·직후(2월 3~5일)는 기존 엔진처럼 경계 안내를 붙인다.
- 원전 대조: 이번 조사는 현대 출처와 기존 코드 기준의 일치 확인까지다. 『沈氏玄空學』 등 원전 판본 대조는 하지 않았다.

### 2-4. 해석의 층 구분(화면 문구 규칙)
1. 전통 이론의 상징: 구성·괘·오행이 전통적으로 뜻하는 것(예: 9운 離火 = 밝음·드러남·확산).
2. 거시 환경 해석: 그 상징을 '시대 분위기'로 읽은 해석. **해석임을 밝힌다.**
3. 현대 사회 현상과의 연결: 실제 통계·역사 자료가 있을 때만 쓴다. 이번 구현에서는 자료를 붙이지 않았으므로 **표시하지 않는다.**
4. 검증되지 않은 가설·전망: 쓰지 않거나, 쓸 경우 '가설'이라고 표시한다.

## 3. 오자원(五子元)

### 3-1. 확인된 것
- 문승현 저서 소개·목차: "오자원(五子元) 60갑자", "지지 중심으로 60갑자를 보는 체계", "오자원 공통심리 주기는 12년", "오자원 지지의 십성화 운동을 간지 공간운 해석에 쓴다"([교보 e북: 시간과 공간 융합연구서 구성 환경명리학](https://ebook-product.kyobobook.co.kr/dig/epd/ebook/E000012128490), [YES24](https://www.yes24.com/product/goods/163126130), [국운과 세계정세 흐름 예측 공간명리학 연구서](https://ebook-product.kyobobook.co.kr/dig/epd/ebook/E000012162198), [2026년 국운 기업운 주식운 예측](https://ebook-product.kyobobook.co.kr/dig/epd/sam/E000012445480), [거시명리학 기업 컨설팅 경영 공간명리학](https://www.yes24.com/product/goods/170331504), [KOBIC 도서정보](https://www.kobic.net/book/bookInfo/view.do?isbn=9791199567917)).
- 유사한 구분을 쓰는 개인 블로그 「河图五子运」: 60갑자를 甲子·丙子·戊子·庚子·壬子로 시작하는 12년씩 다섯 토막으로 나누고 각각 수·화·목·금·토에 배속, 2008~2019 戊子 목운, 2020년부터 庚子 금운이라고 쓴다([新浪 블로그](https://blog.sina.com.cn/s/blog_6e7756460100oae5.html)).

### 3-2. 확인되지 않은 것(구현하지 않은 이유)
- 저서 원문의 정확한 계산 규칙(토막의 시작 기준, 오행 배속 근거, 입춘·동지 경계)을 읽지 못했다(유료 전자책, 목차·소개만 확인).
- 블로그의 배속(河圖 순서 수·화·목·금·토)이 문승현 저서의 '금자원' 등과 같은 규칙인지 확인되지 않았다. 사용자가 언급한 '금자원'이 2020년 庚子 시작과 맞을 가능성은 있으나 **추정**이다.
- 학계 검증 자료 없음. 저자 스스로 "세계 최초 제시"라고 밝히는 독자 연구다.
- 따라서 오자원은 데이터 구조만 '연구 대기(status: research)'로 자리를 마련하고, 계산 결과를 화면에 내보내지 않는다. 저서 원문의 규칙을 확보하면 같은 틀에 추가한다.

## 4. 거시명리학의 개념(저자 설명 기준)
- 구성과 간지를 개인에게 적용하면 미시명리학(운명학), 전 인류에 공통으로 적용하면 거시명리학이라는 구분(저자 설명).
- 구성은 시간이 아닌 공간 개념으로 보고, 구성 공간대운과 간지 대운을 조합한다는 방법론(목차). 계산 규칙 미확인 → 연구 대기.
- 국운·주식운 예측은 저자의 주장이며 검증되지 않았다. 만트라 화면에 국운·주식 예측은 넣지 않는다.

## 5. 기존 개인 30년(`luck-cycle.js`)과의 구분
- `luck-cycle.js` '장기 분석 구간'은 **개인 대운 3개를 묶은 것**이다(대운수에 따라 사람마다 시작 나이·연도가 다르다). 시대 흐름이 아니다.
- 시대 흐름(삼원구운)은 출생 정보와 무관하게 모두에게 같은 20년 운이다.
- 둘의 이름과 설명을 화면에서 분리한다: '시대 흐름(삼원구운, 20년·공통)' / '나의 30년 장기 구간(대운 3개 묶음)'.

## 6. 개인과의 상호작용 판정 원칙
- 시대 오행은 개인의 용신이 되지 않는다. 용신·희신·기신은 기존 통합 용신 엔진(`ch.unified`) 판정을 그대로 읽는다.
- 시대 오행이 이 사람에게 어떤 역할인지(그 오행의 용신·희신·기신 여부, 이 사람에게 어떤 십성인지, 원국에 얼마나 있는지)로 판단한다.
- 시대 오행과 대운·세운 오행의 상생·상극은 '관계'로만 보여 주고, 길흉은 두 오행의 역할(용신/기신)과 함께 판단한다. 상극이라는 이유만으로 불리하다고 쓰지 않는다.
- 운세 흐름 점수·그래프·luck-cycle 결과는 바꾸지 않는다(설명용 별도 결과).
