# 관리자 문헌·명조 검수 조회 — 2026-10-17

관리자 점검·테스트 영역에 읽기 전용 문헌·명조 검수 화면을 추가했다. 합성 명조 32건, 직접 통근 참조 6건, G14/G15 경합 검수와 유사 문헌 명조를 조회·검색한다. 자료 기준일과 검수 한계, 문헌/평주 차이, 일치/불일치 조건, 모든 최종 판정 유보 상태를 표시한다.

/api/research-review는 관리자 인증 후 GET만 허용한다. no-store 응답이며 DB 및 외부 제공자에 접근하지 않는다. 정적 관리자 JS에는 명조 데이터가 없으며 인증 API가 서버 전용 functions/_research-review-data.js의 정제 스냅샷만 전달한다. 운영 백업·고객 자료·개인식별 정보·인증 정보는 포함하지 않는다. 웹 화면은 연구 기록 스냅샷이며 운영 DB의 현재 게시 상태를 의미하지 않는다.

규칙 게시, 검수 승인 처리, 전문가 지표 기록, 원문 추출, AI 생성 버튼은 없다. 기존 만세력 엔진·지식 규칙·챕터 DB는 변경하지 않는다. 이전 원문 검수 보고서와 비공개 output 자료는 이번 배포 커밋에서 제외한다.

검증: research-review-api-sim(인증 실패, GET 전용, 데이터 범위, DB/네트워크 미사용), admin-navigation-sim(메뉴 연결), research-review-browser(필터·사례 상세·비교 문헌·빈 검색·모바일·인증 실패), engine-baseline-sim(기존 엔진 기준선). API/화면 검증 성공은 명리 판정의 타당성 검증을 의미하지 않는다.
