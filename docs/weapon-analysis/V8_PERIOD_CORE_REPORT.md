## 2. 시기별 핵심 역량 판정 (지시 2·4)

**후보**: 운 천간 오행, 운 지지 정기 오행, 운이 끼어 완성한 삼합·방합 오행.

**원국과의 실제 작용 점수**

| 근거 | 점수 |
|---|---|
| 원국 통근(정기) | +2 |
| 원국 통근(여기·중기) | +1 |
| 원국 천간에 같은 오행 | +1 |
| 운 천간이 운 지지 지장간에 통근 | +1 |
| 운 천간·지지 정기가 같은 오행 | +1 |
| 지지 삼합·방합 성립 | +2 |
| 세력 있는(보통 이상) 원국 십성과 생으로 이어짐(식상생재·재생관·관인상생 등) | +1 |
| 운 천간이 원국과 합거(합화 불성립)·충 | −1 |
| 운 지지가 원국과 충 | −1 |

**선정 조건**
- 점수 **3점 이상**이어야 해요.
- 원국 통근·원국 천간·운 안 통근·합국 가운데 하나 이상이 있어야 해요.
- 그래서 운에 들어왔다는 이유만으로는 고르지 않아요.
- 2점 이하면 "뚜렷하지 않음 → 타고난 주무기 중심"으로 보여 줘요.
- 동점이면 천간 쪽을 앞에 두고, 다른 하나는 "함께 켜지는 역량"으로 적어요.

## 3. 타고난 주무기와의 관계 (지시 3)

| 핵심 역량이 주무기에 대해 | 관계 | 설명 |
|---|---|---|
| 같은 오행 | **강화** | 주무기가 그대로 이 시기의 핵심 |
| 주무기를 낳음 | 보완 | 바탕을 채움 |
| 주무기가 낳음 | 보완 | 결과로 연결 |
| 주무기가 다스림 | 보완 | 성과로 묶음 |
| 주무기를 누름 | **전환** | 중심이 옮겨 감. 주무기는 뒤에서 받치고 그 기능을 앞세움 |

- **활용 방향**: 주무기 십성 × 시기 역량 십성의 전략 문장(4판 25개)을 '이렇게 묶어 써요'로 붙여요.
- **시기 역량의 쓰임**: 그 오행의 용신 역할에 따라 "키우는 게 득 / 필요한 만큼만" 한 줄을 붙여요.
