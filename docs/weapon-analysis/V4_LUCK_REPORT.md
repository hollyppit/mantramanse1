### 판정 순서

**① 오행 축**
- 2단계: 운 천간이 주무기 오행이고, 운 지지에 뿌리가 있음
- 1단계: 다음 중 하나
  - 천간이 주무기 오행
  - 정기 뿌리
  - 삼합·방합이 주무기 오행을 만듦
- 0.5단계: 다음 중 하나
  - 생해 주는 기운
  - 얕은 뿌리
  - 반합·육합이 주무기 오행을 만듦
  - 합화가 성립해 주무기 오행이 됨
- 0단계: 위 작용이 없음
- 눌림: 천간이 주무기를 극함
- (5판에서 바꿈) 4판의 과잉 제한(이미 많은 힘이 세지면 '발현'까지로 낮춤)은 없앴어요. 강한 주무기가 다시 강해지는 것도 발현 강도에 그대로 반영하고, 과열 여부는 **활용 유리도**에서 따로 봐요.

**② 십성 축**
- 2단계: 같은 묶음이 천간에 나오고, 지지 통근이 있고, 원국과 같은 십신이거나 격국 역할이 있음
- 1단계: 다음 중 하나
  - 같은 묶음 투출에 통근·같은 십신·격국 역할 중 하나가 더해짐
  - 정기 통근과 격국 역할
  - 짝 작용(좋음·섞임)과 통근
- 0.5단계: **천간에 단순히 나오기만 함**, 통근만 있음, 짝 작용만 있음, 생조
- 제어:
  - 부담 조합 짝이 들어옴
  - 누르는 십성이 들어옴
  - 단, 원국에서 좋은 작용(예: 상관패인·식신제살)으로 성립한 누름은 제화로 보고 제약에 넣지 않아요.

**③ 합충형파해(한 번만 반영)**
- 반영하는 것:
  - 주무기 천간의 합거
    - 합화 조건: 월령의 같은 오행 또는 생, 충 없음
    - 주무기 오행으로 합화하면 지원으로 봐요.
    - 다른 오행으로 합화하면 성질이 바뀌는 제약으로 봐요.
  - 천간충
  - 뿌리 자리 충
- 형·파·해·원진은 "길흉 판단 없이 참고"로만 적어요.
- 같은 작용이 두 축에서 두 번 가감되지 않아요.

**④ 유형별 묶음**
- 오행형: 오행 축만 써요. 십성 기준을 넣지 않아요(제화 예외도 쓰지 않아요).
- 십신형: 십성 축만 써요. 단순 출현은 '보조·강화'까지예요.
- 복합형: 두 축을 따로 판정한 뒤 관계를 봐요.
  - 서로 강화: 둘 다 오름 → 하나가 2단계면 '강하게 발현', 아니면 '발현'
  - 서로 보완: 한쪽 오름, 다른 쪽 받침
  - 서로 상충: 한쪽 오름, 다른 쪽 제어 → '발현·흔들림'
  - 함께 제약
  - 함께 받침 / 한쪽만 받침
  - 작용 적음

**⑤ 마지막 단계**
- 오름이 있는데 합충·눌림도 있으면 '발현·흔들림'이에요.
- 받침과 누름이 함께 있으면 단계를 올리지 않고 '잠재·유지'로 두고, 카드에 "엇갈림"이라고 밝혀요.
- 눌림만 있으면 '제약·조정'이에요(이미 많은 힘이면 '덜어 내는 조정기').

## 3. 상세 카드 (지시문 3절)

대운·세운·월운 칸을 누르면 같은 구조의 카드가 열려요.

- **① 핵심 해석**: 첫 문장은 단계, 둘째 문장은 유형별 특징이에요.
  - 오행형: 오행 능력
  - 십신형: 십성 기능
  - 복합형: 두 축의 관계
- **② 작용 유형**: 강화형·보조형·유지형·제약형 중 하나예요. 복합형은 "오행 축 ○ · 십성 축 ○ → 관계"를 함께 보여 줘요.
- **③ 작용 근거**(사실만):
  - 오행 환경: 천간·지지 오행, 원국 비중, 주무기와의 생극
  - 십성: 천간·지지 정기 십신, 주무기 십신
  - 투간·통근
  - 합충형파해: 직접 작용과 참고를 나눠요.
- **④ 활용 방향**:
  - 활용 결: 운 천간 십성 기준 5결
  - 집중할 능력: 유형별, 짝 능력이 켜지면 조합 이름
  - 집중 분야
  - 전략 문장: [편·정 방식] + [주무기 묶음 × 운 십성 묶음, 25개] + [작용 유형별 강도]
- **⑤ 발현 지원 요인**·**⑥ 제약 요인**: 근거가 있을 때만 나와요.
  - '과하게 쓰여요'는 주무기가 기신·구신이고, 천간 또는 정기 뿌리로 세질 때만 써요.
  - 그때 실제로 과해지는 십성 기능(예: 식상 → 실행이 앞서고 검토가 약해짐)을 적어요.
- **⑦ 운의 유불리**: 기존 흐름 등급을 그대로 써요.
  - 천간과 지지를 각각 [오행 · 십신 · 통합 용신 역할(쉬운 말)]로 따로 적어요. 둘을 희신·기신으로 나눠 판정하지 않아요.
  - 행동 전략은 유불리 × 작용 유형 12개 문장이에요.

## 4. 문체 (지시문 5절)

### 발현 강도

### 활용 유리도 (새로 만듦)
강해진 주무기가 원국 전체에 유리하게 쓰이는지를 강도와 따로 판정해요. 계산은 `weapon.js` `useFavor`에 있어요.

| 기준 | 내용 | 가감 |
|---|---|---|
| 용신 역할 | 주무기 오행의 통합 용신 역할(엔진 `ch.unified.roles` 그대로) | 용신 +2 · 희신 +1 · 한신 0 · 구신 −1 · 기신 −2 |
| 일간 강약 | 역할이 한신일 때만 가름(용신 판정에 이미 들어 있어 두 번 세지 않음) | 신강: 비겁·인성 −1 / 식상·재성·관성 +1<br>신약: 반대 |
| 쓰임처 | 이 운에서 쓰임처(설기)가 열려 많은 힘이 빠짐 | +1 |
| 제화 | 좋은 누름(십신형·복합형만) | +1 |
| 부담 조합 짝 | 부담 조합이 함께 커짐(십신형·복합형만) | −1 |
| 과열 | 많은 힘이 쓰임처 없이 더 세짐 | −1 |

- 등급:

  | 합계 | 등급 |
  |---|---|
  | 2 이상 | 유리 |
  | 1 | 대체로 유리 |
  | 0 | 보통 |
  | −1 | 조절 필요 |
  | −2 이하 | 부담 |

- 발현 강도와 하나로 합치지 않아요. 기존 운세 흐름 등급과도 따로예요.
- 이제 화면에는 세 축이 나란히 나와요: 발현 강도 · 활용 유리도 · 흐름 등급.

| 칸 | 내용 |

| ① 핵심 해석 | 강도 문장, 유형별 문장, 활용 유리도 문장 |
| ② 발현 강도 | |
| ③ 활용 유리도 | 등급과 근거 줄 |
| ④ 작용 근거 | |

- **강화할 능력**
  - 활용 유리도가 보통 이상: 주무기 능력을 키워요. 오행형은 오행 능력, 십신형은 십성 기능, 복합형은 둘 다예요(짝 능력 포함).

- **조절할 기능**: 유리도가 낮거나 과열 근거가 있을 때 실제로 과해지는 십성 기능을 적어요. 부담 조합이면 그 긴장을 적고, 아무것도 없으면 "따로 없어요"라고 적어요.
- **유리도가 낮을 때**: 전략 문장의 강도 줄을 '범위를 넓히지 말고 한정해 써요'로 바꿔요.
- **칸(대운·세운·월운)**: '활용 ○' 칩을 하나 더 달았어요(파랑 유리, 노랑 조절 필요, 자주 부담).
