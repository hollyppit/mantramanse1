# 01. 주무기 판정 근거 보고서 (2026-11-26)

대상: `weapon.js`(판정) · `weapon-data.js`(문안) · `weapon-view.js`(화면) — 버전 `weapon-20261126-2`
원칙: 기존 엔진 값을 **읽기만** 하고, 새 가중치 점수를 만들지 않는다. 모든 조건은 "맞다/아니다"로 판정한다.

## 2. 판정 규칙

### 2-1. 요소 정의 (`elementFacts`)

| 조건 | 정의 | 근거·출처 |
|---|---|---|
| 세력 | `ch.weights.pct[e] ≥ 20%` | 오행 5개의 평균 몫(100÷5). 이 앱에서 쓰는 유일한 새 기준값 |
| 투간 | 일간을 뺀 천간(년·월·시)에 같은 오행이 있음 | 일간 자체는 '나'라서 무기로 꺼내 쓰는 글자로 세지 않음 |
| 통근 | 원국 지지 지장간(`M.HIDDEN`)에 같은 오행이 있음 | 엔진 지장간 표 그대로(2026-11-20 정정본) |
| 온전함 | 드러난 천간 중 하나 이상이 원국 안 천간합·천간충에 걸리지 않고, 뿌리 지지 중 하나 이상이 충을 맞지 않음 | 엔진 `ch.relations` 그대로. 형·파·해·원진은 길흉 판단 없이 근거 줄에만 기록 |
| 득령 | 월령 왕상휴수사에서 왕·상 | 엔진 `seasonal.states` |
| 병존 | 같은 천간(=같은 십성) 또는 같은 지지가 둘 이상. 인접(년월·월일·일시) 여부와 일간과 같은 글자인지 따로 기록 | `glossary-overlap.js` 뜻과 같음 |
| 간여지동 | 한 기둥의 천간 오행 = 지지 본기 오행 | 같은 파일 뜻과 같음. 병존과 **따로** 기록 |
| 깊은 뿌리 | 정기 뿌리 또는 월지 뿌리 | 자평 계열의 본기·월령 중시 |
| 세력 1위 | 다섯 오행 중 최종 세력 최대 | |
| 겉글자 수 | 지장간을 빼고 천간·지지 본기 오행만 센 개수 | 지장간 포함 세력(pct)과 구분해 표에 따로 표시(지시문 9-3) |

### 2-2. 선정 순서 (`judge`) — 가중치 없음

1. **핵심 조건**: 세력 ≥ 20% **그리고** 투간 **그리고** 통근 — 셋 다 맞아야 후보.
   "단순히 있는 것"과 "실제로 세력을 발휘하는 것"을 가르는 선(지시문 2-2 D).
2. **온전한 후보 먼저**: 합·충으로 묶이지 않은 후보만 비교. 모두 묶였으면 그대로 비교하고 '다듬어 쓰는 무기' 표시.
3. **보탬 조건 개수**: 득령 · 병존/간여지동 · 깊은 뿌리 · 세력 1위 — **같은 무게로 개수만** 센다.
4. 같은 개수면 세력 %로 순서만 정한다.
5. 최대 2개. **단 2위와 3위가 같은 개수면 보조 주무기를 두지 않는다**(세력 %만으로 2순위를 고르지 않기). 1위까지 같으면 **복합형**.
6. 후보가 없으면 **없음** — '숨은 힘'(세력·뿌리는 있으나 투간 없음)과 '가벼운 칼'(투간·뿌리는 있으나 세력 부족)을 따로 보여 준다.
7. **시간 모름**: 엔진이 시주를 비우므로 시주 근거는 자동으로 빠진다. 3기둥 판정 후, 시진 12개를 넣어 다시 판정해 첫 무기가 12개 모두에서 남으면 '잠정 확정', 아니면 **미확정**(유력 후보로만 표시).

### 2-3. 신뢰도 (판정 근거의 한결같음 — 정확도·성공 가능성 아님)

- 탄탄: 온전함 + 보탬 2개 이상 + 시간 앎
- 보통: 그 밖의 온전한 무기
- 약함: 다듬어 쓰는 무기 · 보탬 0개 · 복합형 · 미확정

### 2-4. 십성 작용 (`ten-god-weapon`)

주무기 오행의 일간 기준 십성 묶음(비겁·식상·재성·관성·인성)과 실제 드러난 천간의 십성(예: 상관)을 같이 쓴다.
해석은 `weapon-data.js` `elGroup[오행][십성 묶음]` 25칸 — 지시문 3절 표(오행 대표 주무기·과잉 주의)와 "목 + 식상" 예시를 그대로 확장했다.
**명식에 실제로 있는 십성만** 고른다(무기 오행이 곧 그 십성이므로 임의 부여가 없다).

`node tools/weapon-analysis/stats.cjs` → `stats.json`. dev 300(시간 있음) 기준, 판정(상태+오행)이 달라지는 명식 수 / 1순위가 달라지는 수.
