## 2. 유형과 표시 이름 (지시문 2·4절)

- **오행형**: 구조 역할 없이 오행의 세력·뿌리·계절로 두드러짐.
- **십신형**: 구조 역할(격·상신)이 있고 오행 쪽 보탬이 없거나, 십신형 경로로 들어온 경우.
- **복합형**: 오행 쪽 보탬과 구조 역할이 함께.
- **미확정**: 후보가 없거나(드러남·뿌리·세력도, 구조 십신도 없음) 1~3위가 같은 조건으로 동률.
- 표시 이름: `주무기` / `잠정 주무기`(1순위 신뢰도 약함 — 합·충으로 묶임, 보탬 0, 십신형 경로, 시간 모름 유지 9 미만) / `주무기 미확정`.
- 화면(만세력 원국·오행강약·특기적성 카드, 타임라인 종합풀이): 유형 칩, 잠정 표시, 십신 작용, 유형 설명, 용신과의 관계(활용 조건·제약), 파격 제약, 오행·강약 표에 '격국·상신' 열, 판정 순서 안내 갱신. 기존 UI 구조 유지.

## 4. 경계 사례 (지시문 5절)

- **주무기가 격국을 흔드는 쪽**: 1950-1-1 0시 여 토(식상) — 상관견관(구원 없음). 1999-12-22 21시 남 토(비겁) — 비겁탈재. → 주무기로 두되 제약 문장·신뢰도 최대 보통.
- **십신형 경로가 1순위**(세력 평균 미만): 1984-8-2 남 목(관성) 16.7%, 1976-10-4 3시 남 목(관성) 10.6%(식신제살 상신). → 모두 '잠정 주무기'.
- **기신·구신인데 복합형**: 1957-6-12 3시 남 화(식상) 구신 + 식신격 격 오행. → 강점이지만 활용 조건(용신 수가 받쳐 줄 때)·제약 표시.
- **세력 1위가 주무기가 아님**: 1965-3-27 6시 여 목 55.1%(재성)는 합·충에 묶여 뒤로, 토(인성)가 주무기.
- **동률 미확정**: 1989-2-28 3시 남 — 구조 조건이 들어오며 1·2·3위가 같은 조건 수가 됨(1판은 토 단일).

## 5. 오류·주의

- 건록·양인·월겁격을 처음엔 '격 오행'으로 쳐서 비겁 주무기에 구조 점수가 붙었다 → 수정(상신만 인정). 결과 수는 같고 유형만 복합형→오행형으로 30여 개 이동.
- 십신형 보조 주무기에 "조건 수가 같아 세력 %로 순서만 정함" 기록이 붙던 문구 수정.
- '잠정'인데 머리말이 "주무기 하나가 또렷한 명식이에요"로 나오던 문제 → 표시 이름을 따르게 수정.
- 남은 판단 필요: 십신형 경로 하한 10%(평균 몫의 절반), 부분 성립 격도 구조로 인정할지, 파격 주체를 주무기에서 뺄지(현재는 제약만).
