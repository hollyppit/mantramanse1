## 2. 십성 기능과 발현 방식 분리 (2~4절)

- 십성은 기능으로만 해석: 비겁 독립성·경쟁·주도성·추진력 / 식상 창작·표현·생산·기술·실행 / 재성 자원 활용·현실화·사업·성과 / 관성 책임·관리·통제·기준·완성도 / 인성 학습·연구·분석·축적 — "고정된 직업이 아니라 해석의 기본 요소"라고 화면에 명시.
- **짝 십성(발현 조합)**: 주무기 십성과 ① 성립한 상호작용으로 묶인 십성(좋음·섞임·부담) ② 없으면 천간에 드러나고 세력 보통 이상인 십성. 최대 3개.
- **조합 사전 10종**(비겁+식상 '독립 생산', 식상+관성 '완성도를 갖춘 창작', 식상+인성 '연구에서 나오는 창의', 식상+재성 '창작의 사업화', 관성+인성 '전문성 있는 체계' 등): 설명 · 활용 방향(창작·기획·연구·관리·사업·기술) · 강점이 사는 환경 · 일 · 돈. 부담 작용이 성립하면 긴장 설명(상관견관·재극인·도식·비겁쟁재)으로 — 조합을 무조건 긍정으로 보지 않음.
- **같은 십성의 다른 발현 형태 표**(5×4): 예) 관성 — 짝이 식상이면 '창작 활동의 기준·완성도 관리', 재성이면 '사업의 운영·통제', 비겁이면 '독립 전문 활동의 자기 규율', 인성이면 '조직·전문 체계 안의 책임과 관리'. 화면에 "주로 드러날 형태"와 "이 밖에 드러날 수 있는 형태"를 함께.
- **관성 = 조직형 단정 제거**: 커리어 유형 이름을 기능 이름(주도·추진형 / 창작·실행형 / 자원·성과형 / **책임·기준형** / 학습·분석형)으로, 관성·인성으로 '조직' 방향을 기대하던 비교 규칙 삭제, 관성 업무 문장을 "조직의 관리뿐 아니라 창작물의 완성도, 사업의 운영·통제, 혼자 하는 전문 활동의 자기 규율로도"로.

## 3. 결과 구성 A·B·C (5절) — 만세력 원국 카드

- **A · 타고난 핵심 역량**: 주무기 오행·유형·관련 십성·핵심 능력·형성 근거(기존 카드).
- **B · 능력의 발현 방식**: 기본 기능 → 짝 조합(근거: 성립한 작용/함께 드러난 힘) → 주로 드러날 형태와 다른 형태 → 강점이 드러나는 환경 → 과잉 작용 시.
- **C · 능력의 활용 조건**: 용신과의 관계(활용 조건·제약) → 지원 요소(격국·상신, 성립한 작용, 깊은 뿌리, 계절 힘, 용·희신) → 제약 요소(합·충, 뿌리 충, 파격, 부담 작용, 기·구신, 시간 모름 유지 수) → 운에 따른 발현 환경은 운세 흐름 탭으로 연결(원국 탭은 미래를 해석하지 않는 원칙 유지).
- 특기·적성 탭: 카드 + B. 오행·강약 탭: 판정표(격국·상신 열) 유지.
- 실제 직업·이력으로 판정을 역산하지 않음(입력에 직업 정보 없음).

## 4. 운세 흐름 연동 (6절)

운 한 기둥의 작용 유형에 **조합형** 추가: 운 천간의 십성이 주무기의 짝 십성이면 "주무기와 짝을 이루는 능력(예: 식상생재)이 함께 켜지는 때". 짝이 부담 조합이면 조합형 대신 제약("○○ 같은 부담 조합이 커지기 쉬워요"). 기존 강화(주무기 자체)·지원(생조)·발산(쓰임처)·조정(극·합·충) 유지 → 지시문의 네 가지 시기(자체 강화·지원 능력 활성·특정 기능 부각·과잉/충돌 제약)를 모두 덮음. 활성도와 유리도 분리 유지, 점수 산식 불변. 만세력 운세 흐름 상세 카드·유료 시기 줄 모두 같은 판정.
