# MANTRA FORTUNE — 나의 주무기 및 주무기 발현 타이밍 통합 구현 지시문 (사용자 원문, 2026-11-26 전달)

## 0. 프로젝트 목표

만트라 만세력에 새로운 분석 기능인 「나의 주무기」를 추가한다.

단순히 원국에서 가장 강한 오행을 찾아 주무기로 지정하는 기능이 아니다.

원국의 오행 세력, 병존, 간여지동, 통근, 투간, 십성의 구성과 역할을 종합하여 타고난 강점의 발현 가능성을 분석하고, 대운·세운·월운에서 해당 강점이 어떻게 활성화되고 활용될 수 있는지 보여주는 기능이다.

### 최종 적용 위치

다음 네 개 탭에 통합한다.

1. 원국 탭: 나의 주무기 오행과 형성 근거
2. 오행·강약 탭: 주무기 오행의 세력과 구조적 근거
3. 특기·적성 탭: 주무기의 구체적인 능력과 활용 방식
4. 운세 흐름 탭: 주무기의 대운·세운·월운별 발현 타이밍

새로운 최상위 탭은 만들지 않는다.

기존 화면의 디자인 시스템, 카드 스타일, 색상, 여백, 반응형 레이아웃을 최대한 유지한다.

- 병존 판정 로직 존재 여부
- 간여지동 판정 로직 존재 여부
- 지장간 및 통근 계산

- 십성 계산 및 공통 판정 모듈

- 기존 합충형파해 계산

기존에 구현된 계산 로직을 우선 재사용한다.

기존에 구현되지 않은 항목은 임의의 계산 결과를 만들어내지 말고, 구현 가능성과 필요한 기준을 먼저 확인한다.

## 절대 보호할 사항

- 기존 운영 엔진의 운세 점수 계산
- 기존 용신·희신·기신 판정

새로운 주무기 분석은 독립 모듈로 분리한다.

기존 엔진의 운세 점수나 길흉 등급에 주무기 점수를 합산하지 않는다.

# 2. 공통 주무기 분석 엔진 설계

새로운 독립 분석 모듈을 만든다.

파일 구조는 현재 프로젝트의 규칙에 맞추되, 다음 기능을 논리적으로 분리한다.

- element-strength: 오행 세력 분석
- pillar-patterns: 병존 및 간여지동 분석
- root-exposure: 통근 및 투간 분석
- ten-god-weapon: 십성 작용 분석
- weapon-selection: 주무기 선정
- weapon-timing: 운별 주무기 발현 분석
- weapon-interpretation: 사용자용 해석 생성

모든 화면은 공통 분석 결과를 참조한다.

탭별로 별도 주무기를 계산하지 않는다.

## 2-1. 주무기 선정의 핵심 원칙

주무기는 최대 2개까지 선정한다.

- 1순위: 원국에서 가장 뚜렷하게 형성된 주무기
- 2순위: 1순위와 결합해 능력을 보완하거나 확장하는 보조 주무기

단, 모든 명식에 억지로 주무기 2개를 부여하지 않는다.

뚜렷한 단일 주무기가 없으면 다음처럼 표현할 수 있다.

- 복합형 주무기
- 여러 오행이 균형을 이루는 유형
- 뚜렷한 단일 주무기 없음

주무기 선정 결과와 선정 신뢰도를 구분한다.

신뢰도는 명리학적 정확도나 성공 가능성이 아니라, 내부 판정 근거가 얼마나 일관되게 확보되었는지를 나타낸다.

## 2-2. 주무기 분석 요소

다음 요소를 종합한다.

### A. 오행 세력

- 목·화·토·금·수의 원국 내 분포
- 월령의 영향
- 천간과 지지의 오행 구성
- 지장간의 오행 구성
- 통근 여부
- 투간 여부
- 생극제화 관계

단순 개수만으로 강약을 결정하지 않는다.

기존 오행 강약 계산을 우선 사용하고, 주무기 분석을 위해 필요한 추가 정보는 별도로 구분한다.

### B. 병존

다음 형태를 구분하여 판정한다.

- 천간 병존
- 지지 병존
- 특정 오행의 반복
- 일간과 관련된 반복 구조

반복 횟수만으로 주무기 우선순위를 확정하지 않는다.

병존의 위치, 인접 여부, 통근 및 전체 명식에서의 역할을 함께 고려한다.

### C. 간여지동

일주를 중심으로 간여지동 여부를 판정한다.

일간과 일지의 오행 관계를 확인하고, 해당 지지가 일간에 힘을 제공하는지 분석한다.

간여지동이라는 이유만으로 신강이나 주무기 성립을 확정하지 않는다.

### D. 통근과 투간

- 천간이 지지에 뿌리를 두고 있는가?
- 지장간의 어떤 글자에 통근하는가?
- 해당 오행이 천간에 투출되어 있는가?
- 월령의 지원을 받는가?

단순히 오행이 존재하는 것과 실제 세력을 발휘하는 것을 구분한다.

### E. 십성 작용

주무기 오행이 어떤 십성 기능으로 발현되는지 분석한다.

- 비겁: 독립성, 경쟁, 추진, 자기주도
- 식상: 표현, 창작, 기술, 생산, 실행
- 재성: 자원 관리, 현실화, 사업, 성과
- 관성: 조직, 관리, 규칙, 책임, 통제
- 인성: 학습, 연구, 분석, 축적, 전문성

오행은 기본 성향을, 십성은 해당 성향이 발현되는 방식을 설명한다.

십성의 단순 존재만으로 해당 능력이 뛰어나다고 단정하지 않는다.

# 3. 오행별 주무기 해석 체계

다음 내용을 기본 해석 사전으로 사용한다.

| 오행 | 대표 주무기 | 과잉 시 주의점 |
|---|---|---|
| 목(木) | 기획, 성장, 개척, 추진 | 고집, 확장 과잉 |
| 화(火) | 표현, 전달, 창의, 홍보 | 충동, 과열 |
| 토(土) | 관리, 운영, 조율, 안정화 | 정체, 변화 저항 |
| 금(金) | 분석, 판단, 정리, 결단 | 경직, 완벽주의 |
| 수(水) | 통찰, 연구, 정보, 전략 | 생각 과잉, 실행 지연 |

이 표는 오행의 상징을 활용한 서비스 해석 기준이다.

실제 주무기 해석은 반드시 십성 및 원국 구조와 결합한다.

예를 들어 목(木)이 주무기인 경우:

- 목 + 식상: 기획한 것을 표현하고 결과물로 만드는 능력
- 목 + 재성: 기획을 사업이나 수익으로 연결하는 능력
- 목 + 관성: 조직 안에서 기획과 관리 능력을 발휘하는 방식
- 목 + 인성: 연구와 학습을 통한 전문성 축적
- 목 + 비겁: 독립적인 추진과 경쟁을 통한 실행력

다른 오행도 동일한 방식으로 오행과 십성의 조합을 구성한다.

실제 명식에서 확인되지 않은 십성이나 구조를 임의로 부여하지 않는다.

이 탭은 타고난 주무기의 형성 근거를 설명하는 데 집중한다.

# 5. 오행·강약 탭 적용

현재 오행·강약 탭의 기존 기능은 유지한다.

다음 영역을 추가한다.

## 추가 영역: 주무기 오행 분석

기존 오행 분포와 강약 그래프를 활용해 주무기 오행을 강조한다.

### 표시 항목

1. 오행별 세력
2. 주무기 1순위 표시
3. 보조 주무기 표시
4. 주무기 선정 근거
5. 병존·간여지동·통근·투간 정보
6. 관련 십성 작용
7. 과잉 작용 시 주의점

주무기 오행은 기존 오행 그래프의 색상을 유지하면서 테두리, 강조 라벨 등으로 구분한다.

기존 오행 수치 자체를 주무기 점수로 오인하게 만들지 않는다.

### 중요한 구분

- 오행 강약: 해당 오행의 세력
- 주무기: 해당 명식에서 두드러지는 능력의 활용 가능성
- 용신: 명식의 균형과 구조에서 필요한 기운

세 개념을 별도로 설명한다.

특히 가장 강한 오행이 반드시 주무기가 되는 것은 아니며, 용신과 주무기가 서로 다를 수 있다는 안내를 추가한다.

# 6. 특기·적성 탭 적용

현재 특기·적성 탭의 기존 적성 분석은 유지한다.

상단에 「나의 주무기」 영역을 추가한다.

### 표시 항목

- 주무기 1순위
- 보조 주무기
- 대표 능력
- 십성과 결합된 발현 방식
- 능력의 활용 방향
- 과잉 시 주의점
- 기존 적성 분석과의 연결

기존의 표현·창작, 기술·숙련, 신체 활동, 분석·탐구 등 적성 항목과 주무기 분석을 연결한다.

주무기 분석 결과와 기존 적성 분석이 서로 다른 경우 억지로 일치시키지 않는다.

예를 들어 주무기는 목(木)의 기획·개척이지만, 기존 적성 분석에서는 분석·탐구가 높을 수 있다.

이 경우 두 결과를 각각 설명하고 어떤 근거에서 차이가 발생하는지 보여준다.

주무기를 직업 추천으로 단정하지 않는다.

실제 직업 능력이나 성취는 환경과 경험의 영향을 받는다는 점을 고려해 표현한다.

# 7. 운세 흐름 탭 — 주무기 발현 타이밍

이번 기능의 핵심 확장이다.

기존 대운·세운·월운 그래프와 운세 점수는 그대로 유지한다.

기존 그래프 아래에 「주무기 발현 타이밍」 분석 영역을 추가한다.

## 7-1. 분석 대상

- 대운: 장기적인 주무기 발현 환경
- 세운: 해당 연도의 주무기 작용
- 월운: 단기적인 활용 환경

각 운의 천간·지지·지장간을 확인하고 원국의 주무기와 비교한다.

## 7-2. 분석 지표

주무기 발현은 다음 네 가지 지표로 분리한다.

### A. 주무기 활성도

주무기 오행이 해당 운에서 얼마나 두드러지게 작용하는지 평가한다.

- 같은 오행의 유입
- 생조 관계
- 천간 투출
- 지지 통근
- 월령과의 관계

### B. 발현 지원도

해당 운이 원국의 주무기 발현을 돕는 환경인지 분석한다.

오행 생조만 보지 말고 용신·희신·기신·구신·한신 및 원국 구조를 함께 고려한다.

### C. 활용 방향

주무기와 관련된 십성이 운에서 어떻게 활성화되는지 설명한다.

예:
- 식상 작용: 표현, 생산, 창작, 실행
- 재성 작용: 현실화, 수익화, 자원 관리
- 관성 작용: 조직화, 책임, 관리
- 인성 작용: 학습, 연구, 전문성 축적
- 비겁 작용: 독립성, 경쟁, 추진

### D. 제약 요인

- 합충형파해
- 주무기 오행의 극제
- 원국 내 과잉 구조
- 기존 용신 및 격국과의 관계

이러한 요소가 발현에 미치는 영향을 분석한다.

합이나 충이 있다는 이유만으로 무조건 길흉을 부여하지 않는다.

## 7-3. 반드시 구분할 두 가지 결과

**주무기 발현 강도**

해당 시기에 타고난 주무기와 관련된 기운이 얼마나 두드러지는가?

**주무기 활용 유리도**

그 기운을 실제로 활용하기에 원국과 운의 조합이 얼마나 유리한가?

두 지표를 하나로 합산하지 않는다.

주무기 활성도가 높더라도 기신의 작용이 강하거나 원국의 구조와 충돌하면 활용 유리도는 낮을 수 있다.

반대로 주무기 오행이 직접 강해지지 않아도 다른 오행의 지원이나 십성 작용으로 주무기가 발현될 수 있다.

## 7-4. 운별 UI

기존 운세 흐름 디자인과 통일한다.

### 대운

10년 단위의 주무기 발현 환경을 표시한다.

- 어떤 오행이 주무기를 지원하는가?
- 장기적으로 어떤 능력이 부각되는가?
- 과잉 또는 제약 요인은 무엇인가?

### 세운

연도별 주무기 발현을 보여준다.

- 해당 연도의 주무기 활성도
- 활용 유리도
- 주요 십성 작용
- 추천 활용 방향
- 주의할 작용

### 월운

월별로 주무기 활용 환경을 보여준다.

- 해당 월의 주요 오행 작용
- 주무기 활성화 여부
- 표현·실행·관리·학습 등 활용 방향

특정 날짜의 성공이나 실패를 예측하는 표현은 사용하지 않는다.

## 7-5. 그래프

기존 운세 그래프와 혼동하지 않도록 별도의 시각화를 사용한다.

추천 구성:

- 주무기 활성도: 실선 그래프
- 활용 유리도: 별도 보조 지표
- 해당 시기의 주요 오행: 색상 태그
- 시기별 상세 설명: 선택형 카드

기존 운세 점수 그래프와 동일한 점수 체계를 사용하지 않는다.

주무기 발현 지표의 수치가 명리학적 정확도나 실제 성공 확률을 의미하는 것처럼 표시하지 않는다.

# 8. 주무기 발현의 해석 규칙

다음 네 가지 작용 유형을 구분한다.

1. 강화형: 주무기 오행이 직접 강화되는 경우
2. 지원형: 주무기를 생하거나 돕는 기운이 작용하는 경우
3. 발산형: 주무기와 관련된 식상 등의 작용으로 외부 표현이 활성화되는 경우
4. 조정형: 주무기 오행을 제어하거나 구조를 정리하는 작용이 발생하는 경우

단, 이 네 유형을 오행별로 고정하지 않는다.

원국의 오행 세력과 십성 역할에 따라 작용을 다르게 해석한다.

예를 들어 목(木)이 주무기라고 해서 모든 수(水) 운을 준비기, 화(火) 운을 발산기로 고정하면 안 된다.

원국에서 목의 역할, 해당 운의 용신 관계, 십성 작용, 합충형파해를 반영한다.

# 9. 데이터와 계산의 신뢰성

주무기 분석 모듈은 다음 조건을 충족해야 한다.

1. 같은 명식에 대해 네 탭에서 동일한 주무기 결과가 출력되어야 한다.
2. 출생시간 미상인 경우 시주 관련 근거를 사용하지 않는다.
3. 지장간을 포함한 계산과 천간·지지 표면 오행 계산을 구분한다.
4. 병존과 간여지동을 동일한 개념으로 처리하지 않는다.
5. 오행 세력과 용신 판정을 혼합하지 않는다.
6. 주무기 후보가 복수인 경우 선정 이유를 기록한다.
7. 근거가 부족하면 미확정으로 표시한다.
8. 모든 결과에 계산 근거를 추적할 수 있어야 한다.

주무기 점수 가중치는 임의로 확정하지 않는다.

기존 오행 세력 계산과 구조 판정 결과를 먼저 분석하고, 새로운 가중치가 필요한 경우 다음을 기록한다.

- 가중치의 명리학적 근거
- 가중치의 적용 범위
- 다른 가중치 적용 시 결과 변화
- 주무기 선정이 달라지는 명식 수

근거가 부족하면 수치 점수 대신 근거 기반의 정성 판정을 우선한다.

# 10. 테스트 및 검증

기존 감사에서 사용한 300개 명식을 활용한다.

운영 엔진은 수정하지 않는다.

다음 사항을 검증한다.

### A. 원국 분석

- 병존 판정
- 간여지동 판정
- 통근 판정
- 투간 판정
- 오행 세력
- 십성 연결
- 주무기 1순위·2순위 선정

### B. 탭 간 일관성

- 원국 탭의 주무기
- 오행·강약 탭의 주무기
- 특기·적성 탭의 주무기
- 운세 흐름 탭의 주무기

네 곳의 주무기 판정이 동일한지 확인한다.

### C. 운세 흐름 분석

- 대운별 활성도
- 세운별 활성도
- 월운별 활성도
- 활용 유리도
- 합충형파해 반영
- 용신·희신·기신과의 관계

### D. 예외 사례

- 가장 강한 오행과 주무기가 다른 명식
- 용신과 주무기가 다른 명식
- 병존은 있으나 주무기 선정 근거가 약한 명식
- 간여지동이 있으나 전체적으로 신약한 명식
- 주무기 후보가 두 개 이상인 명식
- 뚜렷한 단일 주무기가 없는 명식
- 출생시간이 미상인 명식

예외 사례에서 잘못된 단일 주무기를 강제로 지정하지 않는지 확인한다.

### E. 기존 기능 회귀 테스트

- 원국 계산 변화 여부
- 오행 강약 계산 변화 여부
- 용신 변화 여부
- 격국 변화 여부
- 운세 흐름 점수 변화 여부
- 기존 특기·적성 기능 변화 여부

기존 계산값이 바뀌었다면 원인을 추적한다.
