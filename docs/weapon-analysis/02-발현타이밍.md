# 02. 주무기 발현 타이밍 계산 보고서 (2026-11-26)

## 1. 두 축 — 합산하지 않는다

| 축 | 질문 | 계산 | 표시 |
|---|---|---|---|
| **활성도**(발현 강도) | 이 시기에 주무기 기운이 얼마나 두드러지나 | 운 한 기둥(천간·지지·지장간)과 원국 주무기만 비교 — 아래 2절 | 단계 이름 7개 + 실선 그래프(숫자 눈금 없음) |
| **활용 유리도**(발현 지원도) | 그 기운을 실제로 쓰기에 원국·운 조합이 유리한가 | 기존 엔진 흐름 점수(`x.combined`, 없으면 `ev.fitScore`)를 `luck-grade.js` 3단계로 — **통합 용신·희신·기신·격국·합충이 이미 반영된 값을 그대로** | 좋음·무난·조심 보조 띠 |

두 값은 객체에서도 다른 필드(`best.level`, `favor`)이고 더한 값이 어디에도 없다(`tests/weapon-sim.cjs`가 `total`·`sum` 필드 부재와 유리도=엔진 등급 일치를 매 칸 확인).
화면 문장은 두 값을 **나란히 읽는 열쇠**(`readPair`)만 고른다 — 예: 켜짐 + 조심 → "잘하는 걸로 무리하기 쉬우니 범위를 줄여 쓰세요".

## 2. 활성도 판정 (`luckOne`)

| 신호 | 정의 | 유형(8절) |
|---|---|---|
| 천간 같은 오행 | 운 천간 오행 = 주무기 오행 | 강화형 |
| 지지 뿌리 | 운 지지 지장간에 주무기 오행(정기면 깊음) | 강화형 |
| 생조 | 운 천간 또는 지지 본기가 주무기를 낳는 오행 | 지원형 |
| 쓰임처 | 운 천간 또는 지지 본기가 주무기가 낳는 오행 | 발산형 |
| 극 | 운 천간이 주무기를 극하는 오행 | 조정형 |
| 합거·충 | `M.luckRelations`에서 원국 주무기 천간이 운과 천간합·천간충 | 조정형 |
| 뿌리 충 | 원국 주무기 뿌리 지지가 운과 충 | 조정형 |
| 형·파·해·원진 | 뿌리 지지에 걸림 — **길흉 없이 제약 줄에 기록만** | — |

단계: 강하게 켜짐(천간+뿌리) · 켜짐(천간 또는 정기 뿌리) · 켜지되 흔들림(켜짐 + 조정 신호) · 받쳐 줌(생조 또는 얕은 뿌리) · 조용함 · **눌림 / 정리**.
- 조정 신호만 있을 때, 주무기가 통합 용신 기준 **기신·구신(이미 많은 힘)이면 '정리'**, 아니면 '눌림'. 같은 극이라도 원국 역할에 따라 다르게 읽는다(지시문 8절 — 유형을 오행별로 고정하지 않기).
  실측: '정리' 칸의 유리도 좋음 62.5%(370/592), '눌림' 칸은 16.9%(69/409) — 엔진 점수와 방향이 맞는다.
- 주무기가 기신·구신인데 강화형이 오면 제약 줄에 "더 세지면 과하게 쓰기 쉬워요"를 붙인다(원국 과잉 구조).

**활용 방향**: 운 천간의 일간 기준 십성 묶음 → 비겁 독립·경쟁·추진 / 식상 표현·생산·창작·실행 / 재성 현실화·수익화·자원 관리 / 관성 조직화·책임·관리 / 인성 학습·연구·전문성.
**발현 지원**: 운 천간·지지 오행의 통합 용신 역할(용신·희신·한신·구신·기신)을 상세 카드에 그대로 적는다.

## 3. 300명식 결과 (dev 300 · 2026년부터 세운 10년 · 2026년 월운 12개월, 무기 없는 13명식 제외)

### 활성도와 유리도의 독립성

| | 켜짐 계열에서 '좋음' | 나머지에서 '좋음' | 켜짐 계열에서 '조심' | 나머지에서 '조심' |
|---|---|---|---|---|
| 대운 | 19.8% | 30.8% | 43.7% | 26.0% |
| 세운 | 16.0% | 32.2% | 39.4% | 26.9% |
| 월운 | 12.9% | 20.7% | 30.8% | 23.3% |

주무기가 켜지는 시기가 오히려 '조심'인 비율이 높다. 주무기의 절반(49.6%)이 통합 용신 기준 기신·구신, 즉 **이미 많은 힘**이라 더 세지면 균형 점수는 내려가기 때문이다.
두 값을 합쳤다면 "잘하는 게 켜진다 = 좋은 때"로 뭉개졌을 정보다 — 합산 금지가 실제로 필요한 이유를 데이터가 보여 준다.

## 4. 화면 (운세 흐름 탭, 기존 월운 카드 아래 · 일진 달력 위)

- 대운·세운·월운 각각: **활성도 실선 그래프**(단계 이름 눈금, 점 색 = 그 시기 천간의 오행) + **흐름 등급 보조 띠** + 칸(활성도 칩·흐름 칩).
- 칸을 누르면 **선택형 상세 카드**: 두 축 열쇠 문장 · 작용 유형 · 활용 방향 · 발현 지원(용신 역할) · 신호 · 제약 요인.
- 아래 '가까운 시기 읽기': 지금 대운 + 앞으로 10년 중 켜지는 해 최대 3개.
- 기존 운세 그래프·점수·카드는 그대로(새 카드 한 장 추가뿐). 숫자 점수는 보여 주지 않는다.
