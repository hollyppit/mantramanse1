# 9판 — 바람·칼날·결과 (2026-11-27)

## 기준

| 축 | 값 | 뜻 |
|---|---|---|
| 바람 | 운 흐름 등급(그 장이 이미 쓰는 점수: 인생 흐름·재물 지수·일 흐름 지수·전체 흐름) | 환경이 밀어 주는지 막는지 |
| 칼날 | 주무기 발현도(강하게 발현·발현·발현·흔들림 = 날이 섬 / 보조·강화 / 잠재·유지 / 제약·조정) | 내 무기가 얼마나 날이 서고 먹히는지 |
| 결과 | 활용 유리도(유리~부담) | 그 무기를 쓰면 사주 전체에 득인지 |

세 값은 그대로 두고 더하지 않는다. 운 점수·용신·격국·주무기 선정·전성기 순위는 바꾸지 않았다.

| | 바람 좋음 | 바람 무난 | 바람 조심 |
|---|---|---|---|
| 칼날 섬 | 전성기 | 발휘기 | 돌파기 |
| 칼날 쉼·눌림 | 순항기 | 정비기 | 정비기 |

칼날이 서는데 결과가 조절 필요·부담이면 "잘 먹히는 만큼 대가도 커요" 한 줄, 칼날이 쉬는데 결과가 유리면 "이때 갈아 둔 날이 다음에 득" 한 줄.
