## 1. 무엇을 하나 (`weapon.js` `crossCheck`)

### ① 세 탭 판정을 함께 읽어요

| 탭 | 읽는 값 |
|---|---|
| 원국 | 십성·통근·투간(주무기 facts) |
| 오행·강약 | 오행 세력(가장 강한 오행), 과다·부족 패턴(`MantraTenGodRoles.agreePatterns`), 십성 묶음 세력(강함·과다·약함), 일간 강약, 병존(facts) |
| 주무기 | 선정 결과 |

- 과다·부족 패턴은 십성 작용 판정과 맞춘 목록이에요. 예: 식상과다·재다신약·관살과다·인성과다·군겁쟁재·무○·○ 결핍.

### ② 세 자리를 구분해요 (지시 3)

| 자리 | 조건 |
|---|---|
| 기반 역량 | 주무기를 **낳는** 오행. 세력 20% 이상이거나, 십성 묶음 세력이 강함·과다거나, 2순위 무기일 때(세력 10% 이상) |
| 주무기 | 선정 결과 그대로 |
| 보조 역량 | 주무기가 **낳는** 오행. 6판 보조 역량(2순위 link)이거나, 성립한 생 작용(예: 식상생재)이 있고 세력 10% 이상일 때 |

- 화면에는 "기반 역량 → 주무기 → 보조 역량" 흐름과 각 자리의 기능을 보여 줘요.
- 예: "식상의 표현·창작·실행 기능이 바탕이 되어 주무기로 흘러 들어가요 → 재성의 자원 활용·현실화 기능으로 현실에 옮겨요(식상생재)"

### ③ 판정마다 주무기와의 관계를 적어요 (지시 1·2·4)
가장 강한 오행, 과다 패턴, 무·결핍, 일간 강약 하나하나를 관계로 설명해요.

| 관계 | 뜻 |
|---|---|
| 같음 | 그 판정의 힘이 곧 주무기 |
| 낳음 | 기반 역량 |
| 이어 받음 | 주무기가 낳는 쪽 |
| 누름 | 주무기를 누르는 쪽 |
| 다스림 | 주무기가 다스리는 쪽 |

- **지시 4번 예시(식상과다 → 재성 주무기)**:
  - 화면 문장: "식상과다(설기) 판정을 받은 목(식상)이 주무기를 낳는 기반 역량이에요. 넘치는 표현·창작·실행 힘이 주무기의 자원 활용·현실화 기능으로 빠져나가는 출구가 돼요."
  - 300+300명식 중 '과다 판정 오행이 주무기를 낳는 경우'는 22줄 있었어요(`v7-cross.json` examples.excessGen).
