## 1. 문제 — 丁未일주 사례 (庚戌년 癸未월 丁未일, 1970-07-26)

**5판까지의 결과**: 시간 모름일 때 금(재성) 한 개만 '잠정 주무기'로 잡혔어요.

| | 토(식상) | 금(재성) |
|---|---|---|
| 세력 | 38.5%, 1위 | 17.7% |
| 지지 | 戌·未·未 세 곳(정기 戊 상관·己 식신·己 식신) | — |
| 월령 | 장악(未), 사령 己 식신 | — |
| 병존 | 未未 지지 병존 | — |
| 천간 투출 | 없음 | 庚(정재) 투출 |
| 5판 판정 | 핵심 조건 '투간'이 없어 **후보에서 빠짐** | '십신형 경로'로 혼자 선정 |

- 지시문 6번(투출만으로 우선하지 않기)과 1~3번(지지 병존·지장간·월령·사령 반영)이 지켜지지 않은 상태였어요.

## 2. 바꾼 판정 (`weapon.js`)

| 지시 | 구현 |
|---|---|
| 1. 지지 병존 | `branchRep`(같은 지지가 둘 이상)을 따로 세요. 천간 병존·간여지동(`overlap`)과 분리했어요. |
| 2. 같은 오행 지지의 지장간·십성 | `sameBranches`: 같은 오행 지지마다 지장간 전부와 각 십성(여기·중기·정기)을 적어요. 근거 줄에 "같은 오행 지지 3개: 년지 戌(정기 戊 상관) · 월지 未(정기 己 식신) · 일지 未(정기 己 식신)"처럼 나와요. 지지 중심 경로 조건에 정기 뿌리 2곳 이상을 써요. |
| 3. 월령·사령 | `monthCmd`(월지 정기가 이 오행 = 월령 장악), `saryeong`(엔진 `ch.saryeong`: 절입 후 지금 주도권을 쥔 지장간)를 판정에 넣었어요. |
| 4. 강한 오행 + 십성의 구조 역할 | 순위를 **구조적 중요도**로 정해요(아래 표). 격국의 격 오행·상신, 성립한 실제 작용을 오행 세력과 함께 봐요. |
| 5. 식신생재 같은 이어짐 | 두 무기가 성립한 생(生) 작용으로 이어지면, **낳는 쪽 = 주무기, 받는 쪽 = 보조 역량**으로 둬요. |
| 6. 투출만으로 우선하지 않기 | 투간은 후보 조건일 뿐 순위 가점이 없어요. 또 **지지 중심 경로**를 새로 만들었어요. |
| 7. 병존·통근·투간은 자동 확정 조건이 아님 | 이 셋은 후보 조건과 가벼운 무게로만 써요. '주무기'(확정)는 3판 규칙대로 오행 근거와 십신 근거(격국·상신 또는 성립한 작용)가 둘 다 있을 때만 붙어요. |

### 보조 역량 판정
- 십성 작용 엔진(`ten-god-roles`)이 성립(on)으로 본 생 작용을 먼저 써요.
- 성립으로 안 나오면 격국 엔진의 켜진 상신(예: "재성으로 식신의 기운을 이어 줌(식신생재)")으로도 인정해요.
- 낳는 쪽이 구조적으로 같거나 무겁거나, 월령을 장악하고 있을 때 적용해요.
- 화면에서는 2순위 이름이 '보조 주무기' 대신 **'보조 역량'**으로 바뀌어요.
  - 카드 설명: "토(식상)가 낳는 힘을 이어 받는 쪽이에요(식상생재). 따로 서는 무기라기보다 주무기의 결과를 현실로 옮기는 역량이에요."
  - 유료 상세풀이 종합·재물·개운 블록도 '보조 역량' 문장으로 바뀌어요.

### 지지 중심 경로
천간에 같은 오행이 없어도 아래를 모두 갖추면 후보예요.
- 세력 20% 이상
- 월령: 월지 정기이거나 득령
- 지지 정기 뿌리 2곳 이상, 또는 지지 병존
- 뿌리 자리에 충 없음
- 일간 오행은 제외

카드에는 "천간에 드러나지 않았지만 월령과 지지에서 주도하는 힘이에요. 겉으로 내세우기보다 안에서 꾸준히 작동해요."라는 설명과 지지 십성 목록이 나와요.

### 구조적 중요도 (순위용, 같은 사실은 한 번만)

| 근거 | 무게 |
|---|---|
| 월령: 월지 정기(월령 장악) | 2(월겁·건록은 1) |
| 월령: 득령만 | 1 |
| 사령 | 월령 장악과 같으면 +0.5, 아니면 +1 |
| 격국의 격 오행 | 월령 장악과 겹치면 +1, 아니면 +2 |
| 켜진 상신 | +1 |
| 성립한 실제 작용 | +1 |
| 세력 1위 | +1 |
| 깊은 뿌리 · 지지 병존 · 천간 병존/간여지동 | 각 +0.5 |
| 투간 | 0(후보 조건일 뿐) |

- 이전(5판까지)에는 보탬 조건 6개를 같은 무게로 개수만 셌어요.
- 월령 장악·득령·사령·격 오행은 모두 월지에서 나오는 사실이라, 겹치는 몫을 줄였어요(중복 가점 방지).
