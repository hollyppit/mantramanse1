## 5. 미리보기 확인 (로컬 `report-static`, `?mantraFlags=weapon,aptitude`)

- 네 탭 모두 같은 `data-wp="single:3"`(예시 명식 1992-07-11 18:00 여) — 원국 '나의 타고난 주무기', 오행·강약 '주무기 오행 분석', 특기·적성 맨 위 '나의 주무기', 운세 흐름 월운 카드 아래 '주무기 발현 타이밍'.
- 모바일 375px: 가로 넘침 없음(scrollWidth = clientWidth), 그래프·칸 줄은 카드 안에서 가로 스크롤.
- 스위치 끔(`?mantraFlags=aptitude`): 네 탭 모두 주무기 블록 없음 — 기존 화면 그대로.
- 콘솔 오류: 주무기 파일 관련 없음(로컬 서버의 API·이미지 404만).
- 고친 점: 앱의 기존 `.now` 클래스와 겹친 칸 깨짐 → `.wp-now`로 분리, 금(金) 색 대비 부족 → 짙은 글자색 배경.
