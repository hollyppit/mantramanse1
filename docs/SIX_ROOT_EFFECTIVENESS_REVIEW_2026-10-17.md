### G02-N

해당 원국의 알려진 지지에는 진 근에 대한 술충이 보이지 않는다. 이는 진 근의 무손상·충분한 실효 강도를 증명하지 않는다. 인오 부분 배치·화 재성과 갑목 설기가 수 지원보다 우세한지는 유보.

## 보강한 적용 기준

1. 근 위치마다 ‘배속·문헌 직접 예시 → 해당 위치에 걸리는 관계 → 다른 지원 위치의 관계 → 계절·조후 → 전체 상대 작용’을 나눠 기록한다.
2. 근에 충 글자가 없다고 근이 완전·강력하다고 하지 않는다. 충 글자가 있어도 근 소멸 또는 개고 증강으로 고정하지 않는다. 충의 대상 성분·위치와 competing 합회를 확인한다.
3. 합의 글자 배속·완전 구성·실효 결속·합화·충 해소를 별도 필드로 둔다. 두 글자만으로 완전 삼합국을 만들지 않는다. 위치와 선후의 구체 문헌 예시를 다른 배치에 기계적으로 대입하지 않는다.
4. 조후와 억부 지원은 상호 참조하되 한쪽을 자동 우선시키지 않는다. 특정 계절의 다른 일간 예시를 임수·정화·병화에 그대로 전용하지 않는다.
5. 동일 장간의 직접 근, 인성 생조, 음간 장생 참조를 구별한다. 정유의 예외를 유 속 화 장간으로 바꾸지 않는다.
6. 수치 강도·지원/설기 비율은 이번 원문에서 도출하지 않는다. 실효 강도와 전체 재성·관성 과다는 독립 적용 논증이 마련될 때까지 unknown이다.
