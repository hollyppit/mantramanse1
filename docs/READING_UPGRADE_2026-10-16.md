## 현재 상태

기존 만트라 만세력의 engine.js 및 shared-core.js는 변경하지 않았다. 원국·십성·오행·신강약·용신·대운·세운·월운·일진·자미두수 계산을 기존 엔진에서 읽는다. AI가 계산값·새 용신·실제 개인 사실·미래 사건을 만들게 하지 않는다. 계산 기준선 120개가 일치한다.

## 관리자 사용법

1. **무빙툰 제작 → 챕터 계약·현실 사례**에서 79개 초안을 확인한다.
2. 질문·필수 근거·다른 장과의 차이·현실 장면·기존 장 ID·승인 지식 ID를 편집한다.
3. 주제·순서에서 노출과 순서를 조정하고 새 주제는 사용할 근거 정책을 선택한다.
4. 현실 사례에서 실제 인물의 개인정보를 넣지 않고 가정 사례·예외·전략·승인 근거·현실 답변 조건을 입력한다.
5. 초안 저장 후 생년월일/시각/성별을 넣고 계산·근거·행동 번역을 미리본다. 시간 미상도 허용한다. 이 미리보기는 AI 비용을 쓰지 않는다.
6. 실제 검토한 장·사례만 게시 대상으로 지정하고 **검사 후 게시**한다. 승인·게시·적용 조건·원문 연결이 부족한 근거는 게시를 막는다. 활성화한 장도 개별 원국에 적용 가능한 근거가 없으면 정상 해석으로 채우지 않는다.
7. 복구는 과거 상태를 새 초안으로 만들며 자동 재게시하지 않는다. 그 이후 만든 항목은 삭제하지 않고 보관한다. 저장 충돌이면 최신 버전을 다시 읽는다.
8. 사용자 화면의 목차 메뉴에서 **현실 상황 선택**을 열어 사례·전략에 쓸 상황을 선택한다. 닫거나 모두 비워도 기존 풀이를 읽을 수 있다.
9. **점검·테스트 → 시스템·서비스 점검**에서 생성 진단과 읽기/피드백 지표를 확인한다.

새 테이블/파괴적 마이그레이션은 없다. 기존 KV/Supabase 라우팅을 사용한다.

KV의 기대 버전 검사는 충돌 감지이며 트랜잭션 수준의 원자적 CAS가 아니다. 기존 저장소의 제한을 숨기지 않는다. 지표는 수집이 켜진 시점부터 누적되며 익명 세션 관찰값이다. 브라우저 종료 이벤트 누락 가능성이 있고, 10,000개 조회 상한에 걸리면 일부 집계라고 표시한다. 전체 리포트의 과거 데이터나 명리학의 예측 정확도로 해석하지 않는다.
