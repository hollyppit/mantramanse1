# 5. 수정 필요 여부 및 우선순위 (2026-11-25)

이 감사에서는 **아무것도 수정하지 않았다.** 아래는 제안이며, 실제 수정과 배포는 별도 승인 뒤에 한다. 유명인 검증 결과에 맞춰 바꾸는 항목은 없다. 모든 근거는 명리 이론의 일관성이다.

## 분류
| 분류 | 뜻 |
|---|---|
| **수정 권장** | 이론과 상관없이 엔진 안의 기준을 하나로 맞춰야 하는 것(정합성·표시) |
| **전문가 확인 후 결정** | 학파에 따라 갈리므로 사례집 검토 결과로 정하는 것 |
| **현행 유지** | 정합하거나, 선택한 학설이 타당하고 바꿀 근거가 없는 것 |
| **미확정** | 근거·측정이 부족해 지금 판단하지 않는 것 |

## 1순위 — 수정 권장(정합성)
1. **M1 구조 판정 하나로 맞추기**: 화면에 보이는 구조와 점수에 쓰는 구조를 같은 판정으로 통일한다. 화면은 ③ 화면 필터, 점수는 ② B안을 쓰고 있으며, 두 판정이 47%의 명식에서 엇갈린다.
   - 안 1: 원국 구조 목록(`patterns`)에 B안 성립 여부를 붙이고, 화면 필터도 그 값을 따른다.
   - 안 2: B안과 십성 작용 엔진의 판정을 대조해 한쪽 기준으로 합친다.
   - 영향: 표시가 바뀐다. B안이 기준이면 점수는 그대로다.
2. **M3·M4 제화 판정이 성립한 구조만 쓰기**: 영향은 작다(역할값 변화 2/300). 같은 기준으로 맞추는 정리 작업이다.
3. **M7 낡은 문장 정리**: 엔진 592줄의 "종격을 판정하지 않으므로"를 실제 상태(종격 판정 있음)에 맞춘다. 화면 결과는 바뀌지 않는다.
4. **M6 좋은 구조 표시에 역할 조건 붙이기**: 운 점수의 C안 기준을 원국 목록 표시에도 쓴다.

## 2순위 — 전문가 확인 후 결정(사례집 04)
5. **M2 운 합화 기준**: 원국과 같은 조건으로 운 합화 성립도를 볼지 결정한다. 감사 A안이 이 안이다.
   - 이론상 일관성 근거는 있다.
   - 유명인 검증에서는 정확도 개선이 확인되지 않았다(V1 '추가 검증 필요').
   - 따라서 **정확도 근거가 아니라 일관성 근거**로만 판단해야 하며, 대표 명식 대조가 먼저다.
6. **M11 가종 처리**와 **M12 종격 역할**(종재·종살의 비겁): 학파 기준을 정하고, 화면에 '학파에 따라 달라짐' 표시를 넣을지 정한다.
7. **M9 조후표 대조**: 조후·억부 충돌 사례 5건과 조후 주 기준 명식 일부를 『궁통보감』 일간×월 표와 대조한다. 일치율이 낮으면 조후표 모델을 검토한다.
8. **M10 경계 표시**: 돕는 힘 46~54% 명식에 '강약 경계' 안내를 넣을지 정한다(계산은 유지).
9. **M16 합·충 동시**, **M18 午未합**, **M19 공합**, **M14 사령**: 학파 선택을 문서로 고정하고 화면 용어 설명에 밝힐지 정한다.

## 3순위 — 미구현(필요성 먼저 판단)
10. **M17** 합 해소·충 해소
11. **M20** 화기격·일행득기격·양신성상격
12. **M21** 합살·거관유살
    - 공통: 사용 빈도가 낮고 판정 규칙의 학파 차이가 크다. 전문가 기준이 정해진 뒤에 설계한다.

## 현행 유지
- 합충형파해 표 전체
- 기신·구신 정의
- 희신 규칙
- 격 잡는 순서
- 건록·양인·월겁
- 진종 조건
- 통관 오행 계산
- 원국 합화 조건
- 운 점수의 격국·조후 가중 평균(이중 가산 아님)
- 조건부 역할 방식(복수 용신 절충)
- 종격 화면 모듈(엔진과 일치)

## 미확정
- **M13 한신 배치**: 오신 체계 자체의 한계라 바꾸려면 역할값 설계를 새로 해야 하며, 점수 영향은 미측정이다.
- **M15** 상신·파격의 위치·합거, **M23** 통관 위치 조건: 정밀도 개선 후보지만 점수 영향이 작을 것으로 보이며, 측정하지 않았다.

## 다음 단계 제안(승인 필요)
1. 사례집 30개를 전문가(명리 상담가 2인 이상)에게 블라인드로 보내 각 사례의 판정(엔진과 같음·학파 차이·오류·미확정)을 받는다.
2. 1순위 정합성 정리(M1·M3·M4·M6·M7)는 엔진 사본에서 먼저 시험하고, 바뀌는 명식 수와 화면 변화를 보고한 뒤 승인을 받아 반영한다.
3. 2순위는 전문가 판정이 모인 뒤 항목별로 결정한다.
