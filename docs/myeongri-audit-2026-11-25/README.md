## 핵심
1. **틀린 표나 반대로 된 규칙은 없다.** 합충형파해 표, 기신·구신 정의, 격국 체계, 진종 조건이 모두 고전 정의와 맞다.
2. **가장 큰 문제는 정합성이다.**
   - 같은 십성 구조를 세 곳에서 따로 판정한다. 그 결과 화면에 보이는 구조와 점수에 쓰는 구조가 **300개 중 142개 명식(47%)**에서 다르다.

3. **학파에 따라 갈리는 지점이 화면에 드러나지 않는다.**
   - 강약 경계(±3%p에서 억부 용신이 바뀌는 명식 35개)
   - 가종 9개
   - 조후 단순화 모델(78개)
   - 사령 기준 격(99개)
   - 종격의 비겁 역할
4. 미구현: 화기격·일행득기격·합살·거관유살, 합 해소·충 해소.
