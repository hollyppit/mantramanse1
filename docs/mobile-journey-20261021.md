# 모바일 실제 사용 흐름 검수

운영 `/report/v2/`를 360px iframe 뷰포트에서 가상 명식(1963-05-05 16:20, 여, 서울, 자동 보정)으로 검수했다. 실제 휴대전화 하드웨어 검사는 아니다.

## 수정

- 본문 로딩 후 교체된 문단을 읽기 위치 감지기가 다시 관찰하도록 수정했다. 이전 로딩 안내 노드만 감지하는 상태를 해소했다.
- 챕터 이동 시 선택·상단 제목·요청 우선순위를 스크롤보다 먼저 확정한다. 이동 직후 앞·뒤 챕터 감지가 선택을 덮어쓰지 않게 했다.
- 첫 챕터도 명시적으로 시작 위치에 맞추고 수동 이동 애니메이션을 600ms에서 320ms로 줄였다.
- 근거를 펼치면 자동 읽기를 멈추고 펼쳐진 내용의 길이를 다시 측정한다.
- 세계별 읽기에서는 일간·일주 뒤에 주제 지도로 자동 복귀하지 않는다. 이전 안내의 지연 실행도 다른 챕터를 방해하지 않게 했다.

## 확인

- 사주 입력 → 읽기 진입 → 전체 85개 챕터 순차 이동. 84회 다음/주제 전환에서 제목 불일치 0건.
- 빠르게 넘기는 동안 45회 임시 로딩이 관찰됐다. 모든 챕터를 선요청하지 않고 선택한 챕터와 이웃을 우선 요청하는 방식이며, 이 숫자는 영구 로딩 오류 수가 아니다.
- 마지막 챕터 정상 로딩과 다음 버튼 비활성화 확인. 이전·다음 왕복 제목 일치 확인.
- 자동 읽기 재생 → 근거 펼침 → 일시정지 확인.
- 기존에 대기 화면이 남던 10년 운 흐름 챕터 재방문에서 본문·근거 표시와 선택 유지 확인.
- 빠른 재방문 중 발견한 일간·일주 지연 지도 복귀를 수정하고 회귀 검사를 추가했다.
