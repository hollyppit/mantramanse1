## 상품 단위 (현재 세계 정의 `report/v2/explore.js` 기준)
| 상품 | 세계 id | 비고 |
|---|---|---|

가격은 코드에 박지 않고 관리자 화면에서 정한다(상품표 KV/DB 한 곳).
구매 단위는 **회원 × 사주(출생 정보) × 상품**이다. 같은 회원이 다른 사람 사주를 보려면 그 사주로 다시 산다(가족 사주 판매 여지).
→ 이 단위가 맞는지 확인 필요(회원 단위로 열면 사주를 바꿔 가며 무제한 열람 가능).

## 구조
```
브라우저(/report/)            Cloudflare Functions                 Supabase
 로그인 버튼 ───────────────▶ (카카오·구글) Supabase Auth ───────▶ auth.users
             ───────────────▶ /api/auth/naver (직접 OAuth) ───────▶ admin API로 사용자 생성
 구매 버튼 → 토스 결제위젯 ──▶ /api/pay/confirm (시크릿 키로 승인) ─▶ orders, entitlements
 본문 요청 ─────────────────▶ /api/movingtoon-reading (구매 확인) ──▶ entitlements 조회
```
- 회원: Supabase Auth. 카카오·구글은 Supabase 기본 지원. **네이버는 Supabase가 지원하지 않아** Functions에서 직접 OAuth를 처리하고 Supabase 사용자로 연결한다(+2일).
- 결제: 토스페이먼츠 결제위젯. 금액은 서버가 상품표에서 다시 계산해 위변조를 막고, 승인은 서버에서만 한다. 웹훅으로 취소·환불 상태를 맞춘다.
- 테이블(Supabase): `products`(가격·포함 세계), `orders`(주문·결제 키·상태), `entitlements`(회원·사주 해시·세계, 부여/회수 시각).

## 잠금 방식 — 중요한 제약
- 무빙툰 **장 본문**은 `/api/movingtoon-reading`(DB 게시본)에서 받아 온다 → 여기서 구매 여부를 확인하면 **서버에서 확실히 잠긴다**.
- 그러나 보강 층(서사 엔진 `life-narrative-data*.js`, 주제 심화 `topic-deep.js`, 후킹·통찰 문안 등 약 5.5MB)은 **사이트 JS 파일에 들어 있어** 화면에서만 가릴 수 있다. 개발자 도구로 일부 문장을 꺼내 볼 수 있다.
- 1차 출시: 본문은 서버 잠금 + 보강 층은 화면 잠금. 보강 층까지 서버로 옮기는 작업은 별도(+1~2주).
- 이미 있는 연결 지점: `report/v2/life.js`의 `H.gate`·`step.premium`(잠긴 장 안내), `premium_cta_click` 추적. 잠금 값은 지금 어디서도 켜지지 않는다.

## 사이트 잠금 분리
- 지금 `functions/_site-gate.js`가 도메인 전체를 비밀번호로 잠근다.
- 바꿀 것: `/report/`와 그 API·결제·로그인 콜백은 공개, 루트(만세력)·관리자는 계속 잠금. 결제사 심사 전에 필요.
- 결제사 심사·카카오 검수를 생각하면 pages.dev 대신 자체 도메인을 붙이는 편이 유리하다.

## 사용자(대표님)가 준비할 것
1. **토스페이먼츠**: 가맹점 가입 → 테스트 키(client·secret) 발급. 실결제는 심사 통과 후 라이브 키. 사업자등록증·통신판매업 신고 필요.
2. **카카오 개발자**: 앱 생성 → REST API 키·Client Secret, 비즈 앱 전환(이메일 받기). Redirect URI는 개발 시 알려 드림.
3. **구글 클라우드**: OAuth 클라이언트 ID·Secret.
4. **네이버 개발자센터**: 애플리케이션 등록 → Client ID·Secret, 검수 신청.
5. **Supabase**: 이미 있는 프로젝트를 쓴다. Auth 설정에서 카카오·구글 공급자를 켤 때 위 키를 넣는다(제가 안내).
6. **가격표**: 주제별 가격과 묶음 가격.
7. (권장) 자체 도메인.

키·시크릿은 채팅에 붙여 넣지 말고 Cloudflare Pages 환경변수와 Supabase 대시보드에 직접 넣는다. 코드는 환경변수 이름만 읽는다.
