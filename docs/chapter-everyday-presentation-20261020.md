# 생활 언어·챕터 시각화 개선 (2026-10-20)

- 기존 84개 사전 풀이의 계산 조건, 근거·인용문, 승인 상태를 유지했습니다. 원문 8개 파일의 추상적인 표현을 구체적인 돈·시간·일·사람의 행동으로 고쳤습니다.
- 기존 게시 문장에도 동일한 표현 정리가 적용되도록 서버의 최종 표시 문장과 공통 문체 모듈을 연결했습니다. 화면에서 근거·인용문은 접어 확인합니다.
- ‘~쪽이에요’ 등의 주요 문장을 직접적인 존댓말로 고쳤습니다. 사건·의료 예측을 단정하도록 변경하지 않았습니다.
- 챕터별 막대·오각형·세로 막대·점 그래프를 사용합니다. 실제 만세력 비율을 보존하며, 시계열 값이 없는 자료에 가짜 시간 추이·능력 점수를 만들지 않습니다.
- 자동차 챕터는 엔진·브레이크·연료·구동축·계기판에 대응하는 비유를 사용합니다.
- 패널은 본문 폭을 사용하고 세로 이미지는 자르지 않습니다. 일간·일주 챕터는 기존 awakening의 정확한 두 영상을 연결합니다. 운영 데이터는 포스터 없이 영상만 등록돼 있어 영상 단독 재생을 지원했습니다.
- ‘내 인생의 전성기는 언제?’는 기존 대운의 기회·확장·수확 구간을 사용하는 로컬 챕터입니다. 미래의 80세 미만 구간 중 가장 이른 구간을 먼저 보여주며, 성공 확률이나 임의 점수를 만들지 않습니다. 기본 84개에 로컬 챕터가 더해져 총 85개입니다.
- 이름의 ‘상생’ 등 글자를 명리 용어로 오인해 도입 문장을 숨기는 문제를 수정했습니다.
- 사용자 조회 경로에는 AI 제공자 호출을 추가하지 않았습니다. 자동연구 설정도 바꾸지 않았습니다.
