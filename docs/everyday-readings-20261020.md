# 생활 예시·운 흐름 설명 개선 — 2026-10-20

## 전체 풀이

- 기존 84개 챕터와 로컬 전성기 챕터에 질문별 생활 예시·실제 대화·작은 행동을 작성했다.
- 서버의 새 풀이와 클라이언트의 이전 캐시 화면에 같은 모듈을 적용한다. 같은 예시는 두 번 붙이지 않는다.
- 성향·돈·일·관계에는 답장, 회식, 카드 결제, 정기 구독, 작업 수정, 고객 안내 등 구체적 상황을 사용한다.
- 현침살은 실제 `specialStars`에 있을 때만 관련 5개 챕터에서 언급한다. 챕터마다 강점·예민함·직업 과제·제공할 도움의 예시를 다르게 썼다.
- 사용자 이름은 브라우저에서만 붙이고 HTML을 이스케이프한다. 서버의 이름 제거 규칙을 유지한다.
- 건강·안전은 일반 생활 예시이며, 창작은 일상에 빗대는 감상 질문이다. 질병·사고·전생 사실을 새로 주장하지 않는다.
- 어색한 조건 문구의 이어 붙이기 대신 기존 조건별 완성 문장을 사용한다. 과거 기본 템플릿도 원형과 일치할 때만 같은 방식으로 표시하고 관리자 수정본은 유지한다.
- 실제 문장에 기여한 템플릿만 구성 근거에 기록한다. 단순히 조건이 맞는 다른 구성요소를 적용된 근거처럼 기록하지 않는다.

## 운 흐름

`luck-reading.js`는 대운·세운·월운의 이미 계산된 값을 설명한다. 달력, 십성, 충 계산을 새로 만들지 않는다.

- 올해: 연도가 일치하는 `sewoon.stemTG`를 사용한다. 천간의 십성을 짧게 소개하고 실제로 해볼 수 있는 일로 연결한다.
- 대운: 실제 현재 기간에 해당할 때만 대운의 천간 십성과 흐름을 함께 설명한다.
- 충: 기존 엔진 `Manse.luckRelations`의 운-원국 지지 충만 사용한다. 원국 내부 충을 특정 날짜의 사건으로 바꾸지 않는다.
- 월운: 절기의 실제 시작일, 다음 절입일, 해당 양력 연도·월을 함께 전달한다. 2027년 1월을 2026년의 1월로 표시하지 않는다.
- 시주 미상: 존재하지 않는 시주와의 충을 전달하지 않는다.
- 이전 자료에 월운 연도·날짜가 없으면 특정 월의 충 설명을 생략한다. 모르는 십성을 간지나 흐름 이름에서 역산하지 않는다.
- 편인 하나를 사업 성공으로 연결하지 않는다. 전문 지식·고객 조사·작은 서비스 시험 등으로 설명하며 원국과 함께 계산된 흐름도 보여준다.
- 관리자 미리보기에는 사용자용 문장과 실제 십성·충 대상·기간을 함께 반환한다. 참고 예시를 원문 근거로 표시하지 않는다.

기간 검증 과정에서 대운의 다음 실제 시작 연도가 단순 `startYear+10`과 다를 수 있음을 확인했다. 어댑터는 엔진의 `daeunAt`으로 현재 대운을 선택하고 다음 대운의 실제 시작 시점으로 종료 기간을 전달한다. 만세력 계산과 점수는 변경하지 않았다.
