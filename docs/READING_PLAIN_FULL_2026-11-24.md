# 주제별 상세풀이 전수 검토·개선 (2026-11-24)

화면 코드만 바뀌었어요. DB 게시 문안은 그대로라 재게시는 필요 없어요. 다만 DB 원문 자체를 고쳐야 하는 항목은 아래 '남은 것'에 따로 모았어요.

## 검토 방법
- 자동 검사(`tools/reading-plain-audit.cjs`)
  - 상세풀이 페이지가 싣는 스크립트 154개를 같은 순서로 싣고, 게시 문안을 화면 역할로 넣어 사주 12개 × 107장을 그려요.
  - 사용자가 읽는 문장 약 7만 개(서로 다른 문장 약 1.6만 개)를 규칙으로 검사해요. 규칙은 용어로 시작, 용어 많음, 긴 문장, 내부 설명, 습니다체, 추상, 한자예요.
  - 문제 문장마다 출처 파일을 찾아요.
  - `--dump` 옵션을 주면 사주 2개의 장별 본문을 주제별 파일로 내보내요.
- 사람 검토: 검토자 5명이 사주 1명의 7개 주제 본문을 끝까지 읽고 약 220개 항목을 짚었어요. 요약은 공유 노트 `reading-plain-review-20261124.md`에 있어요.
- 결과 파일
  - 고치기 전: `docs/READING_PLAIN_AUDIT_BEFORE.md` (문제 962개, 5.8%)
  - 고친 뒤: `docs/READING_PLAIN_AUDIT_AFTER.md` (661개, 3.9%)
  - 남은 문제의 대부분은 접힌 '근거' 칸과 원국표 칸이에요.

## 고친 것
1. **같은 장 안에서 시기가 엇갈리던 문제(가장 큰 문제)**
   - 장 첫 문장, 서사 본문, '앞으로 10년' 그래프, '○○ 흐름 한눈에 보기' 그래프, '준비 달력'이 서로 다른 '가장 좋은 해·달·10년'을 말하고 있었어요.
   - 이제 해·달은 모두 `ReadingFeature.rank` 하나로 맞췄어요(`reading-text.js` rfScores, `fate-blocks-4.js`).
   - 10년은 그래프 점수 `topDecades`로 맞췄어요(`life-narrative.js` 재물 10년 문장).
2. **시기표 카드**
   - 칸 등급을 그래프와 같은 점수(`dwTier`)로 바꿨어요. 예전엔 모든 칸이 '흐름 좋음'이었어요.
   - 교운기 안내는 실제 해·나이로 바꾸고("2027년에 10년 운이 바뀌어요. 2026~2028년(만 34~36세)은…"), 맺음 고지와 함께 리포트에서 한 번만 보여 줘요.
   - '같은 흐름이 10년 더' 문장은 장마다 다른 문장으로 바꿨어요.
   - 자녀·결혼 장에서는 스무 살 안팎의 지나온 칸을 빼요.
3. **근거 문장 쉬운 말**
   - 게시 문안의 정해진 틀을 화면에서 바꿔 보여 줘요(`reading-text.js` plainSay). 예: "일간을 돕는 힘이 상대적으로 약한 쪽(신약)이라" → "내 힘이 약한 편(신약)이라".
   - 엔진·문안 같은 내부 말을 걷고, 조사 오류(인성가, 무·기은)를 고쳤어요.
   - 서사 근거 줄의 한자 글자쌍, 온도 숫자, 근거 강도 문장도 쉬운 말로 바꿨어요(`life-narrative.js` plainEv).
4. **내면의 구조(프리미엄 심화)**
   - 기운 이름을 짧은 생활어로 바꾸고, 본문 비율에서 용어를 뺐어요.
   - 네 묶음을 한꺼번에 견주던 13개 함수를 '결론 먼저, 숫자는 둘까지'로 다시 썼어요.
   - 괄호 속 괄호를 없앴어요.
   - 인연 장은 관계의 말로 바꿨어요. 남성의 인연 기운이 '돈을 다루는 힘'으로 읽히던 문제예요.
5. **포인트 블록**
   - 12운성·십성·글자 관계·운의 관계 문단을 '생활 모습 먼저, 근거(자리·용어) 뒤'로 바꿨어요.
   - '지금 대운은 비겁의 기운이라' → '지금 10년은 내 힘을 세우는 기운(비겁)이 들어오는 때라'로 바꿨어요(60개).
   - '기후' 비유는 '편'과 '온도'로 바꿨어요.
6. **신살·글자 관계 문단(chart-lines)**
   - 순서를 '있어요 → 뜻 → 생활 풀이 → 내 사주의 자리'로 바꿨어요(예전엔 뜻이 조언 뒤에 왔어요).
   - '이 장에서도 드러나요' 같은 내부 단위 말을 쓰지 않아요.
   - '내 사주에서는 년주(…)에 있어서'처럼 조사가 겹치던 문장을 '이 별은 내 사주의 어린 시절·가족 자리에 있어요.'로 바꿨어요.
7. **기타**
   - 숨은 합(암합) 문장을 생활 먼저로 바꾸고 한자 뒤 조사를 고쳤어요.
   - 깊이 블록에서 강점 문단 바로 뒤 약점 문단에 '대신'을 붙였어요.
   - self_21의 '3년쯤 뒤면'을 실제 해로 바꿔요("내년(2027년)이면").
   - 그래프·원국표·내 사주 상자·재물 그릇의 안내 문장을 쉬운 말로 바꿨어요.
