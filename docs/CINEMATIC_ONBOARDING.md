## 관리

관리자 → 콘텐츠·온보딩 → 시네마틱 온보딩에서 장면 추가·삭제·정렬·활성화, 독백 구간과 초 단위 시간, PC/모바일 영상·이미지, 전경, 카메라 움직임, 전환 효과와 시간, 봉인 이미지와 문구를 편집한다. 0초는 글자 수 기반 자동 시간이다. 업로드와 기존 미디어 선택을 지원한다. 초안 저장·미리보기·게시·게시 이력 복원은 기존 인증과 API를 사용한다. 이전 5개 씬은 '이전 온보딩 편집'에 보존되어 있다.

기본 시각 자료는 기존 quest 이미지다. 요청한 도시·가족 일상 등의 새 영상은 제공되지 않아 제작하거나 업로드한 상태가 아니다. 관리자에서 해당 영상을 등록하면 무음 자동 재생·반복되며 독백 변경 시 영상은 유지된다. 영상 실패 시 등록된 이미지가 남는다. 모바일 미디어가 없으면 PC 미디어를 cover 크롭한다.

## 저장과 복구

DB 스키마 변경 없이 `free:onboard` 및 `free:onboard:draft`의 `renewal.cinematic`에 추가한다. 기존 키와 미디어를 삭제하거나 변환하지 않는다. 최초 개발은 로컬에서 수행했고, 후속 사용자 요청에 따라 운영 배포와 게시 검증을 완료했다.

운영 반영 전 기존 관리자 API `GET /api/onboarding?draft=1` 응답과 공개 `GET /api/onboarding` 응답을 별도 파일로 보관한다. 기존 게시 절차는 게시 직전 공개본을 `free:onboard:hist` / `free:onboard:h:<id>`에 보존한다. 기존 미리보기·게시 관리에서 이력 복원 → 초안 확인 → 게시로 복구한다. 시네마틱 사용을 끄고 저장·게시하면 보존한 기존 온보딩으로 돌아간다. 코드 롤백은 이번 변경 파일을 이전 Git 버전으로 되돌리고 배포한다. 운영 데이터에 새 필드가 남아 있어도 이전 코드는 이를 사용하지 않는다.
