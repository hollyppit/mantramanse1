## 실패 진단과 수정

- 이전 plan-rejected는 구체적 원인 기록이 없었다. 새 진단에서 OpenAI 기획 제한시간 초과와 Anthropic의 빈 출력/출력 한도 소모를 관찰했다. 모든 이전 실패의 원인을 하나로 확정하지 않는다.
- 기획·집필·검토의 JSON Schema, 단계별 시간 예산, 전생 전용 낮은 추론량/Anthropic thinking 비활성화, 출력 완료·중단 메타데이터를 추가했다.
- 중복 예시·행동 제안·메타데이터·구조 관측의 중복 값은 기획 입력에서 제외했다. 검수 판단·조건·예외·반대 근거·원국은 유지하며, 독립 검토에는 출처 원문도 전달한다.
- 최종 첫 사례의 OpenAI 기획 입력은 12,451토큰이었다. 앞선 실패 사례의 Anthropic 기획 입력 33,529토큰보다 작다. 제공자가 달라 엄밀한 토크나이저 동등 비교는 아니다.
- 최종 첫 사례는 OpenAI gpt-6.1-sol에서 기획 47,742ms, 집필 59,040ms, 검토 14,827ms, 수정 집필 49,646ms, 재검토 4,097ms로 진행돼 통과했다. 실제 검토 후 수정 경로도 작동했다.
- 이름·생년월일·원고·비밀키를 실패 기록에 저장하지 않는다. 안전한 필드 경로/분류/제공자/모델/시간/토큰만 24시간 보존하고 관리자 인증으로 조회한다.
- 관리자 원고 출력에 기획·검토·원문 근거·성공 호출 메타데이터를 추가했다. 비인증 사용자 응답에는 이 자료가 없다.

## 실제 문학 검수

초기 past-story-5 두 원고는 북/종만 바뀐 유사한 산성 이야기였다. 이 상태를 차별성 통과로 보지 않고 보완했다.

같은 슬롯의 최근 기획 최대 6개를 창작 줄거리 요약으로 참고한다. 원국·판단 ID·캐시 식별자는 이 참고 자료에 포함하지 않는다. 이름·사건 원인·적대 동기·딜레마·해결법의 재사용을 피하고, 독립 검토에서도 소품만 바꾼 동일 구조를 거부하도록 했다. 슬롯 인덱스는 KV 기반 최근 참고 자료이며 전 세계 모든 과거 작품의 유일성을 보장하지 않는다. 동시 생성에서는 최근 기록 반영에 경쟁 조건이 있을 수 있다.

최종 두 원고를 직접 읽었다. 첫 작품은 신병의 기억을 쓰는 방어 비술을 포기한 뒤 지형과 협업으로 대체 방어를 세운다. 두 번째는 자신의 거짓 전공을 인정하고 포로패를 증거로 보존해 처형을 막는다. 초반 단서, 양쪽 대가가 있는 선택, 해결 방식, 마지막 회수 소품이 다르다. 직업·시대·의복은 같은 무관 슬롯과 맞는다.

관리자 기본 테스트 사주에서 최종 첫 원고를 실제로 불러왔고, 원문 판단을 대조했다. 원칙성, 평가·책임의 압박, 지지·학습·동료의 필요가 인물의 습관·약점·협업 선택에 연결된다. 픽션 사건을 실제 이력이나 전생 사실로 주장하지 않는다. 두 사례는 표본 검수이며 모든 원국·50개 슬롯의 문학 품질을 보증하지 않는다.
