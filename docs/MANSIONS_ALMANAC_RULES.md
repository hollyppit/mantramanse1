# 28수 택일 규칙 원문 대조 (2026-11-21)

규칙마다 문헌·판본·권차·원문·번역·해석·계산 방식·검증 단계를 적었다. 문헌이 해당 행사를 직접 말하지 않으면 "언급 없음"으로 두고 넓혀 해석하지 않았다. 면(葉) 번호는 Kanripo 쪽 표지(예: 001-27a)이며, 원본 이미지와는 대조하지 않았다.

## 1. 날짜별 28수 배속법

| 항목 | 내용 |
|---|---|
| 문헌명 | 《흠정협기변방서》(교차: 《어정성력고원》 卷5) |
| 판본 | 文淵閣 四庫全書本 전산(위키문헌·Kanripo KR3g0051 일치) |
| 권차 | 卷一 本原 「二十八宿配日」 |
| 페이지 | Kanripo 001-27a~28b |
| 원문 | 「考原云日有六十宿有二十八四百二十日而一週…一元甲子日起虚…二元甲子起奎三元甲子起畢四元甲子起鬼五元甲子起翼六元甲子起氐七元甲子起箕至七元盡而甲子又起虚周而復始但一元起於何年月日則不可得而考矣」 / 「其宿曜之名虚昴星房屬日危畢張心屬月室觜翼尾屬火壁參軫箕屬水奎井角斗屬木婁鬼亢牛屬金胃柳氐女屬土…七元周而復始恰與此相符」 |
| 번역 | 날은 60(간지), 수는 28이라 420일에 한 바퀴 돈다. 1원 甲子日은 虛에서, 2원은 奎, 3원은 畢, 4원은 鬼, 5원은 翼, 6원은 氐, 7원은 箕에서 시작해 되풀이한다. 다만 1원이 어느 해 어느 날 시작했는지는 알 수 없다. 수의 칠요 이름(虛昴星房은 日 …)과 이 일곱 원의 순환이 꼭 맞는다. |
| 해석 | 날마다 수가 하나씩 이어진다(卷36 楊公忌 조: 「每日一宿自然順序不用安排」). 甲子日의 수는 위 7수 중 하나이고, 각 수는 요일(칠요)이 고정이다. |
| 계산 방식 | 조건 ① 甲子日의 수 ∈ {虛,奎,畢,鬼,翼,氐,箕}(수 번호가 4칸 단위로 정해짐). 조건 ② 수의 칠요 = 그날 요일(7칸 단위로 정해짐). 4와 7은 서로소이므로 ①·② 두 조건만으로 날마다 수가 하나로 정해진다. 원전에 없는 것은 "칠요 日=일요일"이라는 요일 대응뿐이며, 《협기변방서》는 日曜를 회골·파사의 「蜜」, 즉 서역 칠요 日이라고 밝힌다. |
| 검증 단계 | 協紀 卷1: edition_verified(2026-11-22, IA 06056502.cn n147·n150, 원본 면이 전산과 같음). 卷36 葉39a에도 같은 七元 목록이 있음. 考原: text_verified |

- 현재 엔진 점검(2026-11-21): 기준일 2026-11-21=女로 420일을 계산하면 甲子日 수가 정확히 {虛,奎,畢,鬼,翼,氐,箕}이고, 칠요도 모두 맞는다. 현대 역서(중국 노황력)가 준 기준일과 원전 규칙이 같은 결과를 낸다.
- 1원의 시작일(절대 기점)은 원전이 "알 수 없다"고 하므로, 몇 번째 원인지는 표시하지 않는다.
- 《선택기요》(1867): 「但看官曆上甲子日下値虛宿便是一元」 — 관력에서 甲子日이 虛면 그날부터 1원.

## 2. 伏斷 (일지 ↔ 수)

| 항목 | 내용 |
|---|---|
| 문헌명 | 《협기변방서》 卷36 辨譌 / 《구선주후경》(고금도서집성 卷684) / 《옥갑기》 / 《선택요략》 上 / 《선택기요》 上編 |
| 판본 | 각 전산본 |
| 원문 | 協紀: 「以子日起虚丑值斗亥值壁…戌值胃酉值觜申值鬼未值張午值角已值房辰值箕夘值斗寅值室」 / 選擇紀要: 「子虛丑斗寅嫌室。卯女辰箕巳怕房。午角未張申値鬼。酉觜戌胃亥壁當。」 |
| 번역 | 子日에 虛, 丑日에 斗 … 亥日에 壁이 들면 伏斷일이다. |
| 해석 | 12쌍: 子虛 丑斗 寅室 卯女 辰箕 巳房 午角 未張 申鬼 酉觜 戌胃 亥壁. |
| 계산 방식 | (일지, 그날 수)가 위 12쌍이면 伏斷. 卯는 女를 따른다. 근거는 세 가지다. ① 丑斗와 같은 수가 되어 주기상 불가능하다. ② 다른 네 문헌이 卯女다. ③ 協紀 같은 권의 표·본문이 卯女를 가리킨다. 「夘值斗」는 四庫 원본 면(卷36 葉39a)에 실제로 있으며, 寫本 내부 불일치로 본다(2026-11-22 대조). |
| 검증 단계 | 協紀 卷36: edition_verified(IA 06056527.cn n75·n80). 나머지 4종: text_verified, 교차 일치(전산) |

- 현재 엔진: 12쌍이 모두 84일 주기 안에서 나온다(卯女 포함). 엔진의 자체 점검(`mansions-day.js` checkAssign)은 卯를 뺀 11쌍을 쓴다.
- 協紀는 伏斷을 "與旬空路空之義相似尚屬有理"라 하면서도 用事 宜忌표(卷11)에는 넣지 않았다.

## 3.1 《옥갑기》 판본 대조 (2026-11-25)

### 확보한 판본
- 《續道藏》(1607)의 《諸神聖誕日玉匣記等集》. 현존 옥갑기 중 가장 오래된 수록본이다.
  - 그 안의 「法師選擇記」에 「二十八宿吉凶日」이 있다.
  - 도장 三家本 36책 332c–335a쪽의 영인 원본 면을 직접 읽었다(IA `daozang05_202201`, daozang36 jp2 0335–0338).
  - 목록(36책 317쪽)에는 「二十八宿吉凶之圖」로 올라 있다.
- 형식: 수마다 머리줄(예: 「角木狡[蛟] 凶 鄧禹」)과 칠언 8구다.
- 다루는 행사: 祭祀·嫁娶/婚姻·開張(개업)·起造/修造·移徙(이사)·入宅·埋葬/安墳·上官.
  - 현재 위키문헌 노래에는 없는 개업·이사 언급이 이 판본에는 있다.

- Kanripo 전산본(KR5h0051)에는 판독 오류가 있다(예: 室火猪→「室灭猪」, 虛日鼠→「虛日㐫」). 화면에 쓰려면 원본 면에서 다시 옮겨야 한다.

### 판단
- 판본에 따라 길흉이 절반 넘게 뒤집힌다. 따라서 "옥갑기에 따르면 이 날은 길/흉"이라는 단일 판정은 근거가 없다. 현재처럼 판정하지 않는 것이 맞다.
- 판정을 하려면 사용자가 따를 전통(판본)을 정해야 한다.
  - (ㄱ) 《續道藏》본을 판본 확인 프로필로 추가하고, 화면에는 두 판본을 나란히 보여 준다.
  - (ㄴ) 하나를 기본으로 정한다.
- 위키문헌 노래 쪽 간본(乾隆·光緒 刻本 등)은 아직 확보하지 못했다.

## 4. 날짜 시험 자료
- 《나진자》(고금도서집성 卷686) 「五角六張」: 紹興 癸丑(1133) 음력 4월 5일=角, 7월 26일=張, 10월 25일=角.
- 남송 역서의 해당 날짜를 양력(율리우스 적일)으로 바꿀 수 있어야 시험할 수 있다. 이 앱의 음력 계산은 1133년을 다루지 않아 **시험하지 못했다**.

## 5. 적용하면 안 되는 자료
- 《숙요경》: 27수 월숙 체계(수가 요일에 고정되지 않음). 協紀도 「與中國風俗迥然不同」이라 함. 중국 28일 값일수에 옮겨 쓰지 않는다.
- 年禽·月禽·時禽(《금성이견》, 《선택기요》): 연·월·시 단위 규칙. 날 규칙으로 넓히지 않는다.
