# 구현 결과 (2026-10-13)

## 완료한 변경
- 종합 상품은 요청 순서의 15주제를 기본 읽기 흐름으로 제공한다. 원본 챕터 ID와 데이터는 유지하고 주제별로 재배치한다. 기본·심층 챕터의 실제 수는 15보다 많으며 추가 상세는 “더 깊이 읽기”로 펼쳐 읽는다. 관리자 지정 모듈·에셋·특화 상품을 삭제하거나 저장본을 덮어쓰지 않는다. 기존 세계 지도는 explore=1에서 유지하며 map 확인 경로도 보존한다.
- 각 주제의 핵심 풀이에 8요소를 제공한다. 원국 십성군·신강약·월주, 통근 및 시간 미상 조건을 함께 읽고 직업 상위 분야·재성/식상·관계 합충·시간축·학파별 후보를 분야별 근거로 사용한다. 사실은 모델의 출력으로 표시하고 해석과 실천 제안을 구분한다.
- 단일 일간에 고정된 장단점 풀이를 조건 결합 설명으로 교체했다. 기존 상세와 창작 이야기는 보존한다. 핵심 성향을 여러 챕터에서 다시 읽는 부담을 줄이고 그래프/계산표는 본문에 유지한다.
- AI에 문단 역할을 전달하고 고정 사실/학파 근거는 재작성에서 제외한다. 엔진 후보의 임의 용신 선정 지시를 제거했다. 없는 신살·귀인·격국 명칭, 원국 비중 불일치, 숫자 부분 문자열 우회 및 챕터 간 동일 생성 문장을 거부한다. 검증 실패 시 기존 설명을 유지한다.
- 관리자 해석 모듈에 공통 설명 템플릿 입력을 추가했다. approved 상태와 두 종류 이상 조건을 가진 선택 모듈만 핵심 설명에 사용한다. 계산 이유와 예외는 고정한다. 기존 extra.readingCore 저장으로 스키마 변경 없이 호환하며 템플릿 변수와 모순 검사도 적용한다.
- 지식 DB에는 strengthenActions/copingActions 선택 필드를 추가하고 기존 actions로 폴백한다. 구형 요청에서 필드가 빠져도 이전 전략을 보존한다. 학파(theory) 편집과 공통 구조 누락·동일 문장 점검을 연결했다. 기존 조건/예외/충돌·출처·프롬프트/에셋 관리자 기능을 유지한다.
- PDF는 웹의 같은 핵심 설명 객체를 사용한다. AI 변경도 반영하며 원국·대운·10년 세운·월운 계산표를 포함한다. 내용 길이별로 페이지를 분할한다. 접힌 기존 상세 전부를 복제한 PDF는 아니며 핵심 설명과 계산표 중심이다.
- 온보딩·입력 슬라이드·귀인 호칭·일간 소개·영상·무협 인트로·자동 스크롤·관리자 속도 설정을 유지한다. 접힌 상세는 자동 읽기 시간에서 제외한다. TTS/효과음은 추가하거나 활성화하지 않았다.

## 검증 결과
- 최종 회귀 75개 통과, 실패 0. 처음 Playwright 미탑재로 건너뛴 calendar-ui-sim은 번들 Playwright/Edge와 로컬 모의 서버로 별도 실행해 통과했다.
- 엔진 기준선 120명식 일치. 달력 검증은 절기 기준식 비교, 음력 왕복/알려진 날짜, 한국 시간대 및 경계를 포함한다. 원국 계산 엔진 파일은 변경하지 않았다.
- 8명식: 서로 다른 연령·계절·성별·시간 미상 포함. 15주제/8요소, 원본 ID 보존, 엔진/원본 불변, 특화 상품 유지, 개인화 출력 차이, 핵심 설명의 정확한 중복/계산 모순 0을 확인했다.
- 실제 관리자 API 메모리 저장/재조회: 공통 템플릿·조건 적용, draft 거부, 새 전략 보존, 기존 속도 설정 보존 통과.
- Edge 모바일 390×844: 120개 공통 요소, 실제 읽기 진입과 본문 표시, 가로 넘침 없음, 페이지 JavaScript 오류 0. 샘플 자동 읽기 29:16(기존 상세를 모두 노출한 중간 구현은 105:24); 현재 속도/글자 수에 따른 예상 시간이다.
- PDF A4 HTML 템플릿 38쪽: 웹/AI 핵심 문구 동기화, 모든 페이지 내용 높이 검사에서 넘침 0, 실제 브라우저 PNG 시각 확인. 실제 다운로드 PDF의 CDN 라이브러리 로딩/래스터화는 실행하지 않았다.
- 초기 검증 중 주제 제목 누락, 시간 설명 중복, 숨겨진 상세 시간 포함, 원국 비중과 운 지수 혼동 검출을 수정하고 재검증했다.

## 남은 확인과 한계
- 운영 DB/R2에 접근하거나 배포하지 않았다. 영상 120개가 실제 모두 등록되어 있는지 및 운영 연결 상태는 확인하지 않았다. 영상 매핑과 에셋 저장 경로는 수정하지 않았다.
- 전통 명리 해석의 정확성을 자동 테스트만으로 확정할 수 없다. 학파별 기준·가중치·문헌 근거의 전문가 검수와 운영 지식 데이터 보강은 필요하다.
- 새 기본 핵심 설명은 검수 가능한 편집 규칙이다. 같은 조건군에서는 공통 문구가 존재한다. 의미상 비슷한 모든 문장의 완전한 제거 또는 모든 조언의 개인적 적중을 보장하지 않는다. 중복 검사는 정확한 문장 일치를 중심으로 한다.
- AI 검증은 결정론적 규칙과 명칭 패턴 검사이며 모든 자연어 변형·한자 별칭까지 완전하게 증명하지 못한다. 실제 유료 AI 공급자 생성 품질/비용/지연은 모의 응답 외에 검증하지 않았다.
- 실제 모바일 기기의 영상 재생·느린 네트워크, 다운로드 PDF 파일, 운영 백업/복구는 별도 확인 항목이다. 백업·복구 절차는 설계 문서에 있고 DB 마이그레이션/운영 쓰기는 수행하지 않았다.

## 재현
프로젝트 루트에서 node tests/reading-renewal-suite.cjs 및 node tests/reading-renewal-sim.js.
브라우저 테스트는 .claude/report-dev.js를 PORT=8787로 실행하고 TASK_PLAYWRIGHT에 Playwright 패키지 경로를 지정한 뒤 node tests/reading-renewal-browser.cjs를 실행한다. 모의 서버는 운영 데이터와 분리된다. 기존 calendar-ui-sim에는 CALENDAR_TEST_URL과 NODE_PATH를 함께 지정한다.

사용자 기존 변경인 report/v2/NEXT_PLAN.md와 외부툴_프롬프트는 유지했다. 커밋/푸시/배포는 하지 않았다.


## 후속 작업 결과

운영 관리, 원본 폴더 백업·누락 복원, 실제 AI·영상 검사와 PDF 다운로드 검증을 추가했다. 최신 결과와 남은 운영 작업은 [운영 관리 안내](MOVINGTOON_OPERATIONS_GUIDE.md)를 기준으로 확인한다. 이 문서의 초기 테스트 수와 당시 미완료 목록은 초기 작업 시점의 기록이다.
