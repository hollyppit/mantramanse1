# 소원 성취 명당 — 구현 보고 (2026-11-03)

"나의 운명 지도"에 **내 사주에 맞는 소원 성취 명당**을 점수순으로 나열하는 기능. 로컬 구현·테스트 통과, **미커밋·미배포**.

## 동작
- 소원 분야 선택: 재물·사업 / 합격·학업 / 직업·승진 / 창작·표현 / 인연·결혼 / 건강·회복 / 종합 (선택값은 브라우저에 저장).
- 기준 위치: 지도 카드의 기준 지역(현재 거주지 또는 출생지).
- 점수(0~100, 상대 비교값) = 방위 적합도 40 + 소원-방위 적합도 30 + 소원 분야 태그 20 + 거리 10.
  - 방위: 기준 위치에서 장소까지의 실제 방위각 → 8방위 → 오행 → 이 사주에서의 유리/불리(기존 지역 해석 엔진 재사용).
  - 소원-방위: 소원이 이어지는 오행(재물=재성, 학업=인성, 직업=관성, 창작=식상, 인연=성별에 따라 재성/관성, 건강=억부 용신)과 방위 오행의 상생상극 관계 × 그 오행의 용신/기신 역할 보정.
  - 태그: 장소에 붙은 소원 분야와 일치하면 100, 종합 태그 65, 그 외 25.
  - 거리: 30km 이내 100 → 300km 이상 20, 사이는 직선.
- 목록은 상위 10곳 + "더 보기", 각 장소에 순위·유형·점수·4개 세부 점수·방향/각도/거리·"왜 이 순위인가"(근거 문장, 유리/불리, 출처 링크·확인일).
- 금지 표현 검사는 하지 않음(사용자 결정).

## 장소 데이터
- 장소는 **관리자가 출처와 함께 등록**한 것만 쓴다. 출처 이름·https 주소·확인일이 없으면 저장되지 않는다. 앱이 장소를 임의로 만들지 않는다.
- 이번 작업에서 운영 DB에 넣은 실제 장소는 **없다**(테스트는 가짜 fixture만 사용, 로컬 메모리 KV).
- 관리자 탭 "소원 성취 명당": 등록·수정·게시·게시 취소·이전 버전 되돌리기·삭제·일괄 게시, 공개 스위치, 사주·기준 지역·소원 분야를 넣어 순위 미리보기(초안 포함).

## 스위치
- 클라이언트 `wishSpots`(기본 꺼짐) + 서버 스위치(`/api/wish-spots`의 `enabled`, 기본 꺼짐). 서버 스위치가 켜지고 게시된 장소가 있어야 보인다. 켜져도 "나의 운명 지도"(`region`)가 켜져 있어야 화면에 나온다.
- 끄기: 관리자 탭에서 "끄기"(약 1분 내 반영).

## 검증
- wish-spots-sim(차트 400개): 가중치 합 100, 총점=가중평균, 소원 점수·거리 점수 독립 재계산 일치, 소원 분야별 오행 매핑, 태그·거리 효과, 비활성 제외, 원국 불변, 네트워크·운(대운/세운) 미참조. 소원 분야를 바꾸면 1위가 달라지는 사주 96%.
- wish-spots-api-sim: 인증, 출처 필수, 게시 흐름, 스위치, 되돌리기, 일괄, 삭제, 다른 KV 키 불간섭.
- 기존 테스트(엔진 기준선 120개, region·region-reading·wealth·byeongyak·jonggyeok·gyeokguk·admin-navigation·luck-flags 등) 모두 통과.
- 브라우저 확인: 데스크톱·375px 모바일에서 목록 표시, 소원 분야 변경 시 순위 갱신, 가로 넘침 없음.

## 한계
- 점수는 이 앱의 해석 모델 내 상대값이며 확률·효과를 뜻하지 않는다. 방위오행은 전통 상징 해석이다.
- 방위는 기준 지역 대표 좌표(시·도 단위 선택 시 중심점) 기준이라 정밀 주소와 차이가 있다.
- 장소 정보(운영 여부·이용 안내)는 등록 시점의 출처 기준이다. 실제 장소 데이터는 관리자가 출처를 확인해 입력해야 한다.
- 대운·세운 등 운 데이터는 반영하지 않는다(원국만).

## 배포 시 순서
1. 커밋·푸시(Cloudflare Git 빌드).
2. 관리자에서 실제 장소를 출처와 함께 등록·게시.
3. 공개 스위치 켜기. 켜기 전에는 사용자 화면에 아무것도 나오지 않는다.

## 초안 장소 45곳 (docs/data/wish-spots-seed.json)
- 위키백과 문서 주소를 출처로, 좌표는 위키백과(없으면 연결된 위키데이터 P625)에서 가져왔다. 확인일 2026-11-03. 이름·좌표 규칙 검증(validateSpot)을 모두 통과.
- **소원 분야 태그와 유형은 전통적으로 알려진 관념에 따라 제가 분류한 값**이며 위키백과가 보증하는 내용이 아니다. 게시 전에 검수할 것.
- 반영 방법: 관리자 → 소원 성취 명당 → "JSON 일괄 등록(초안)" → 이 파일 선택 → 목록 확인 → 선택 게시 → 공개 스위치 켜기.
