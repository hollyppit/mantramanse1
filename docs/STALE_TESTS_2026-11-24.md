# 낡은 테스트 실패 정리 (2026-11-24)

오프라인 테스트(브라우저·운영 서버가 필요한 `*-browser`·`*-live`·`*-qa`·`cinematic-*`·`timeline84-*`와 인자가 필요한 도구 `regression-snapshot`·`interpretation-quality`를 뺀 353개)를 다시 돌려 실패를 하나씩 원인부터 봤어요.

## 실제 화면 문제였던 것(코드 고침)
- **reading-detail-profiles-sim**: 한 장에 별이 여럿이면 "이 별은 내 사주의 어린 시절·가족 자리에 있어요."가 똑같이 반복됐어요(11-23 신살 문단 수정 때 생김).
  - 이제 별 이름을 넣어요: "화개살은 내 사주의 …에 있어요."
  - 글자 관계 문장도 "충은 내 사주의 …를 잇고 있어요."로 바꿨어요(`report/v2/chart-lines-depth.js`).
- **signal-sim**: 점수 엔진이 바뀐 뒤(통합 용신·십성 역할) 직업·사업 지표의 분포가 밀렸어요. 직업은 '조심'이 38%, '무난'이 29%였어요.
  - 두 지표의 등급 기준값만 지금 분포(하위 10·30%, 상위 30·10%)로 다시 맞췄어요(`luck-grade.js`: job [43,49,57,64], business [41,48,57,63]).
  - 캐시 꼬리표: topic-deep·허브 `20261124-sig`. 허브 story.js 는 다른 세션이 올린 `-sec` 버전에 맞춤.

## 테스트가 낡았던 것(테스트 고침)
- **world-entry-sim**: viewer 일부만 잘라 실행해 `swWatch`(신호 색 감시)가 없었음 → 모의 함수 추가
- **report-v2-sim**: PDF 표지에 로고 `<img>`가 생겨 'img 없음' 검사가 실패 → 이름 속 태그(`<img src=x`)만 검사
- **unseong-cycle-sim**: 엔진과 12운성 모듈 사이에 다른 모듈이, 원국 표 아래 한눈에 보기·물상 카드가 들어감 → 배치 검사 완화
- **ux-writing-copy-audit-sim**
  - 도구가 Node 내부 acorn 을 써 `--expose-internals` 가 필요 → 테스트가 스스로 그 옵션을 붙여 다시 실행
  - 따옴표 안 대사·'…할까 봐'는 말투 판정에서 뺌
  - 남은 후보 673개를 직접 훑어 이유를 붙여 검토 예외에 추가(단편 소설 문체, 주역 원문·실천 문장, AI 작성 지침, 노래 가사, 토정비결 한문, 점검 질문형, 라벨·조각)
- **coherent-reading-flow-sim**: 새 묶음 이름 `bundle-detail-` 인정
- **commerce-sim**: 결제 날짜가 고정돼 환불 기간(7일)을 넘김 → 1시간 전으로(앞선 커밋)
- **tarot-symbols-sim**: report/index.html 의 story.js 버전을 허브 HV(`-sec`)와 맞춤
- **rebuild-admin-20261023**: 장·문안이 늘어(107장) 고정 숫자 84/925 대신 서로 일치하는지 봄
- **rebuild-compose-20261022**
  - 창작·개운·건강 안내 문구가 해요체로 바뀜(아닙니다→아니에요, 보장하지 않습니다→않아요, 면책 끝 '우선하세요'→'예측하지 않아요')
  - 카탈로그 비교를 종합풀이 묶음까지 포함한 전체 장으로
- **health-narrative-flow-sim**: 건강 주제는 운영에서 꺼져 있고 서버도 보관 장을 조립하지 않음 → 꺼져 있으면 이유를 밝히고 건너뜀(다시 켜면 그대로 검사)
