# 사고수 — 어떤 장면을 조심할까 (참고) (2026-11-03)

운세 흐름 탭에서 그래프 지표를 "사고수"로 두고 대운·세운·월운·일진 한 칸을 고르면 상세에 **조심할 장면** 블록이 나온다. 모듈 `accident-hint.js`(`MantraAccidentHint`), 테스트 `tests/accident-hint-sim.cjs`.

## 읽는 방식 (전통 해석, 참고용)
- 장면 7가지: 목=높은 곳·계단·운동 중 넘어짐, 화=불·열·전기, 토=무너짐·낙석·공사 현장, 금=도로·차량·금속 도구, 수=물·빙판·빗길, 날카로운 도구(양인살·현침살), 갑작스러운 충격(백호대살·괴강살). 낙정관살은 수 장면에 더한다.
- 신호: 운 글자와 원국 글자의 충(1.5)·형(1.0)·파/해/원진(0.5) → 걸린 원국 글자의 오행 장면, 이미 많은 오행(≥32%)을 운이 더함(1.2), 억부 기신(0.6)·구신(0.4), 해당 신살(1.0·0.8). 1.5 이상이면 표시, 2.5 이상 '주의'. 최대 3개.
- "원국에서 걸린 자리": 걸린 원국 기둥의 전통 대응(년주=집 밖 먼 곳·이동, 월주=직장·일터, 일주=집과 가까운 생활권, 시주=귀가길·늦은 시간).
- 앱의 사고수 지수(0~100)를 함께 표시한다(지수는 기존 계산 그대로).

## 한계
- 사고 발생·종류·시점을 예측하지 않는다. 사망·중상 같은 단정 표현은 쓰지 않고(테스트로 차단) 면책 문구와 일반 안전 수칙 한 줄을 붙인다.
- 장면·장소·기둥 대응과 임계값은 전통 관념과 이 앱의 설계값이며 검증된 통계가 아니다. 문구는 고정 템플릿이고 AI를 쓰지 않는다.
- 사고수 지수가 낮아도 신호가 있으면 장면이 나오고, 지수가 높아도 장면이 없을 수 있다(서로 다른 계산).

## 스위치
- `feature-flags.js`의 `accidentHint`(기본 켜짐). 끄려면 false로 바꿔 배포.
