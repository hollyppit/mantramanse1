## 4. 지켜야 할 원칙

1. **엔진 계산 규칙은 건드리지 않는다.** 바꿔야 하면 비교 테스트를 먼저 만든다(`tests/engine-baseline-sim.js`, `regression-snapshot.js engine.js 120`).
2. AI 가 계산값·점수를 만들지 않는다. 문장은 승인된 근거·기존 풀이 텍스트의 조합.
3. 근거 없는 단정·보장 표현 금지, 전생은 창작 판타지 표시 유지(윤회의 문 `notice`).
4. 기존 데이터·에셋 삭제 금지. DB 변경은 마이그레이션·롤백 가능하게.
5. 구현하지 않은 것을 완료했다고 보고하지 않는다. 확인하지 못한 것은 "확인 못함"으로 적는다.
6. 사용자 화면 코드에 "일주 각성"·"수호신" 문구를 쓰지 않는다(`tests/ilgan-intro-sim.js` 가 주석까지 검사).
7. 줄바꿈(CRLF) 주의: 대부분 파일이 CRLF. 스크립트로 수정할 때 `\r\n` 을 정규화했다가 되돌릴 것.
