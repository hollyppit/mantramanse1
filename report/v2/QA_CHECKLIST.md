# 운명 세계 지도 — 실기기·네트워크 검증 체크리스트

대상: `renewal/world-map` 브랜치 배포본(미리보기). 개발 PC의 브라우저 에뮬레이션으로는 확인하지 못한 항목만 담았다.
결과는 항목 옆에 ○ / × / 메모로 적고, × 는 기기·OS·브라우저 버전을 함께 남긴다.

## 0. 준비

| 항목 | 값 |
|---|---|
| 기기 | iPhone Safari(최신 + 1~2개 이전 iOS), Android Chrome(저사양 1대 포함) |
| 테스트 사주 | 1992-06-23 01:30 남 / 1985-03-14 09:00 여 / **시간 모름** 1개 |
| 주소 | `/report/v2/` (QA 빠른 진입: `?qa=1992-06-23,01:30,M` 은 입력만 채운다 — 제출은 직접) |
| 되돌리기 스위치 | `?explore=0` 이면 예전 한 문서 읽기. 문제가 생기면 이 주소로 비교 |
| 관리자 | `/report/admin/` → "세계관"·"서비스 점검" 탭 |

## 1. 진입 흐름 (모든 기기)

- [ ] 입력 → 프롤로그 → (일간 소개·일주 영상) → 끝난 뒤 **세계 지도**가 나온다
- [ ] 일주 영상이 없는 사주에서도 오류 화면 없이 지도까지 도착한다
- [ ] 영상 자동재생이 막힌 상태(iOS 저전력 모드)에서 탭하면 재생되거나 정지 이미지로 넘어간다
- [ ] 지도 화면에서 가로 스크롤이 생기지 않는다(375px, 360px, 412px)
- [ ] 세계 카드: 상태 칩(탐험 가능/탐험 중/탐험 완료)과 **유료 배지가 서로 다른 것**으로 보인다
- [ ] 우상단 "‹ 홈" 고정 버튼이 제목·안내 문구를 가리지 않는다 ← 현재 일부 화면에서 가깝게 겹침

## 2. 세계 입장 연출

- [ ] 첫 입장에만 3.5초 연출, 탭하면 즉시 건너뛴다
- [ ] 같은 세계 재입장 시 연출이 없다(새로고침 후에도)
- [ ] iOS "동작 줄이기" 켠 상태에서 연출 없이 바로 들어간다
- [ ] 입장 영상/이미지를 관리자에서 등록한 세계는 로딩 실패 시 색 바탕으로 대체된다(주소를 일부러 틀리게 입력)

## 3. 세계별 인터랙션

| 세계 | 확인 |
|---|---|
| 천명의 서고 | 기둥·십성 버튼 터치 영역(44px 이상), 같은 십성 강조, 접기 3곳, 시간 모름 사주에서 시주 비움 |
| 황금의 성채 | 분야 칩 2개 비교(375px에서 세로로 쌓임), 사업·독립 탭 막대, 10년 막대 연도 탭 |
| 인연의 정원 | 유형/정렬 칩 줄바꿈, 일주 4열 격자, 일간·일지 직접 선택(음양 불일치 안내), 상대 가정 전환 |
| 시간의 회랑 | 대운 가로 스크롤(스냅), 해→월 선택, "자세한 근거" 시트 스크롤·닫기, 읽는 법 |
| 윤회의 문 | 전체 화면 컷, 자동 재생/일시정지, 이전·다음, 마지막 컷 후 지도 복귀, **창작 표시가 항상 보임**, 이미지 로딩 지연 시 색 바탕 |
| 개운의 성역 | 4개 탭 한 줄, 체크리스트 체크 후 새로고침해도 유지, PDF 버튼 해금 전 비활성 / 해금 후 생성, 공유 카드 |

## 4. 데이터·네트워크

- [ ] 느린 3G 제한에서 지도→세계 상세 전환이 5초 안에 화면을 그린다(이미지는 나중에 채워져도 됨)
- [ ] `/api/worlds` 실패(오프라인)에서도 기본 6개 세계가 나온다
- [ ] 전생 이미지(약 160KB)가 느린 망에서 뒤늦게 떠도 컷 문장이 먼저 읽힌다
- [ ] 데이터 절약 모드(Chrome "데이터 절약")에서 영상이 로드되지 않는다
- [ ] 시크릿/사생활 보호 모드에서 진행 저장이 막혀도 오류 없이 읽기가 계속된다(저장만 안 됨)

## 5. 이어보기·상태

- [ ] 챕터 서랍 "탐험 홈" → 지도 → 이어서 읽기가 마지막 위치부터 시작
- [ ] 읽음 표시가 새로고침 후에도 유지(같은 사주), 다른 사주에서는 섞이지 않음
- [ ] 뒤로 가기(브라우저)가 앱을 이탈시키지 않고 자연스럽게 동작하는지 — 현재 해시 라우팅 없음, **이탈하면 ×로 기록**

## 6. 관리자

- [ ] 세계관: 이름·색·순서·사용 여부 변경 → 저장 → 사용자 지도에 반영(새로 연 무빙툰부터)
- [ ] 세계관: 입장 영상 업로드(모바일 브라우저에서도) 후 미리보기
- [ ] 세계관: "기본값으로 되돌리기"가 업로드 파일은 지우지 않는다
- [ ] 서비스 점검: 운영 데이터 기준 에셋 누락 0 확인, 풀이 누락 의심/단정 표현 결과 검토

## 7. 알려진 한계 (× 가 아니라 기록용)

- 유료 표시는 배지뿐이며 서버 권한 검증이 없다.
- 전생 무빙툰은 이미지 1장 + 카메라 이동이다(컷별 이미지·영상 없음).
- 상대 전체 사주 궁합은 없고, 일주 두 글자 상성만 제공한다.
- 기존 실패 테스트 5개(`free-sim`, `panel-sim`, `panel-edit-sim`, `calendar-ui-sim`, `regression-snapshot` 사용법)는 이번 변경과 무관하다.
