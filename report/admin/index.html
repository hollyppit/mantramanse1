폴더

    클립 행을 폴더로 끌어다 놓아 옮길 수 있습니다.

    장제목폴더조건영상우선

    조건에 맞는 클립이 없습니다. “+ 클립 추가”로 시작하세요.

    만세력 엔진은 앱과 같은 파일(engine.js)을 씁니다. 아래 값은 계산 결과이며, 직접 바꿔 가며 조합을 시험할 수 있습니다.

    조합을 실행하면 여기서 순서대로 재생됩니다

    선택된 순서

      일주 60개 × 9개 장에서 어느 칸이 비어 있는지 봅니다. 초록 해당 일주를 직접 지정한 클립이 있음 · 파랑 조건 없는 공통 클립으로 채워짐 · 회색 0은 비어 있음.

      클립 편집

      조건 — 아무것도 고르지 않은 항목은 “상관없음”입니다. 고른 항목이 모두 맞아야 이 클립이 후보가 되고, 더 구체적인 클립이 먼저 뽑힙니다(일주 6 · 일간/용신/신강약 3 · 십성군/월지/일지 2 · 성별 1점의 합).

      자막 타임라인

      줄마다 “몇 초에 나타나 몇 초에 사라지는지”를 정합니다. 시간은 앞부분 자르기를 반영한 재생 시작 기준(초)입니다. 겹치지 않게 입력하세요.

      ✨ AI로 자막 쓰기 (Claude 메인 · 실패 시 GPT 자동 전환)

        나타남(초)사라짐(초)자막 내용음성(일레븐랩스)

        음성은 “연출 → 읽는 목소리”에서 목소리 읽기: 켜기 · 엔진: 일레븐랩스, “일레븐랩스 목소리”에서 목소리를 고른 뒤 만듭니다. 같은 문장·설정은 다시 만들지 않고 재사용하므로 크레딧이 추가로 들지 않습니다. 미리보기에서 들으려면 “영상·목소리 소리 켜기”를 체크하세요.

        연출 — 비워 둔 칸은 “기본 연출 설정” 값(없으면 내장 기본값)을 따릅니다. 이 클립에서만 다르게 하고 싶은 칸만 고르세요.

        장 이름·순서 관리

        장의 순서가 곧 영상이 이어지는 순서입니다. 이름은 자유롭게 바꿀 수 있고, 클립은 이름이 아니라 장 자체에 연결되어 있어 이름을 바꿔도 그대로 유지됩니다. 클립이 들어 있는 장은 삭제할 수 없습니다(먼저 다른 장으로 옮기세요).

        기본 연출 설정

        모든 클립에 공통으로 적용되는 연출입니다. 클립 편집에서 따로 지정한 칸만 이 값 대신 쓰입니다. 비워 두면 내장 기본값(페이드 전환 · 아래 반투명 자막 · 목소리 끔)입니다.
