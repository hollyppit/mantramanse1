폴더

    클립 행을 폴더로 끌어다 놓아 옮길 수 있습니다.

    장제목폴더조건영상우선

    조건에 맞는 클립이 없습니다. “+ 클립 추가”로 시작하세요.

    만세력 엔진은 앱과 같은 파일(engine.js)을 씁니다. 아래 값은 계산 결과이며, 직접 바꿔 가며 조합을 시험할 수 있습니다.

    조합을 실행하면 여기서 순서대로 재생됩니다

    선택된 순서

      일주 60개 × 9개 장에서 어느 칸이 비어 있는지 봅니다. 초록 해당 일주를 직접 지정한 클립이 있음 · 파랑 조건 없는 공통 클립으로 채워짐 · 회색 0은 비어 있음.

      오른쪽 미리보기에서 글자나 이미지를 클릭하면 아래에 서식(글씨체·크기·색·위치…)이 나타나고, 끌어서 옮길 수 있어요. 제목에서는 줄바꿈이 되고 *별표*로 감싼 글자는 금빛이 됩니다. 저장해야 실제 페이지에 적용됩니다.

      미리보기 (인트로 영상·알림 신청은 동작하지 않음)

      판매 페이지(/report/)에 들어올 때 전체 화면으로 먼저 음소거로 재생되는 영상입니다. 이 탭의 저장은 클립 저장과 별개로 바로 반영됩니다.

      웹(PC)용 인트로 화면 폭 768px 초과에서 재생 · 가로 영상 권장

      모바일용 인트로 화면 폭 768px 이하에서 재생 · 세로 영상 권장

      인트로 문구 영상 위에 글자를 띄웁니다. 비워 두면 영상만 재생됩니다. 시간은 영상 시작 기준 초입니다.
      글자 모양·위치·애니메이션

      글자 크기는 화면 폭에 비례해서, 같은 값이어도 웹(넓은 화면)에서는 모바일보다 훨씬 크게 보입니다. 웹·모바일 탭에서 기기별로 따로 맞추세요. 웹/모바일 칸을 비워 두면 공통 값을 씁니다.

      한쪽만 올리면 모든 기기에서 그 영상이 재생됩니다.

      권장: 가로 720~1080px, mp4(H.264), 소리 포함, 3MB 이내. 큰 파일은 첫 방문자가 오래 기다립니다.

      클립 편집

      조건 — 아무것도 고르지 않은 항목은 “상관없음”입니다. 고른 항목이 모두 맞아야 이 클립이 후보가 되고, 더 구체적인 클립이 먼저 뽑힙니다(일주 6 · 일간/용신/신강약 3 · 십성군/월지/일지 2 · 성별 1점의 합).

      자막 타임라인

      줄마다 “몇 초에 나타나 몇 초에 사라지는지”를 정합니다. 시간은 앞부분 자르기를 반영한 재생 시작 기준(초)입니다. 겹치지 않게 입력하세요.

      ✨ AI로 자막 쓰기 (Claude 메인 · 실패 시 GPT 자동 전환)

        나타남(초)사라짐(초)자막 내용음성

        음성은 “연출 → 읽는 목소리”에서 목소리 읽기: 켜기 · 엔진: 일레븐랩스, “일레븐랩스 목소리”에서 목소리를 고른 뒤 만듭니다. 같은 문장·설정은 다시 만들지 않고 재사용하므로 크레딧이 추가로 들지 않습니다. 미리보기에서 들으려면 오른쪽 “🗣 목소리 듣기”를 체크하세요.

        연출 — 비워 둔 칸은 “기본 연출 설정” 값(없으면 내장 기본값)을 따릅니다. 이 클립에서만 다르게 하고 싶은 칸만 고르세요.

        폴더 설정

        장을 지정하면 안의 클립은 장을 따로 고르지 않아도 이 장에 속합니다. 클립이 직접 장을 지정했다면 그 값이 우선합니다(위 체크로 한꺼번에 풀 수 있음).

        우선순위: 이 폴더와 하위 폴더 안의 모든 클립의 우선순위에 더해집니다. 조건이 같을 때 합이 높은 클립이 먼저 뽑힙니다.

        공통 조건 — 이 폴더 안 모든 클립이 상속합니다. 클립이 같은 항목을 직접 고르면 클립 값이 우선합니다. 폴더에서 한 번 바꾸면 안의 클립을 하나씩 고칠 필요가 없습니다.
        공통 연출 — 클립에서 따로 지정하지 않은 칸에 적용됩니다 (우선순위: 클립 → 이 폴더 → 상위 폴더 → 기본 연출).

        일괄 편집

        연출 — 값을 고른 칸만 대상 클립 모두에 덮어씁니다. 비워 둔 칸은 그대로 둡니다.

        🎧 목소리 비교 테스트

        같은 문장을 여러 엔진·목소리로 번갈아 들어 보고, 마음에 드는 것을 바로 적용합니다. 속도·모델·말투 지시 등은 현재 “목소리 설정” 값을 따릅니다. 일레븐랩스·OpenAI는 글자 수만큼 사용량이 들며, 같은 문장·설정은 저장된 파일을 재사용합니다.

        장 이름·순서 관리

        장의 순서가 곧 영상이 이어지는 순서입니다. 이름은 자유롭게 바꿀 수 있고, 클립은 이름이 아니라 장 자체에 연결되어 있어 이름을 바꿔도 그대로 유지됩니다. 클립이 들어 있는 장은 삭제할 수 없습니다(먼저 다른 장으로 옮기세요).

        기본 연출 설정

        모든 클립에 공통으로 적용되는 연출입니다. 클립 편집에서 따로 지정한 칸만 이 값 대신 쓰입니다. 비워 두면 내장 기본값(페이드 전환 · 아래 반투명 자막 · 목소리 끔)입니다.

        아래 세 값을 한 번에 맞춥니다 — ① 자막·음성이 영상보다 길 때: 영상을 처음부터 다시 반복 ② 목소리가 자막 시간보다 길 때: 자막·영상을 늘려서 끝까지 읽기 ③ 자막 읽는 속도: 초당 8글자(글자가 많으면 표시 시간을 늘림). 비워 두면 이 값이 내장 기본값으로 이미 적용됩니다. 예전에 다른 값을 저장해 두었다면 이 버튼으로 되돌리세요.
