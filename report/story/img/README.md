# 스토리 온보딩 이미지 폴더

이미지 파일(WebP 권장, 가로 1200px 이하)을 이 안에 넣고, `report/story/content.js` 의 해당 블록 `src` 에 **이 폴더 이후의 경로**만 적습니다.

    src: 'problem/problem-01.webp'      ← 파일 위치: report/story/img/problem/problem-01.webp

권장 하위 폴더: problem/ insight/ mantra/ movingtoon/ result/ story/ paywall/  (자유롭게 만들어도 됩니다)
파일이 없으면 화면에는 자리표시가 나오며, 파일만 넣으면 바로 적용됩니다. 영상은 mp4(H.264), 짧게 압축하고 poster 이미지를 함께 지정하세요.
